# B25 概览页热力图（额度版）设计

状态：**设计定稿**（2026-11-16），在实验分支 `experiment/b25-heatmap-v2` 上实现。
**实验特性，不进 main**：试用通过前不合并主线、不升版、不发版（仓库所有者 2026-11-16 决定）。
实现卡见 [tasks/m16.md](../tasks/m16.md)。
依据：`docs/backlog.md` B25、实验分支 `origin/experiment/b25-heatmap`（T12.2–T12.7 已实现后端与旧版 UI）、
[05-config.md](../05-config.md) `config stats`、[10-cli-luci.md](../10-cli-luci.md) 概览页/CLI/rpcd 约定。

本设计**取代** [b25-heatmap.md](../b25-heatmap.md) §7 的 UI 布局（该文件随 T16.1 合并实验分支后进入 main）；
§2–§6（开关、数据模型、采样、持久化、`stats history` 契约）与 §9 的失败边界沿用实验实现，不再重写。

## 1. 目标与非目标

目标：在概览页**「流量与连接」块内**左右分栏放热力图（左侧 90 天日历网格，右侧保留原有实时流量
与连接信息），并按**月流量额度**给格子上色——越接近日均额度越红。

非目标：
- 不做域名/节点/目的地记录，不做历史回填，不改 `stats` 口径；
- 不改采样与持久化的数据字段（除新增 `quota`），不引入图表库；
- 不做「本月已用 / 剩余」汇总卡，不做超额告警（后续可另开卡）。

## 2. 数据口径

沿用实验实现：`config stats 'stats'` 的 `heatmap_enabled`（默认 0）、`/etc/aether-proxy/usage.json`
的 `days{日期:{tx,rx,observed,healthy}}`（保留 90 个本地日期）、`stats history` 与 rpcd
`stats_history`。

新增（T16.2）：`usage.json` 顶层 `quota`。

```json
{
  "schema": 1,
  "updated_at": 1790000000,
  "quota": { "bytes": 100000000000, "set_at": 1790000000 },
  "days": { "2026-11-15": { "tx": 123456, "rx": 987654, "observed": 86400, "healthy": 82000 } }
}
```

- `quota.bytes` 为**十进制**字节（1 GB = 10^9，1 TB = 10^12）；`null` 或字段缺失 = 未设置。
- 日平均额度按**该格日期所在月**的实际天数计算：`daily = quota.bytes / daysInMonth(日期)`。
  2026-02 用 28 天、2026-11 用 30 天、2026-12 用 31 天；跨月不重置、不累积。

## 3. 额度设置

- 存放：`usage.json` 的 `quota`。**不放 UCI**：`aether-proxy.init` 注册了 `aetherproxy` 的
  reload 触发器，任何 UCI 保存都会重载服务，而额度只是展示参数，不该动数据面。
- CLI（逻辑唯一实现处）：`aether-proxy stats quota`、`stats quota set <值>`、`stats quota clear`。
- rpcd：`stats_quota`（`{action:'show'|'set'|'clear', bytes?}`），ACL 归 **write**，转发 CLI。
- `stats history` 回复顶层加 `quota`，前端据此着色；未设置时前端退回相对算法（§4.3）。
- 写入互不覆盖：monitor 的每日落盘必须**先重读**文件再写，保留 `quota`；quota 写入保留 `days`。

## 4. 颜色

### 4.1 额度档（quota 已设置）

`r = 当日(tx+rx) / (quota.bytes / 该日期所在月天数)`，5 档 + 空档：

| 档 | 条件 | 浅色主题 | 深色主题 | 含义 |
|---|---|---|---|---|
| 0 | 有记录但 tx+rx = 0 | `#ebedf0` | `#21262d` | 当天没走代理 |
| 1 | r < 0.25 | `#9be9a8` | `#1f6f3f` | 很省 |
| 2 | 0.25 ≤ r < 0.5 | `#40c463` | `#2ea043` | 正常 |
| 3 | 0.5 ≤ r < 0.75 | `#ffd33d` | `#d29922` | 偏多 |
| 4 | 0.75 ≤ r < 1 | `#fb8500` | `#db6d28` | 接近日均额度 |
| 5 | r ≥ 1 | `#e5484d` | `#f85149` | 达/超日均额度 |
| 空 | 该日无记录 | `#ebedf0` 但更淡（`--ap-heat-void`，浅 `#f4f6f8` / 深 `#181d23`） | | 无数据、无 tooltip |

阈值边界按「左闭右开」：`0.25 → 档 2`，`1.0 → 档 5`。

### 4.2 深色主题

用 CSS 变量 + `@media (prefers-color-scheme: dark)` 覆盖，不检测 LuCI 主题类。

### 4.3 未设额度（回退）

`r_rel = log1p(当日流量) / log1p(窗口内最大值)`，映射 4 档绿阶（GitHub 式）：浅色
`#9be9a8`/`#40c463`/`#30a14e`/`#216e39`，深色 `#0e4429`/`#006d32`/`#26a641`/`#39d353`；
`level = ceil(4 × r_rel)`，`0` 流量走档 0。窗口内无任何流量时全部走档 0。

### 4.4 健康度

**不再用边框/角标**（旧实验设计）。格子只有一种视觉变量（额度占比）；健康占比、
观测时长放进 tooltip。理由：25px 方格里两个编码读不出来。

## 5. 布局

### 5.1 分栏

「流量与连接」块（`trafficSection`）在 `h3` 之后改为两列：

```
[ 近 90 天 ]            [ 月额度 ▾ ]      |  （表头）上传  下载
[ ■■■■■■■■■■■■■■■■■ ]                    |   代理   …     …
[ ■■■■■■■■■■■■■■■■■ ]   （5 行 × 18 列）   |   直连   …     …
[ ■■■■■■■■■■■■■■■■■ ]                    |   合计（WAN）…
[ ■■■■■■■■■■■■■■■■■ ]                    |  代理连接 n  总连接 m
[ 图例 ▢▢▢▢▢ 无记录 ]
```

- 容器：`display:flex; gap:1.5em; align-items:center; flex-wrap:nowrap`；左列 `flex:1 1 50%`，
  右列 `flex:1 1 50%`（右列内容就是今天的表格 + 连接行，不改）。
- 左列自上而下：caption 行（左「近 90 天」、右「月额度」下拉）、网格、图例。
- 右列垂直居中（`align-items:center`），表格高度约 140px，与左列网格（约 140px）对齐。
- **`heatmap_enabled` 关闭时整块与今天完全一致**：只有右列内容、不渲染 caption/网格/图例，
  也不调用 `stats_history`（不产生额外 RPC）。开关入口统一放在高级页的「实验性功能」标签页
  （T16.4，热力图是首个实验性功能），默认关闭。
- 宽度 < 720px 时 `flex-direction: column`：热力图在上、实时信息在下，左右两列都占满宽度。

### 5.2 网格尺寸

- 90 天 = **5 行 × 18 列**，row-major 连续日期，无前导空格，今天恒为最后一格（index 89，
  右下角）；不与星期几对齐（半幅宽度放不下 7 行周对齐且会过高）。
- `grid-template-columns: repeat(18, minmax(0, 1fr)); gap:3px; width:100%`；每格
  `aspect-ratio:1; border-radius:20%; width:100%`。
- 尺寸推导（桌面内容宽约 1100px，两列各约 510px）：`(510 − 17×3) / 18 ≈ 25.5px`，
  5 行 + 4 个间距 ≈ **140px** 高，与右列表格等高；单元格尺寸不写死，随容器自适应。
- 左列容器 `overflow-x: auto` 兜底；宽屏不出现滚动条。

### 5.3 图例

一行 6 个色块：无记录 + 5 档。有额度时标区间「0–25% / 25–50% / 50–75% / 75–100% / ≥100%」，
未设额度时标「少 … 多」。图例与网格同一行高；窄屏允许换行。

## 6. 交互

### 6.1 额度下拉

- 选项：`不限` / `50 GB` / `100 GB` / `200 GB` / `500 GB` / `1 TB` / `自定义…`。
- 选中即生效：`不限` → `stats_quota {action:'clear'}`；预设 → `{action:'set', bytes}`；
  `自定义…` → 展开一个整数 GB 输入（1–100000）与「确定」，提交后调 `action:'set'`。
- 成功后**只重着色、不刷新页面、不重载服务**；失败在 caption 行下方显示一行错误文字
  （不弹通知、不清空选择）。
- 初始值：`quota.bytes` 等于某个预设值则选中它，否则选中「自定义…」并填好 GB 数；
  `null` → 「不限」。
- 5 秒轮询刷新**不得重建** caption 行 / 下拉 / 图例的 DOM：只更新格子的 class 与 `title`，
  否则打开的下拉会被关掉（T16.3 验收项）。

### 6.2 tooltip（原生 `title`）

按行：
1. 日期 `YYYY-MM-DD`；
2. 代理流量（自动单位，沿用现有 `ap` 格式化）；
3. 健康占比 `82%（70800/86400 秒）`；`observed = 0` 显示「—」；
4. 观测时长；
5. 占日均额度百分比（仅设了额度时显示）：`r × 100` 取整，`≥100%` 原样显示。

无记录的格子没有 `title`。

### 6.3 刷新与错误

沿用概览页现有节奏：热力图数据来自 `stats_history`，在开启状态下随概览刷新读取；读取失败保留
上一次网格并在图例下方显示一行错误（沿用实验实现的「保留最后网格」语义）。

## 7. 边界

| 场景 | 行为 |
|---|---|
| 关闭开关 | 不采样、无历史 API、块内无热力图、布局与今天一致 |
| 首次开启 | 只有开启后的日期有记录，之前全部「无记录」 |
| 未设额度 | 相对绿阶回退，图例标「少…多」 |
| 额度 < 当日流量 | 档 5（红），不裁剪、不封顶显示 |
| observed = 0 | 健康占比显示「—」，仍按流量着色 |
| 跨月 | 每格按自己那个月的天数算日均额度 |
| 时钟/时区 | 日期取自 `usage.json` 的本地日期字符串，不在前端重新推算时区 |
| 历史文件损坏 | `stats_history` 返回 `enabled:true, days:[]`，显示空网格 + 一行错误 |
| 额度写入失败 | 下拉恢复原值附近显示错误，不改变现有配色 |

## 8. 测试与验收

- 后端：额度 set/clear、单位解析、边界、monitor 落盘保留 `quota`、`stats_history` 回传、ACL。
- 前端：18 列常量、90 格、index 89、6 档边界（含 0.25/0.5/0.75/1.0 与按月天数）、
  无额度回退、关闭零变化与零 API、下拉预设/自定义/失败、轮询不重建 DOM、i18n。
- 真机（H28K）：格子实际像素、整块高度、窄屏单列、下拉写入后刷新仍在、开启一天后
  `usage.json` 有 `quota` 与当日条目；设备操作需仓库所有者当次授权。
