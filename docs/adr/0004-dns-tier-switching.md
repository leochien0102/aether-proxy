# ADR-0004 DNS 回退由切换上游实现，不依赖 chinadns-ng 组内并发

- 状态：**已定**（2026-10-14）
- 背景：需求中的回退顺序是「经节点 → 直连境外 → 国内」。chinadns-ng 同一组内的上游是并发查询、先到先用（已核实 README），
  把三级放进同一组时，被污染的抢答会赢得竞争。
- 决定：trust 组任何时候只配置一级上游。由 daemon 根据代理健康检测和 DNS 探测切换级别（T1/T2/T3），每次切换都重启 chinadns-ng
  并对 dnsmasq 发 SIGHUP 清空缓存。启动时从 T2 开始。
- 后果：每次切换有不到 1 秒的 DNS 中断（dnsmasq 会重试）。降级期间混入的污染应答在恢复时会被清空。
  节点域名的引导解析使用一个独立的自定义组 `boot`（直连境外 DNS），从结构上消除了「解析节点要靠节点」的死锁。
