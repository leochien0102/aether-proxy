# ADR-0006 更新通道：CI 生成并签名清单，设备只验签

- 状态：**已定**；签名密钥的持有人与存放位置待定（D3）
- 背景：需求要求组件和数据由应用自行管理更新，不依赖 feed 版本。官方 OpenWrt 没有 chinadns-ng，并且需要覆盖多种架构。
  设备端做规则转换和架构判断容易出错，而且出错后只能通过升级 aether-proxy 修复。
- 决定：由 aether-proxy 仓库的 CI 每天转换数据、校验上游摘要、按架构重新打包组件，生成 `manifest.json` 并用 usign 签名，发布到固定 tag 的 Release。
  设备端只负责验签、校验哈希、原子安装和回滚。架构映射也放在清单中。
- 后果：需要维护一条 CI 流水线和一对签名密钥。镜像地址可以不受信任。转换规则的修正不需要升级 aether-proxy。
