# ADR-0007 主机策略用单表模型

- 状态：**已定**（2026-10-14）
- 背景：需求中有 helloworld 的三种访问控制方式，外加「不走代理」「强制代理」「游戏模式」三张名单，名单之间的冲突优先级悬而未决。
- 决定：每台主机一行，`policy ∈ {follow, direct, proxy}` 加上 `udp` 开关；未列出的主机由 `unlisted_policy ∈ {follow, direct}` 决定。
  helloworld 的三种方式都可以用这个模型表达。完全相同的 IP/MAC 出现在两行属于配置错误。目的地例外（用户直连列表）优先于主机策略。
- 后果：结构上不存在名单冲突，不需要优先级规则。MAC 匹配首版即支持。
