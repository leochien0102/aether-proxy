### B27 设备侧三段证据（H28K，2026-11-20 19:18–19:21）

**改之前（`log_level=notice`，936 行 `aether-proxy` 日志里）：**

```text

```

**改成 `debug` + reload 之后（`last_reload.ok=true`，下一个 30 s 监控 tick 起）：**

```text

         chinadns_listening=true node_id=n_a2df6532… node_tcp_ip=20.243.152.198 … proxy_ok=true
         proxy_latency_ms=226 dns_ok=null proxy_reason=healthy dns_reason=disabled]

19:18:51 daemon.debug aether-proxy: CMD_RUN [cmd=curl … https://www.gstatic.com/generate_204 rc=0 ms=329]
19:18:51 daemon.debug aether-proxy: CMD_RUN [cmd=nft -j list counters table inet aetherproxy rc=0 ms=18]
```

**改回 `notice` + reload 之后：** `daemon.debug` 行 0 条（覆盖 19:19:30–19:21:49 近 2.5 分钟，
期间监控 tick 正常跑，`state=running`、`tier=T1`）；回收前的最后一条 debug 是 reload 自身在
级别生效前打出的 `CMD_RUN [cmd=sha256sum …]`（19:19:22）。

三段合起来即 B27 的验收判据：**缺省无 debug 输出 → 改级别后出现 → 改回后消失**，且 reload 成功、
级别在 reload 成功后应用。设备已恢复 `main.log_level=notice`。
