## 4. 直发 Release 与撞墙修复

首次派发 `release-assets.yml`（`44487940271`）在 `check-direct` 失败：

```
Release verification failed: Gate bytes conflict with published package aether-dns-1.0.2-r1_aarch64_generic.apk; bump its package release
```

原因是门禁把未升号的 `chinadns-ng`/`aether-dns` 一起重构建，构建产物与已发布字节不同；而直发路径只做
「同版本字节必须相同」的校验，没有像通道路径那样复用已发布字节。

修复 `f9fb943 🐛 fix(release): reuse published bytes for unchanged packages`：`tools/release/stage.py`
在正式组装阶段先读 `channel-stable` 清单，对版本号未变的包取已发布字节（逐件校验 sha256/size），
再写 `SHA256SUMS` 与 inventory。这正是 M4-17 的语义，`docs/release-checklist.md` 已补说明。

重跑 `release-assets.yml`（`44488145138`）成功，Release 18 件资产、非 draft、非 prerelease。
