## 2. 变动

- 热力图开启时，守护进程启动用 `usage.json` 里当日的累计做基线，同一天内重启（升级、手动重启、崩溃后拉起）
  不再把今日流量清零；SIGHUP 重载不重新播种。
- 修掉一处数据丢失：以前重启后的当日值只剩「重启之后」那段，跨天落盘还会把它写回 `usage.json`，
  使那一天**永久**变小；现在写回「重启前 + 重启后」的完整值。
- 异常退出（`SIGKILL`、断电）仍丢最后一段未落盘流量，属既有设计，未改。

## 7. 设备

两台设备（x86、H28K）当前 `heatmap_enabled=0`，是 2026-11-21 20:00 为保护当天 2 GB 累计而做的临时措施：

- `usage.json` 的 `2026-11-21` 冻结在 `tx=215646491` / `rx=2017970421`；
- 采样与落盘均停（`state.json` 无 `usage_today`，`stats history` 返回 `enabled:false`）。

r8 装上后需要把 `stats.heatmap_enabled` 打回 `1`：新代码会从磁盘那份 2 GB 继续累加，
**当天即可验证**（不必等跨天）：观察 `state.json` 的 `usage_today.tx/rx` 是否 ≥ 磁盘值并且随流量增长。
