# 1.0.0-r1 设备升级验收（H28K，2026-11-11）

**结论**：0.7.0-r1 → 1.0.0-r1 在 H28K 上完成；引擎从日期版 `2026.11.04-1` 迁移到 `aether-dns 1.0.0-r1`；
升级事务按设计跳过引擎前置（已满足），服务只重启一次，配置与数据面未变，设备未重启。

## 前置与发布物

- 发布：tag `v1.0.0-r1` = `59c3f3b`，Release 18 资产（含 `aether-dns` 四包）。
- 通道：`channel-stable` 清单 `aether-proxy 1.0.0-r1`、`aether-dns 1.0.0-r1`（sha256 与 DNS Release 一致）。
- 迁移前置：H28K 原装日期版 `aether-dns 2026.11.04-1`（`Provides: aether-dns-any`），事务会因
  "无精确恢复资产" 返回 `PREREQ_MANUAL_REQUIRED`，故先手工执行
  `opkg install --force-downgrade aether-dns_1.0.0-r1_aarch64_generic.ipk`（sha256 `7b2a2beb…`，与清单一致）。
  普通 0.7.0 设备（未装 aether-dns）不需要这一步：`opkg status` 对未安装包返回 0 且无 `Status:` 行，
  事务按首装处理。
