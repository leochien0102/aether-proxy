## 4. 设备验收

本轮按用户安排，跳过本地试用包构建，直接发版后由维护者在 **x86** 上在线更新观察：

```sh
aether-proxy update check          # 应显示 aether-proxy 1.2.2-r3
aether-proxy update package aether-proxy
# 重启服务，让新收集器接管
/etc/init.d/aether-proxy restart
raw=/var/run/aether-proxy/raw.log
grep -c dnl_init "$raw"; grep -c on_start "$raw"
aether-proxy log stats; sleep 10; aether-proxy log stats
```

期望：`dnl_init > 0` 且 `on_start` 整串出现（不再只剩一行 `local listen addr`）；
两次 `log stats` 的 `ACCEPTED` 在会话进行中即增长。结果回填到本节。
