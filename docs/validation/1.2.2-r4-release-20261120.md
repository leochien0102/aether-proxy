## 4. 设备验收（x86 在线更新，维护者执行）

```sh

/etc/init.d/aether-proxy restart
raw=/var/run/aether-proxy/raw.log
grep -c 'startup: .* info lines suppressed' "$raw"     # ≥1
grep -c 'local listen addr' "$raw"                      # ≥1
grep 'I \[main\.zig' "$raw" | grep -vc 'local listen addr'   # 应为 0
```
