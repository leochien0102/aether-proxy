# aether-proxy 0.6.3-r1

安全更新版本，**建议所有 0.6.2 用户升级**：

- 托管核心 `aether-xray` 升级到 **26.10.31**。上游因 Linux IPv4 MPTCP 监听漏洞撤回 26.10.29；26.10.31 默认关闭 MPTCP 以减少攻击面。
- 保留 0.6.2 的 SOCKS5/HTTP/WireGuard/Hysteria2 出站与 `aether-xray`/`chinadns-ng` 单源发布。
- 概览页延迟文字分级：≤200ms「正常」、201–800ms「偏高」、>800ms「过高」。
- `chinadns-ng` 仍是手工更新组件；aether-xray 与 chinadns-ng 都随本 Release 提供双架构 ipk/apk。

## 升级

更新页会看到 `aether-xray` 26.10.31；请及时更新。`/usr/bin/xray` 仍由 feeds/ssr-plus 的 patched 包维护，本应用不覆盖它。
