# 1.3.1-r1

发布日期：2026-11-26

## 主要变化

- 高级设置新增局域网显式代理。SOCKS5 和 HTTP 可分别启用、分别设置端口，共用一组用户名和密码；客户端使用页面显示的 LAN IPv4 地址连接。HTTP 代理支持通过 CONNECT 访问 HTTPS 站点，不是到代理本身的 TLS 连接。
- 节点列表按 TCP 探测延迟分色，方便比较节点；概览页仍按当前节点的健康状态显示颜色。

## 升级须知

- 两种代理默认关闭，不自动放行防火墙。按需启用，仅向受信任的局域网设备提供地址和凭据；能查看 LuCI 待应用更改的管理员也可能看到暂存的密码。
- 从 1.3.0-r1 可在线升级。本次不升级 DNS 引擎或 Xray，未升版本的组件复用已发布的包。
