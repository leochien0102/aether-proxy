# aether-proxy 1.2.2-r5

补丁版：**1.2.2-r5**。修回 r4 里被一并压掉的 `dnl_init tag:` 加载规模行。核心版本仍为 1.2.2，
支持窗口为 **1.2.2 + 1.2.1**。

## 修回：`dnl_init tag:` 应当保留

- r4 的抑制规则里，例外正则把 `tag:` 后面多写了一个空格，而 chinadns-ng 的实际输出是
  `I [dnl.c:534 dnl_init] tag:chn loaded:109671 added:109626 cost:2212.789k`（`tag:` 后直接跟名字），
  导致这几行被当成普通明细压掉，`grep -c 'dnl_init tag:' raw.log` 为 0。
- 现在例外改成 `^I \[dnl\.c:[0-9]+ dnl_init\] tag:`：每个 tag 一行加载规模会保留，
  无 `tag:` 的 `L2 items:…` / `L1 items:…` 等明细仍被抑制。

## 升级说明

- 同版本核心的补丁版，配置无需迁移；`uci export aetherproxy` 升级前后保持一致。
- 旧版写入的 `raw.log` 里被误压的明细不会回填，验收请只看升级并重启服务后的新启动时间窗。
- 升级后重启一次服务：`/etc/init.d/aether-proxy restart`。
