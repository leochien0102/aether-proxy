# aether-proxy 1.2.0-r2

修订版：**1.2.0-r2**。只修热力图「当天那格要重启才更新」的体验问题，其余与 1.2.0-r1 相同。
核心版本不变（仍是 1.2.0），支持窗口仍为 **1.2.0 + 1.1.3**。

## 当天数据实时可见（T16.8）

- 现象：`usage.json` 只在跨天或服务干净停止时写，而页面只读这个文件，所以当天那格在重启前一直是
  0 或空。
- 修法：不再增加闪存写入，而是把当天累积挂到 daemon 本来就每轮发布的**内存快照** `state.json`
  （`/var/run`，tmpfs）：
  - monitor 每个 tick 写入 `usage_today: {date, tx, rx, observed, healthy, at}`（热力图关闭时不写）；
  - `stats history` / rpcd `stats_history` 读完 `usage.json` 后，用 600 秒内的当天快照**覆盖**该日条目；
  - 概览页热力图的 history 刷新间隔由 10 分钟降到 **60 秒**（仍是"最多一个请求在飞"，不新增轮询）。
- 效果：今天那格在 **30–60 秒**内随流量变化，颜色与 tooltip 同步更新。
- 不变项：`usage.json` 的格式与写入时机**完全没动**（只在跨天与干净停止写），闪存写入次数不变；
  异常掉电仍最多丢失当天数据；daemon 未运行时退回只读文件的行为。
- 真机验证（H28K，1.2.0-r1 + 本地构建）：75 秒内当天条目 `tx` 334,210 → 679,563、
  `observed` 65 → 135，`usage.json` mtime 未变。

## 迁移要求

- 支持窗口不变：**1.2.0 + 1.1.3**；`1.1.2` 及更早仍为 manual-only。
- 从 1.2.0-r1 直升即可，无配置迁移、无契约变化；热力图开关与额度设置保留。

## 发布边界

资产由门禁 CI 构建，正式发布复用同一批产物（RC 不重建）。`aether-xray` / `aether-dns` /
`chinadns-ng` 版本未变，按通道规则复用已发布字节。
