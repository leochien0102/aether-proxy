# aether-proxy 1.1.1-r1

后端与 LuCI 同步为 **1.1.1-r1**；本版是 UI 修复补丁版，不引入新功能。
以下仅列出相对 [1.1.0-r1](1.1.0-r1.md) 的增量与迁移边界。

## 补充端口常显（M4-12）

- 高级页「补充端口」字段始终可见；仅在端口范围为「常用 + 补充端口」（`common_extra`）时可编辑并生效。
- 其它档位下字段置灰并显示提示，保留已填写的值；常显不表示这些值在其它档位生效。
  原有端口范围语义不变，范围限制仍仅作用于 TCP。

## 兼容测试（M4-11）

- 冻结页面/RPC 快照已换为已发布的 **1.1.0-r1**，用于验证旧页面与当前后端的兼容性。
  这是测试项，不影响运行时，不赋予旧客户端新的更新能力；本次升版不再更换快照。

## 迁移要求

支持窗口滚动为 **1.1.1-r1 + 1.1.0-r1**，两者路径均为 `direct`，契约已知包相同：
四个 `UPDATE_PACKAGES` 加 `aether-dns`（由引擎前置事务管理，不加入更新页主列表）。
1.0.0 移出窗口，和 0.7.0、0.6.3 及更早版本一样为 **manual-only**。
0.6.3 存量设备仍须按 [更新文档](../08-updates.md) 手工迁移并满足依赖，不承诺直升 1.1.1。

固件包版本后缀 `-1` 与通道版本后缀 `-r1` 在更新器的版本比较中等价；
不改变资产完整性校验或引擎替换前必须准备精确恢复资产的要求。

## 发布边界

本次只做升版与发布准备，**不构建、不打 tag、不推送、不发布**，未进行 1.1.1 真机验证。
不改产品代码、更新链格式或依赖；`aether-dns` 仍由 DNS 仓库 CI 唯一构建，channel 按 pin 校验、签名并分发。
宿主机测试不替代固件安装或真机验收，不据此声明未经验证的平台或更新路径可用。
