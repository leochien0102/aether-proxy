# 1.3.1-r3

发布日期：2026-11-27

## 主要变化

- 局域网 SOCKS5 与 HTTP 显式代理共用一个认证开关。开启时必须同时填写用户名和密码；关闭时可保留整组凭据，但连接不再检查凭据。
- 「清空凭据」只清空当前表单，不会自动关闭认证或立即删除已保存的内容。要删除共享及旧版凭据，请关闭认证、清空并成功保存；取消或保存失败不会删除凭据。

## 升级须知

- **关闭认证时，任何能连到监听端口的客户端都可以使用代理。** 两种监听默认关闭，防火墙不会自动放行；启用前请确认端口只对预期客户端可达。
- 从 1.3.1-r2 升级后，已有凭据的旧配置不会因缺少新开关而自动开放。凭据不完整或存在冲突时，请核对后再保存；新配置的认证默认关闭。本次不升级 DNS 引擎或 Xray。
