# aether-proxy 0.6.3-r7

本版集中改进 DNS 启动顺序与 init restart 交接：

- restart 预先保留 DNS handoff，避免该受保护路径在重建期间回落系统 resolver。
- 节点域名通过隔离 bootstrap 和显式查询解析，保持 DNS 优先、失败再用 LKG；确认私有实例退出后才继续启动。
- Xray 按实际 DNS 引用检查进程归属、socket 与协议；适用内核优先被动验证双栈，减少 readiness 探测引起的 loopback 日志。
- 停止钩子错误对调用者可见，cleanup 错误优先保留；恢复 restart 的 TERM 屏蔽/恢复语义。
- 补齐新增启动失败步骤的日志中译，保留未知步骤诊断与历史日志兼容。
- 修复 schedule 和双协议测试上游夹具，保留原业务断言。

保护范围不扩大到普通 opkg stop/start 升级、首次接管或无既存 intent 的 daemon respawn；不承诺零中断，也不保证文件系统不可写时仍能持久停用。TPROXY 就绪门仍仅检查 TCP，DNS 按实际引用协议检查。

后端功能代码已在同源本地候选包中通过 H28K 的正常 restart、stop/start 和恢复观察，设备未重启、配置未变；日志译名补漏另通过完整 LuCI/i18n 检查。正式资产由 CI 构建和检查，不把本地候选包当作本次发布资产。

后端与 LuCI 同步为 0.6.3-r7，依赖与安装路径不变，仍使用独立 aether-xray、chinadns-ng；本版不新增 aether-dns 发布包。支持窗口内用户可通过更新页升级，旧 0.3.1 设备仍需全量固件迁移。
