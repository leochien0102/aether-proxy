# aether-proxy 1.1.3-r1

后端与 LuCI 同步为 **1.1.3-r1**；本版统一组件版本展示，并把 aether-dns 的包定义收成单一来源。

## 组件版本（M4-19）

- 概览页「组件版本」显示**已安装包的版本**（`<ver>-r<n>`，与 opkg/apk 一致），
  不再只显示二进制自报的核心版本；`components --json` 同时给出 `installed`、`banner` 与 `mismatch`。
- 已装包版本与二进制自报核心不一致时，版本旁显示 ⚠，标题说明「二进制版本与已安装包不一致」。
- 版本比较语义不变：`-rN` 不参与排序，仅用于展示与相等判断。

## aether-dns 单一来源（M4-20 / C1）

- aether-dns 的包定义移到本仓库的 `aether-dns/Makefile`：按架构下载 DNS Release 的裸二进制
  （sha256 钉在 Makefile 中）后打包，无 Rust 编译、无 libc 依赖。
- 固件 feed 与发布通道使用同一份包定义；通道不再 staging DNS 的 ipk/apk，也不再需要单独的 DNS 钉版。
- DNS 仓库的 Release 只服务人工下载（ipk/apk 与裸二进制）。

## 迁移要求

支持窗口滚动为 **1.1.3-r1 + 1.1.2-r1**，两者路径均为 `direct`，契约已知包相同：
四个 `UPDATE_PACKAGES` 加 `aether-dns`。1.1.1 及更早移出窗口，为 **manual-only**。
0.6.3 存量设备仍须按 [更新文档](../08-updates.md) 手工迁移。

固件包版本后缀 `-1` 与通道版本后缀 `-r1` 在更新器中等价；本版起组件页统一显示 `-rN`。

## 发布边界

资产由门禁 CI 构建，正式发布复用同一批产物（RC 不重建）。`aether-dns` 的二进制由 DNS 仓库构建，
本仓库只负责打包；通道签名清单，设备只信任签名清单。
