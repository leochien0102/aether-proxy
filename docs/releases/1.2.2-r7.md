# 1.2.2-r7

发布日期：2026-11-21

## 变化

- **概览页的「启用」提示按节点状态分档**。服务未启用时，横幅不再一律让人打开开关，而是说清当前缺什么：
  - 还没有节点：「还没有节点：先在『节点与订阅』添加订阅或导入分享链接，然后启用服务」，并给出
    「打开节点与订阅」入口；
  - 有节点但没有选中并应用：「已有 N 个节点：请先选择一个节点并应用，再启用服务」，同样带入口；
  - 已选中并应用：「服务未启用：打开『启用』开关后会自动启动」，不带入口。
  前两档的禁用开关悬停提示与横幅同源，不再出现「开关点不动、文案却让人去点」的矛盾。
- 开关何时可用没有变化：仍然要求已有当前节点，`enabled=1` 时不显示这条横幅。

## 升级说明

设备从上一版升级时会由应用自身更新器完成三包替换；`uci` 配置不需要迁移。

## 发布边界

- `aether-xray` / `aether-dns` / `chinadns-ng` 若未升版本号，Release 与通道复用上一版已发布字节（M4-17）。
