# 1.2.2-r9

发布日期：2026-11-21

## 变化

- **运行中打开热力图时，今日累计不再从零开始。** 以前只有在「进程启动时开关已经是开的」那一刻才会读取
  `usage.json` 的当日累计；升级后再去界面打开开关，走的是重载，采样从零起算，热力图的今天会掉回零头。
  现在开关从关变开时的第一个采样点会补做一次种子，接着磁盘上的累计继续往上加。
- 开关关着的时候不读盘、不采样、不落盘；已经采样中的进程重载不会重复播种。
- 补上了上一版（1.2.2-r8）遗留的这条路径，其余行为与 r8 相同。

## 升级说明

设备从上一版升级时会由应用自身更新器完成三包替换；`uci` 配置不需要迁移。

## 发布边界

- `aether-xray` / `aether-dns` / `chinadns-ng` 若未升版本号，Release 与通道复用上一版已发布字节（M4-17）。
