# aether-proxy 1.2.1-r1

正式版：**1.2.1-r1**。核心版本升到 1.2.1：新增**节点自动切换**（默认关闭）、日志页的
**页级工具栏与「截断到上次启动」**，并按统一块结构重做了订阅/节点/概览/日志等页面；
同时修掉两处会让功能静默失效的判定错误。支持窗口为 **1.2.1 + 1.2.0**。

## 节点自动切换（默认关闭）

- 开关在「节点与订阅 → 通用设置 → 自动切换」，默认**关**；说明文字常显，旁边有黄色 ⚠
  图标，悬停或点击（移动端可点）显示风险提示：频繁切换出口 IP 可能触发部分站点/应用的风控。
- 参与方式是**显式名单**（`main.failover_nodes`），不是「每个节点一个状态位」：
  - 订阅行的三态控件：全选 = 实心勾，部分选中 = 短横 + `8/10` 计数，全不选 = 空框；
  - 节点行是两态开关，勾上即加入名单；切换立即在页面内重绘，保存仍走页脚。
- 触发条件：当前节点连续 **3 次** TCP 探测失败（`node_reachable`，3 秒超时）→ 按 UCI 里的
  节点顺序找第一个可达的名单内节点 → 用既有 reload 事务切换运行时节点。
  `main.node` **不会被改写**，重启后回到 UCI 里选定的节点。
- 保护：切换后 **10 分钟**冷却；同一候选 **30 分钟**内不重试；手动切换后 10 分钟内不自动切；
  不自动切回原节点；候选全部不可达时记 `NODE_FAILOVER_FAILED` 并静默 10 分钟。
- 事件：`NODE_FAILOVER`（通知，含 from/to/ip/reason）、`NODE_FAILOVER_FAILED`（警告）；
  `node-probe.log` 会追加 `action=failover` 的一行，便于事后核对。
- 当前节点不在名单里时，自动切换等同于**关闭**（不探测、不切换），页面上会用一行灰字说明原因。

真机验证（H28K，`nft` 表头插入丢包规则模拟出口被黑洞）：约 **111 秒**后触发
`NODE_FAILOVER`（JP-Pitlane-X → SG-Pitlane-V），`state.json` 的 `node_ip` 随切换更新、
`main.node` 保持原值；名单只放 JP + HK 时正确跳过可达的 SG，切到 HK。

## 日志页

- 「清空日志」「截断到上次启动」提到**页级工具栏**，事件页与原始日志页都能用；两个按钮互斥禁用，
  确认弹窗写明影响范围。
- **截断到上次启动**保留的是「本次进程启动至今」：标记取 `state.json` 的 `started_at`，
  旧状态文件退回 `since`，都没有则报 `NOT_RUNNING`。本次修掉了 `started_at` 晚于组件启动
  5–10 秒的问题（此前会把本次启动的 `listening TCP …`、`Xray … started` 一并删掉）。
- 标签条改用主题原生的 `cbi-tabmenu`，与高级页一致；Bootstrap 深色下不再把「原始日志」截成「原始…」。

## 界面

- 订阅/节点页统一成「块」结构：标题 → 说明 → 右对齐工具行 → 主体；「全部更新/添加」「检测全部/
  添加节点」都在自己的块内，不再漂在块外。
- 节点表：删掉与当前节点重复的「适用」列，当前节点在名称前显示**绿色圆点**（带呼吸动画，
  `prefers-reduced-motion` 下关闭）；多选删除保留；「启用」列只在确实存在停用节点时出现。
- 订阅地址**默认遮蔽**（`https://host/…`），点击整格或按 Enter/Space 才显示完整 URL，
  再点或重绘即恢复遮蔽；不写入 UCI 或 localStorage，避免截图泄露订阅 token。
- 概览页恢复原来的页头控制（启用、自动刷新、刷新/启动/重启/停止）与状态行布局；
  端口范围的说明气泡抽成 `ap.hint_icon()`，与自动切换的 ⚠ 共用同一套交互。
- 更新页的组件表补上「组件更新」标题，把「如需安装其他版本」的完整说明放进块说明，
  「上次检查 … — … 检查更新」回到同一行。
- 托盘/窄屏：表格统一为容器内横向滚动；块级标题不再与页级标题重复。

## 修复

- **非阻塞 connect 就绪判定**：`socket.poll()` 在超时时也会返回「被轮询 fd 的数组」且 `revents = 0`，
  旧实现只看 `SO_ERROR`，把超时误判为可达——出口 IP 被黑洞时自动切换与切换前探测都不会触发。
  现在要求 `revents != 0` 且 `SO_ERROR == 0`。
- **节点 IP 可达性**：切换节点 IP 前先做 TCP 探测，不可达则记 `NODE_IP_UNREACHABLE` 并保持现状；
  LKG 只在真正应用成功后才写，避免把不可达地址当成"上次可用"。
- `state.json` 的 `started_at` 与 `since` 语义分开：前者是守护进程启动时刻，后者是最后一次状态迁移。

## 迁移要求

- 支持窗口：**1.2.1 + 1.2.0**；`1.1.3` 及更早转为 **manual-only**（不再承诺通道直升）。
- 从 1.2.0-r4 直升即可，无配置迁移：新字段 `sub.failover`、`main.failover_nodes` 缺省都不写入，
  自动切换默认关闭；订阅/节点/热力图/额度/日志格式均不变。
- 手动节点在总开关打开后需要显式加入名单才会参与自动切换。

## 发布边界

资产由门禁 CI 构建，正式发布复用同一批产物（RC 不重建）。`aether-xray` / `aether-dns` /
`chinadns-ng` 版本未变，按通道规则复用已发布字节；apk 资产按规范命名（不带架构后缀）。
