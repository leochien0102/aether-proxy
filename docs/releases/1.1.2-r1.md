# aether-proxy 1.1.2-r1

后端与 LuCI 同步为 **1.1.2-r1**；本版是 UI 与发布流程的补丁版，不引入运行时新功能。

## 端口范围提示（M4-16）

- 概览页「端口范围」后新增信息图标；悬停、点按或键盘聚焦显示「只影响 TCP；UDP 始终按原策略代理。」。
- 高级页「补充端口」说明去掉重复：可编辑时只讲格式（1–65535、去重后最多 64 项）；
  置灰时显示当前档位与切换目标（「当前端口范围为『…』，切换到『常用 + 补充端口』后生效」）。

## 发布流程（M4-15）

- 正式资产改为复用门禁构建的同一批产物：RC 不再重新编译，promote 只校验与发布；
  每个 commit 只构建一次，发布的字节与被 smoke 验证的字节一致。
- 门禁产物保留 90 天；没有成功的门禁运行或产物过期时，RC 失败并提示先跑门禁，不静默重建。

## 迁移要求

支持窗口滚动为 **1.1.2-r1 + 1.1.1-r1**，两者路径均为 `direct`，契约已知包相同：
四个 `UPDATE_PACKAGES` 加 `aether-dns`（由引擎前置事务管理）。
1.1.0 及更早（0.7.0、0.6.3、0.6.2、0.3.1）均移出窗口，为 **manual-only**，不承诺通道直升。

固件包版本后缀 `-1` 与通道版本后缀 `-r1` 在更新器的版本比较中等价；
不改变资产完整性校验或引擎替换前必须准备精确恢复资产的要求。

## 发布边界

正式 proxy 资产由门禁 CI 构建、RC 原样复用；`aether-dns` 仍由 DNS 仓库 CI 唯一构建，
channel 按 pin 校验、签名并分发。发布说明按 tag 去掉 `v` 命名为 `1.1.2-r1.md`。
