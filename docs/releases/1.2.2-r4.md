# aether-proxy 1.2.2-r4

补丁版：**1.2.2-r4**。把 x86 上 `chinadns-ng` 启动时刷屏的配置明细从原始日志里收敛掉，
并顺手去掉颜色码与自带时间戳。核心版本仍为 1.2.2，支持窗口为 **1.2.2 + 1.2.1**。

## 原始日志：启动只留有用的

- 背景：r3 修好启动 burst 丢失后，`raw.log` 里一次启动会出现约 30 行 `chinadns-ng` 的
  `I [main.zig:…]` / `I [dnl.c:…]` / `I [groups.zig:…]` 配置明细，同一条消息还会以
  「纯文本」与「带 ANSI 颜色 + 自带时间戳」两种形态各出现一次。
- 现在：这类明细不再写入 `raw.log`，一次启动通常只剩 6 行左右。保留的是——
  `local listen addr`（启动完成）、每个 `dnl_init tag:… loaded:…`（规则规模）、
  以及所有 `W [` / `E [` / `[Warning]` / `[Error]` / 含 `failed` 的行。
- 压掉了多少行不会悄悄消失：下一次写入前（或读取结束时）会补一行
  `aether-proxy: chinadns-ng startup: N info lines suppressed`。
- 写入前统一去掉 ANSI 颜色码与 `chinadns-ng` 自带的时间戳，`raw.log` 里不再出现 `[32;1m`。
- Xray 的日志、事件流、限流与轮转规则均未改动。

## 升级说明

- 同版本核心的补丁版，配置无需迁移；`uci export aetherproxy` 升级前后保持一致。
- 升级后重启一次服务让新收集器接管：`/etc/init.d/aether-proxy restart`。
- 若你依赖 `raw.log` 里的 `dnl_init` / `on_start` 明细做排查，请改用 `logread -e aether-proxy`
  读取未过滤的环形缓冲（那里仍保留全部原始行）。
