# aether-proxy 1.2.2-r3

补丁版：**1.2.2-r3**。修掉原始日志收集器在 BusyBox awk 下「写完第一行就退出」的缺陷，
并让子进程日志计数在会话进行中就能读到。核心版本仍为 1.2.2，支持窗口为 **1.2.2 + 1.2.1**。

## 原始日志：启动那一串不再只剩一行

- 根因：BusyBox awk 的 `fflush()` 会刷新但不设置返回值，而收集器用 `fflush("raw.log") != 0`
  判断失败，于是**成功写完第一行后误判为出错并退出**；收集器随后重连，重连前的那串启动日志全部丢失。
  在 x86 上跑 `chinadns-ng` 时最明显——每次启动只剩一行 `local listen addr`，`dnl_init` / `on_start` 全不见。
- 修复：不再判断 `fflush()` 的返回值；跟随会话是否真的挂上改用「syslog 探针回执或真实应用实时行」
  确认，确认后写 `<run-dir>/raw-log.ready`。
- 守护进程在拉起 xray / DNS 之前最多等 2 秒这个回执；超时只记一条告警并继续启动，
  不阻塞、不回放历史、重连时也不重复写旧行。

## 计数在会话进行中就能读

- `logfilter.awk` 原来只在「第一条放行」和「会话结束」时写 `.logstats`，长时间运行的会话里
  `aether-proxy log stats` 的 `ACCEPTED` 会一直停在 1。
- 现在放行的同时检查「距上次写入 ≥5 秒」或「新增 ≥50 条」，任一达到就刷新；丢弃计数变化与摘要仍立即写。
- 限流阈值（20 行/秒、120 行/分）、轮转规则与 `log stats` 输出格式均不变。

## 升级说明

- 同版本核心的补丁版，配置无需迁移；`uci export aetherproxy` 升级前后保持一致。
- 从 1.2.2-r2 升级只替换 `aether-proxy`（LuCI 侧本次无改动，版本号随发布统一为 1.2.2-r3）。
- 升级后建议重启一次服务，让新的收集器接管：`/etc/init.d/aether-proxy restart`。
