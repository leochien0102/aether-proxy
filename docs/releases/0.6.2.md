# aether-proxy 0.6.2-r1

0.6.2 小版本，包含：

- SOCKS5、HTTP、WireGuard、Hysteria2 出站（均为手工节点；分享链接导入仍待后续）。
- 概览页与节点&订阅页延迟分级颜色：≤200ms 绿、201–800ms 黄、>800ms 红。
- 托管核心 `aether-xray` 保持 26.10.29（纯上游、无补丁，安装 `/usr/bin/aether-xray`）。
- `chinadns-ng` 包源迁入 aether-proxy 仓库，应用显式依赖它；仍为手工更新组件，不进入更新页。
- aether-xray 与 chinadns-ng 都是独立 ipk/apk，和 aether-proxy、LuCI、i18n 一起发布到本 Release 和 channel-stable。

## 首次安装

先按架构安装 `aether-xray` 与 `chinadns-ng`，再安装 aether-proxy、LuCI 和中文翻译：

```sh
opkg install aether-xray_26.10.29-r1_<arch>.ipk \
             chinadns-ng_2025.08.09-r1_<arch>.ipk \
             aether-proxy_0.6.2-r1_all.ipk \
             luci-app-aether-proxy_0.6.2-r1_all.ipk \
             luci-i18n-aether-proxy-zh-cn_<ver>_all.ipk
```

`<arch>` 为 `aarch64_generic` 或 `x86_64`；25.12 使用对应 `.apk`，不要混用格式。

## 升级

更新页仍从签名通道 `channel-stable` 更新；本 Release 的包与通道产物同源、同 hash。
