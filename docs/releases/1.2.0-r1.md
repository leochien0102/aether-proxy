# aether-proxy 1.2.0-r1

后端与 LuCI 同步为 **1.2.0-r1**。本版新增**实验性**的「流量与连接」热力图（默认关闭），
后端首次引入按天的用量历史；其余行为与 1.1.3-r1 一致。

## 概览页热力图（B25，实验性，默认关闭）

- 在概览页「流量与连接」块内左右分栏：左侧 90 天日历网格（5 行 × 18 列），右侧保留原有
  实时流量与连接信息。
- 颜色编码**当月额度占比**：`r = 当日代理流量 ÷ (月额度 ÷ 该日期所在月天数)`，冷→暖五档 +
  两个中性档；**红色只用于达到/超过日均额度**。未设额度时按窗口内**分位数**分四档着色，
  不出现红色。
- 概览页顶部提供「月额度」控件：不限 / 50 / 100 / 200 / 500 GB / 1 TB / 自定义（在同一控件内
  直接填 GB 数，回车或失焦生效，Esc 回退）。
- tooltip 内容：日期、代理流量、健康占比（含观测秒数）、观测时长、占日均额度百分比。
- **开关在高级设置 →「实验性功能」标签页**（本版首个实验功能），默认关闭；关闭时不采样、
  不写历史、概览页与 1.1.3 完全一致。

## 用量历史与命令行

- 新增 `usage.json`（`/etc/aether-proxy/usage.json`，0600、原子写、保留 90 个本地日期）：
  monitor 在开启时按轮采样 nft 代理计数器，跨天与服务干净停止时落盘；当天数据只在内存，
  异常掉电最多丢失当天。
- 新命令 `aether-proxy stats history [--days N] [--json]`（只读）与 rpcd `stats_history`
  （read）；`stats quota` / `stats quota set <值>` / `stats quota clear` 与 rpcd `stats_quota`（write）。
  额度为十进制字节（`100G` = 100 GB，1 GB–100000 GB），不写入 UCI、不触发服务重载。

## 迁移要求

支持窗口滚动为 **1.2.0-r1 + 1.1.3-r1**，两者路径均为 `direct`，契约已知包相同：
四个 `UPDATE_PACKAGES` 加 `aether-dns`。**1.1.2 起滑出窗口，为 manual-only**；更早版本同样
manual-only，存量设备按 [更新文档](../08-updates.md) 手工迁移。

升级后热力图默认关闭，不会自动开启；开启后才开始记录，历史不做回填。打开热力图后当天数据
需要一次跨天或服务干净停止（重启一次即可）才出现在网格里。

## 发布边界

资产由门禁 CI 构建，正式发布复用同一批产物（RC 不重建）。`aether-xray` 与 `aether-dns`
本版未变更版本，按通道规则复用已发布字节；通道只更新签名清单，设备只信任签名清单。
