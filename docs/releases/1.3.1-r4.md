# 1.3.1-r4

发布日期：2026-11-27

## 变化

- 修好「改完配置后第一次重启」偶发的一次假失败：以前会先报一条
  `CMD_FAILED … timer exited early (status 1)` 与 `START_FAILED step=render`，再等 30 秒自动重试；
  现在同样的重启一次成功，不再出现这两条事件。
- 旧配置代目录已经不存在时，发布步骤直接视为清理完成，不再白跑一次 `rm` 并可能被它的收尾状态拖住。
- 真超时、命令自身非 0、握手帧真的损坏，仍然分别报 124、原退出码、-1——判定没有放宽。

## 升级说明

设备从上一版升级时会由应用自身更新器完成三包替换；`uci` 配置不需要迁移。

## 发布边界

- `aether-xray` / `aether-dns` / `chinadns-ng` 若未升版本号，Release 与通道复用上一版已发布字节（M4-17）。
