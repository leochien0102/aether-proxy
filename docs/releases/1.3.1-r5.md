# 1.3.1-r5

发布日期：2026-11-27

## 主要变化

- 更新应用或重载 rpcd 后，本应用旧源码的文件描述符不再逐次累积。修复不关闭正在使用的描述符，不重启 rpcd，不要求重新登录 LuCI，也不处理其他插件打开的文件。
- 更新页只在「更新策略」中展示通道地址。默认地址可以选中复制，留空仍使用内置通道；「组件更新」状态行不再提供重复的下载目录链接。

## 升级须知

- 后端现在包含原生模块，请使用与设备架构相符的包。使用 r4 页面在线更新时由更新器选择架构；LuCI 界面与中文包仍不区分架构。现有 UCI 配置无需迁移。
- 若 rpcd 的文件描述符软上限低于 2048，模块会适度提高它，但不会超过现有硬上限，也不会调低既有上限。已经耗尽文件描述符的旧进程能否完成首次在线升级，不在手工试用验证的保证范围内。

## 发布边界

- 仅应用和界面更新。未升版本的独立引擎复用已发布字节；本次不单独发布 DNS 引擎。
