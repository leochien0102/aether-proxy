# 1.3.0-r1

状态：未发布

## 主要变化

- 概览页的节点、默认模式和端口范围在一次应用中生效，只重载一次，不再一并提交其他页面尚未应用的设置；失败时仅针对本次修改项尝试恢复。
- 修复热力图流量落盘与额度修改互相覆盖的问题，停服务、停用热力图或跨日遇到写入竞争时保留待写数据并重试；同时修正刷机备份清单的账本路径，保留配置刷机时可正确收录账本。
- 节点导入兼容 VLESS、Trojan 链接的 tcp/raw 等价写法和地址后的单个空路径斜杠；VMess gRPC 链接不再丢失显式填写的服务名和多路模式。
- 订阅与节点导入增加规模和异常字符检查，避免超大订阅或异常链接占用过多资源、把控制字符带入节点配置。
- 在线更新能正确识别 APK 已安装的 DNS 引擎能力；后端版本恰好等于兼容链终点时，更新器仍会升级本机已安装但落后的页面包和翻译包，不会补装未安装的包，需要升级却没有适用安装包时会明确报错；已完成的安装或回滚结果不再被随后到期的时间预算覆盖。
- DNS 重载、回滚及级别切换会等待目标进程真正监听后再继续，避免过早报告切换成功；同一路径替换 DNS 二进制后也能在重载时识别变化。
- 当前节点域名解析出的 IP 更新失败时，会恢复原有转发规则与 Xray 配置，并保留动态分流集合，避免只更新了一半。
- 服务启停与重载更可靠：避免重复守护进程和重载、清理互相抢占，Xray 重启中收到停止请求也会停止，不再继续拉起服务。
- 更新下载及其跳转只允许 HTTP 或 HTTPS，规则数据解压增加大小限制；外部命令的输出文件改为私有隔离，超时与计时进程清理更可靠。
- 更新页将错误按纯文本显示、仅提供有效的 HTTP 或 HTTPS 通道链接；安装页面包时会清理 LuCI 框架缓存，并补齐启动和重载失败步骤的中文提示。

## 升级须知

- 使用 aether-dns 且 DNS 上游配置含 tls:// 时，升级前请把国内上游以及已启用的直连境外上游改为受支持的非 TLS 上游，或选用支持该配置的 ChinaDNS-NG；新预检会在启动或重载前明确拒绝不兼容配置，不会自动降级协议。
- 单份订阅最多允许 1024 个解析有效的候选节点，重复节点在去重前也计数；超限会使该份订阅整体更新失败并保留原节点，不会截取前 1024 条。超大聚合订阅请先在订阅源端筛选或拆分。
- 单条分享链接按字节计最多 16 KiB，控制字符也会导致拒绝；订阅会跳过非法行，全无有效节点时更新失败并保留原配置。自行生成链接时请先修正异常字段；此上限不是整份订阅的大小，LuCI 导入入口仍有原有的更小请求限制。
- 自定义更新源须使用 HTTP 或 HTTPS，且每项规则解压后不得超过 8 MiB；不符合时该项更新失败，不替换旧规则，请先调整源地址或规则文件。
