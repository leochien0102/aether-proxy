# 1.2.2-r8

发布日期：2026-11-21

## 变化

- **同一天内重启（升级、手动重启、崩溃后被拉起）不再清零今日流量。** 热力图开启时，守护进程启动会用
  `usage.json` 里当日的累计做基线继续累加；本轮第一笔可读的 nft 采样仍然只建立基线，不会把历史再算一遍。
- 修正了一处数据丢失：以前重启后的当日值只有「重启之后」那一段，跨天落盘时还会把这段零头写回
  `usage.json`，让那一天的累计**永久**变小。现在跨天写回的是「重启前 + 重启后」的完整值。
- SIGHUP 重载不会重新播种，重载前后口径一致。
- 异常退出（`SIGKILL`、断电）仍会丢掉最后一段还没落盘的流量，这是既有设计，未改。

## 升级说明

设备从上一版升级时会由应用自身更新器完成三包替换；`uci` 配置不需要迁移。

## 已知影响

- 历史上发生过「当天升级」的日期，其累计值当时已被写小，无法恢复；本次修复只保证今后不再发生。
