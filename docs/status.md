## 2. 已完成的能力

- **节点与订阅**：多订阅（通用设置 + 单订阅覆盖）、节点导入（分享链接/URI/新协议）、拖动排序、
  当前节点绿点、订阅地址默认遮蔽点击显示、自动切换**显式名单**（默认关，三态控件 + 未生效提示）。
- **节点健壮性**：切换前 TCP 可达性校验（T16.12）、解析取证与坏候选退避（T16.14）、
  LKG 只存已验证地址（T16.15）、静默丢包不再被误判为可达（T16.20）、运行期自动切换（T16.17/T16.21）。
- **日志**：页级工具栏（清空 / 截断到上次启动）、事件与原始日志双标签、启动 burst 不丢、
  丢弃摘要即时且带 `first:`、`aether-proxy log stats` 自检、chinadns-ng 启动噪音收敛、
  相邻重复折叠（T16.40，已合并、**尚未随版本发布**）。
- **界面**：全站块结构统一（`ap.section`）、自动切换三态控件、⚠ 风险提示与端口范围同款气泡、
  块内自洽（说明/工具行/表格同块）、窄屏统一容器内横滚。
- **更新**：正式通道 + 组件更新块（状态行、`Channel address` 链接）、一起更新/回滚、
  兼容契约与 `manual-only` 窗口、channel 清单验签。
- **数据面**：端口范围三档（B26，`port_scope` + `extra_ports`）、节点不健康时降级为仅被墙（B19，前后端均已落地）、
  热力图（额度版，实验开关）。
