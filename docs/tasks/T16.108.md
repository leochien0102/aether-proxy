# T16.108 本机显式入站：重载成功须以真实监听就绪为准

单一目标：在真实 daemon/reload 事务中，已启用的显式 SOCKS5/HTTP 端口必须由本代 Xray 在配置的 loopback 地址实际监听，才发布重载成功。不允许另一个进程恰好监听该端口就算就绪。复用既有有界 readiness/回滚路径，优先检查是否已满足；若已满足，只补回归证据。首次启动若使用同一就绪检查应保持一致；默认双关不增加等待。不开放 LAN、UDP 或 TLS 到代理，不做防火墙、LuCI、定时巡检或设备测试。

验收：以生产配置切换 双关→仅 HTTP→两者→仅 SOCKS→双关；对每次成功，证明新开的端口是正确进程、关闭的端口不可用，至少一次使用真实认证请求。用受控监听占用拟新增端口，证明不能误报成功；先前工作的代理配置恢复可用、不误杀占端口进程、不泄密。用确定性屏障而不是等待固定秒数证明未就绪时不提前发布。报告分清实际 Xray 与故障夹具证据。范围：已有 Xray 就绪检查及直接启动/重载调用点、对应生命周期/显式代理测试和 reports/T16.108.md；不重构无关就绪路径。运行受影响套件和干净检出 review、diff --check。提交用 emoji + 小写模块 + 中文行为标题，任务号放正文。只本地交回 SHA 和报告，不合主线、不推送、不发版、不操作设备，不动 B29 草稿。
