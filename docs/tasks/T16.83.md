# T16.83 sys.run 每次调用私有的临时输出（M5 第一部分）

目标：stdout、stderr、wrapper 诊断和定时器握手文件均只在本次调用独占创建的私有临时目录内处理；不依赖调用方 umask，不改变目标命令继承的 umask。当前 sys.uc 的 stdout 用 PID/序号拼公共路径，其他辅助文件散落在临时根。优先复用现有原语，无新依赖；不要改调用者。

验收：在本地隔离临时根，宽松 umask 下运行真实 sys.run，在命令执行期间观察目录不可被其他用户访问；并发调用各用独立目录，stdout/stderr 不串流；验证普通成功、非零退出、超时与命令自行退出 124 的既有返回契约，正常返回后无本次残留。创建目录失败时不启动目标、不退回旧公共路径；清理仅限本次拥有的文件，保留旁边的哨兵。只改 aether-proxy/src/lib/sys.uc、针对性宿主测试及 reports/T16.83.md。用无敏感数据的夹具，不访问设备。不改超时握手算法（其无界等待另卡跟踪），不宣称整个 M5 已解决。给出修前/后证据、跑既有 sys.run/timeout 相关测试、review.sh main、git diff --check。仅交本地提交。
