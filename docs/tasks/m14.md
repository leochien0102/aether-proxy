# M14 任务卡：raw-log collector 存活修复

> **项目与范围**：本文件的任务卡全部属于 **aether-proxy** 仓库（主检出 `/workspace/openwrt/aether-proxy`，GitHub `leochien0102/aether-proxy`）。
> 执行时只在 `tests/start-task.sh <卡号>` 或本卡指定 worktree 中读写；
> **不准修改主检出，也不准碰 `/workspace/openwrt` 下的任何其他仓库**（helloworld、luci-extras、openwrt-actions 等，含其构建目录）。
> 任务卡要求「参考」其他仓库的文件时，只读不写。执行约定见 [README.md](README.md)「执行约定」。

背景（2026-11-05，r3 实测）：T13.2 的 collector 启动后只写入启动批次，随后退出：

```text
CHILD_CRASHED [name=raw-log code=1 restart_in=null]
```

`supervise` 对 raw-log 采用“失败只 warn、不重启”的策略，导致 raw.log 停更；x86 只有 2 行、H28K 52 行，均远少于 logread 历史。需要让 collector 在 logread 结束/失败后自动恢复，同时保留现有 tmpfs/0600/轮转和“系统 logd 不动”的边界。

## T14.1 raw-log collector 自动续跑

- **分支**：`fix/rawlog-loop`，基于 `b57a4dd`（0.6.3-r3）。
- **允许改动**：`aether-proxy/files/aether-proxy-rawlog.sh`、`aether-proxy/src/lib/supervise.uc`（如需）、`aether-proxy/src/lib/daemon.uc`（如需）、tests、docs/09、报告。不改 UI/API/配置/版本。
- **要求**：
  1. `logread -f` 或 awk 正常 EOF/失败退出后，collector **自动重启采集**；不得只 warn 一次后永久停更。
  2. 用有限退避避免 logread 立即失败时忙循环（例如 1–5 秒；连续失败仍保持有界）。
  3. TERM/INT 停止时干净退出、回收 logread/awk、删除 FIFO；不能因为自动重启导致服务停止时残留进程。
  4. 保留 `/var/run/aether-proxy/raw.log`、`raw.log.1`、0600、1 MiB/2000 行轮转；不写 flash，不清/改系统 logd。
  5. 不重复写同一批日志：重启 logread 只取新行（`-f` 无 `--lines` 历史），必要时记录一次 info/warn 说明采集重启。
  6. 启动后应能持续捕获 `SERVICE_STARTED`、`PROXY_HEALTHY` 等后续事件，而不是只有启动瞬间。
- **测试**：
  - fake logread 正常退出后 collector 自动重启并捕获下一批行；
  - fake logread 连续失败时不忙循环、有退避；
  - TERM 时不重启、子进程/FIFO 全回收；
  - 轮转/权限/上限回归；
  - 真实 H28K 或 x86：重启服务后 `raw.log` 持续增加，`ps` 有 raw-log，日志不再 `CHILD_CRASHED` 后停更。
- **验收**：collector 持续存活；系统日志不变；不 bump、不 push。
