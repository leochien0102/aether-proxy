# T16.57 · 停机不得被在途 Xray 重启反转

独立于 T16.55、T16.56。代码基线 `cb47a649`。任务是定位并验证一个生命周期问题，不预设修改点：服务已接受 Xray 重启请求，旧实例正在退出；随后 daemon 收到并处理停机请求。此后不应再启动新的 Xray，也不能挂住停机流程。审计提出的是待复现的时序，不是真机故障记录。

用隔离目录、真实 daemon 信号入口和受控的假子进程，先做稳定旧红：用可观察的握手/屏障区分“开始退出旧实例”“daemon 已接受停机”“允许旧实例退出”。仅证明发送过信号，或最终进程数为零，不足以排除中途短暂启动。记录启动次数、PID、正常退出/清理及有界等待；所有临时进程在成功和失败时都回收。若旧版无法复现，交证据和实际调用链，不猜修。正对照：没有停机时正常重启一次并恢复可用；另测普通停机不回归。不得靠延长 sleep、重跑碰运气、在测试里代替 daemon 执行决策或改变生产时序来过测。

允许改 `aether-proxy/src/lib/daemon.uc`、直接相关 `tests/daemon/`、`reports/T16.57.md`。若根因必须改其他文件先交证据申请。只修此在途重启/停止交错，不重写信号队列，不改 H3、更新器、DNS reload、M3 落盘策略、外部接口、依赖或版本。保留既有清理和完成通知。

验收：`bash tests/daemon/run.sh`、`bash tests/reload/run.sh`、`bash tests/host/ucode tests/run.uc`、`CI_TOOLS_DIR=/workspace/openwrt/ci-spike/tools bash tests/review.sh cb47a649`、`git diff --check cb47a649...HEAD`。报告包含触发顺序、根因、旧红新绿、未取消对照、无泄漏与退出码；关键回归纳入默认套件。只本地提交；不合 main、不 push、不派 CI、不碰设备、不发版。
