# T16.94 C1 第一部分：限制客户端 TCP 连接任务

实现仓 aether-dns，基线 2c3f145164e494f324575ad454ee3374b79a8eeb，工作树 /workspace/openwrt/aether-dns-wt/T16.94，分支 fix/t16.94-tcp-admission。

只限制服务端同时处理的客户端 TCP 连接数，所有监听地址/端口共享一个有依据的有限额度。在派生连接任务前取得额度，不能先 spawn 再排队；满额时不创建等待任务，不阻塞 UDP 或关停。避免空闲监听器提前占用额度。明确过载行为与默认上限的理由，无需新配置项或依赖。正常结束、EOF、错误、取消均归还；保留现有 500ms 全局退出预算、TCP 合法长帧、UDP 与缓存语义。UDP 在途请求与上游并发是 C1 的独立后续，不在此卡。

仅改 DNS TCP 接入及相关宿主测试、reports/T16.94.md。复用已有测试设施，以隔离本机、小额度和同步信号验证跨监听器共享、满额不再派生任务、释放后下一次正常连接成功、关停可收敛；用普通 DNS 请求，不用压测或外网。区分内核已建立连接与应用已接纳任务；不要仅以 connect 成功作为证据。跑专项、cargo test --locked --offline、git diff --check；报告注明观察点、测试上限与生产上限。只本地提交，不合 main、不推送、不发版、不动设备。
