# T16.64 · VLESS/Trojan 标准分享链接的等价写法（M12 第一部分）

目标：同一节点的标准链接用 `type=raw` / `type=tcp`，或在 host:port 后带一个空路径 `/`，导入结果应一致。只修这组等价写法。VMess gRPC 字段映射仍待独立核实，不在本卡宣告 M12 全部关闭。

入口：`aether-proxy/src/lib/uri.uc` 的 transport、parse_standard 与 parse_authority。先追踪共享解析器的调用方，优先沿用已有归一化；不能为接受空路径而放宽地址、端口或任意路径校验。保留 query 中编码的路径值、fragment 标签及现有不支持项。不要引入新依赖。

验收：用脱敏 VLESS 与 Trojan 样本，在同一协议内逐字段对比 tcp/raw 和有无单个尾斜杠的解析结果；覆盖带 query/fragment、未知 transport、非空路径、双斜杠、非法端口，及至少一条现有导入入口。旧行为红、修后绿；如共享函数影响其他调用方，用对照说明范围。只准改 uri.uc、现有 URI/导入测试及 reports/T16.64.md；不改 schema、UI、渲染器、订阅协议、版本。跑 unit、node、sub、review.sh <派卡基线> 和 git diff --check。仅本地提交。
