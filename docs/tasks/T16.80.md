# T16.80 核验正式 aether-dns ELF 的 strip 状态（M19）

单一目标：用发行字节验证“上游已经 strip，打包无需重复处理”这一假设，量出压缩包而不只是裸 ELF 的差值。本卡只交证据，不改构建或运行时。

以本仓 `aether-dns/Makefile` 当前选定版本为准，对 x86_64、aarch64_generic 分别取真实发布 ELF（优先用本地下载缓存，否则只读下载），按 Makefile 的 SHA-256 校验。记录版本、来源、文件大小、ELF Machine、`.symtab`/`.strtab`/`.debug_*` 是否存在；区分动态符号和调试段。核对生产端实际构建参数，不单凭两份 Makefile 的注释下结论。

只在临时副本用支持该架构的 strip 工具做对照；对同一架构用同一打包方式、相同元数据与压缩参数各打一次原件和副本，记录工具版本、两个哈希、裸 ELF 与压缩包前后大小和差值，明确实包还是等条件重打包。不得把裸字节减少等同于固件节省。数据已足够则给结论：无需修改，或建议后续在哪一层处理；缺资产/工具/可信哈希就写明缺口，不用宿主 debug 二进制代替。
