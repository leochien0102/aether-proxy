只限制 UDP 监听入口派生的在途查询任务数。全进程各 UDP 监听器共享有限额度，与 TCP 连接额度独立。收到请求后、复制出任务私有报文和 spawn 之前决定是否接纳；空闲监听器不占额度，满额直接丢弃该数据报，不派生等待任务、不排队、不逐包打印错误。接纳额度覆盖到本次处理及回复结束，出错或取消也释放。给默认值及选择理由，不承诺进程内存总上限。不新增依赖或配置项，不改 TCP、上游尝试与后台刷新策略、缓存、UDP 限长或全局 500ms 退出预算。

复用已有本机测试设施，小额度与可控上游屏障验证：跨监听器合计不越限、满额时未多派生任务/未请求上游、TCP 仍可完成正常查询、解除屏障后后续 UDP 请求可处理、满额关停能收敛。用应用接纳/上游观测作证，不以客户端等不到回复作为唯一证据。不做压测；尽量复用现有夹具，不复制整套 TCP 用例。
