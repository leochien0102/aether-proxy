# T16.124 · 订阅 User-Agent 下拉选择

**目标与边界**：通用设置、订阅添加/编辑共用选项：应用默认或跟随通用设置、1–2 个已验证常用值、自定义…。仅自定义显示文本框；历史非预设值原样回显。标签 User-Agent；说明不影响直连或代理。复用现有 UCI 字段，不增加模式字段。

**独立验收**：用本地订阅端点记录实际 User-Agent 并返回本应用支持的样本；验证默认、继承、覆盖、自定义、恢复继承，修改无关字段不覆写旧值。检查请求获取方式不变。不承诺所有服务端返回相同格式。

**交回**：附改动范围、验证命令、实测结果和局限；仅本地提交，不推送、不发版、不动设备。
