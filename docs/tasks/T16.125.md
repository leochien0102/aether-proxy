# T16.125 · 将清空交互推广至应用文本输入

**目标与边界**：依赖 122–124。先列出各页可编辑单行文本字段（含弹窗、动态列表新增栏、自定义 User-Agent），逐项接入或注明已有等价行为。只作用于本插件，不改 LuCI 全局；不在只读字段、选择器或长文本编辑器上机械套用。保留动态列表＋与删除已添加条目的独立语义。

**独立验收**：报告提供页面/字段覆盖表与排除理由；按控件类型做真实浏览器输入→聚焦→清空→失焦→复位验证，至少覆盖普通字段、弹窗、动态列表、自定义 UA、密码，检查不同主题、窄屏、无重复按钮；完整 LuCI 回归。

**交回**：附改动范围、验证命令、实测结果和局限；仅本地提交，不推送、不发版、不动设备。
