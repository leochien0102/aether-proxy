# T16.90 明确构建与测试只读权限（M15）

目标：构建、测试和被复用的组件构建不依赖仓库默认 token 权限，也不继承发布写权限。见 reports/T16.89.md 第 3 节。仅改 .github/workflows/{build,test,release-component}.yml 中必要的 permissions，复用现有 tests/ci 契约加最小断言，附 reports/T16.90.md。普通构建/测试默认 contents: read，组件工作流默认只读，只有真正创建/上传 Release 的 job 显式 contents: write。先核对实际 artifact 下载与 API 调用，若确需其他只读权限请给出调用点；不要为了通过测试加写权限。不改独立 release-assets 工作流、引用 SHA、触发条件、步骤或输出。

验收：解析前后 YAML，剔除 permissions 后严格相等；逐 job 列出直接运行及 reusable 调用时的权限上限，检查构建/测试无写权限、发布 job 保持必要写权限，反向对照过宽权限会使断言失败。复跑配对 channel 检出的 41 项现有 CI 契约及新增断言、干净检出的 review.sh main、git diff --check。仅本地提交，报告区分静态验证与远端实跑。不要 push、dispatch、打 tag、发版或动设备。
