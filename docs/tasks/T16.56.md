# T16.56 · reload 识别同路径 DNS 二进制替换（审计 M6）

基线 `2e6a8494`；工作树 `/workspace/openwrt/aether-proxy-wt/T16.56`；分支 `fix/t16.56-dns-binary-signature`。仅做 M6，不依赖 T16.55。

目标：DNS 可执行文件在同一路径经 rename 替换，即使新旧字节数与 mtime 相等，reload 仍识别文件身份已变、重读并发布新版本；未替换时仍复用版本，不多调用 `-V`。先检查 `binary_signature(path)` 的全部生产调用点，用实际宿主 ucode `fs.stat()` 确认字段名，不以 Python stat 或手造对象代替该项证据。

验收：在隔离夹具先创建两个同时存在、等长、mtime 相同、inode 不同的可执行文件，让它们返回可区分的等长版本串，再原子替换。走真实 reload 路径，用精确调用次数或前后差值及已发布版本证明旧红新绿；紧接着再 reload，未替换不得再探测。不得靠 sleep 碰时序、修改路径/mtime 触发成功、硬编码 inode、删除或放宽既有断言。保留 stat 错误及原有回滚语义；不把签名当作内容完整性保证。

白名单：`aether-proxy/src/lib/reload.uc`、`tests/reload/` 中直接相关的夹具与用例、`reports/T16.56.md`。不改更新器、最低版本策略、信号调度、锁、DNS 引擎仓、公共状态格式或版本号。不引入内容哈希、轮询或新依赖。若另一个生产文件确需改动，先给调用点和证据再申请。

交付：`bash tests/reload/run.sh`、`bash tests/host/ucode tests/run.uc`、`CI_TOOLS_DIR=/workspace/openwrt/ci-spike/tools bash tests/review.sh 2e6a8494`、`git diff --check 2e6a8494...HEAD`。报告列出实际 stat 字段、前后元数据、旧红新绿、第二次 reload 的探测次数及退出码。只本地提交，不合 main、不推送、不派发 CI、不发版、不操作设备。
