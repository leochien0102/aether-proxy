# T16.122 · 框内操作：焦点、可见性和布局

**目标与边界**：仅修共享控件及现有凭据字段。细小无圆框 ×，维持足够点击区。空值、占位、失焦、只读、禁用不显示；键盘焦点移到本栏按钮仍能操作。密码眼睛固定最右、默认遮蔽，× 在左独占位置。清本栏草稿、还焦、不提交。

**独立验收**：真实 LuCI 浏览器在反馈所用主题复现旧版两处问题，再测空/有值、聚焦/失焦、鼠标/键盘；用实际可见性、边界和点击命中证明 × 与眼睛不相交。深浅及 360px 各验，保留默认 URL 复制与认证保存/复位回归。

**阻断合入的两条浏览器回归（后续复用此控件的卡也必须通过）**：
1. 用实际主题 CSS，记录主题及版本。初始空值、仅占位、有值失焦、输入后清空和复位后为空：检查 × 的最终渲染，不得可见、可命中或进入 Tab 序列；有值聚焦才出现，Tab 到本栏按钮仍可操作。只检查 DOM 上的 hidden 属性不算证据。
2. 有值且聚焦时，测 × 与眼睛两个 **button 命中框**（不是 SVG 图形）的矩形交集面积必须为 0；用真实指针坐标分别点两者，显隐只切 type 且值不变，清空只改本栏且焦点返回输入。空值时眼睛位置不漂移。报告附桌面/窄屏坐标、同主题前后截图与复跑命令。
3. 提交同一组可复跑断言。审查者独立跑正式 r6 与候选版，在故障主题下两条旧版分别红、候选绿；若拿不到同款主题或未复现，要标明未验，不得拿另一主题或总通过数代替。两项均过才可向其他页面推广。

**交回**：附改动范围、验证命令、实测结果和局限；仅本地提交，不推送、不发版、不动设备。
