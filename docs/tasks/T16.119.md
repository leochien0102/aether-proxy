# T16.119 · rpcd 文件描述符余量与本应用模块的 exec 边界

基线 d530a669。H28K rpcd soft/hard 1024/4096；应用更新前 25、后 57，其中应用源文件 15 个（6 deleted），其他模块 33、其余 9。单次前后净增不是逐次 open 的证明。设备没有 io 模块。

只在 rpcd 所在进程生效：软上限低于 2048 时提高到 min(2048,hard)，不降低既有值、不改硬限制或全系统。只给本插件入口及 /usr/share/ucode/aetherproxy/ 下已打开的常规模块源文件原 fd（含 deleted）补 FD_CLOEXEC，保留其他 flags，不 close 活 fd、不改别的插件。不得用子进程修改其自身 fd/limit 冒充父进程生效。优先兼容已有平台接口；若须增加原生模块，先证明目标 SDK、ipk/apk、旧更新器的依赖闭包和首次升级安全，无法满足则回报阻塞，不静默跳过。

仅允许本应用包、其构建/测试与报告；不改 rpcd、ucode 或其他包，不引入全局服务、周期扫描或 rpcd restart。验收：隔离实测原 fd flags、新旧 inode 跨 exec、重复 reload 不再累积本应用 fd、仅观察其他项、软硬上限边界、保留 LuCI 会话与暂存更改。只更新应用的前后快照分别列 ours/other/deleted；未打补丁的高水位首次更新与稳态分开验证。不得靠 SSH 手装后自升级假冒首次页面升级。Pi 不推送、不发版、不操作设备。报告 reports/T16.119.md；DSH 独立审查、测试及决定是否可集成。
