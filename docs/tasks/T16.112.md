# T16.112 简化 LAN 显式代理配置

基线：T16.111 `0f398a13`。单一目标：管理员只填一组认证信息，不填写监听 IP；SOCKS5、HTTP 各自启停和设端口。沿用现有 Xray、配置事务和防火墙，不改透明代理。

- 从 OpenWrt 配置的逻辑 LAN 接口取得当前可用本地 IPv4，不硬编码 br-lan，不取默认路由/WAN，不把浏览器推断的地址写进 UCI。界面只读显示来源和地址；若有多个合格地址，只允许从实际候选中选一次。无有效地址时不扩大监听、不回退通配地址；两个服务都关时不要求 LAN 在线或填写凭据。
- 只存一份用户名和密码，两入站都强制使用；保留独立开关与端口（默认 1080、8080）。同时开启才校验两端口互异，沿用现有内部端口冲突检查与精确监听就绪判定。关闭一项不清空共用凭据。HTTP CONNECT 不等于到代理本身的 TLS。
- 原双配置不可静默选一套覆盖另一套：两组相同或仅一组非空可无歧义沿用；不同则明确要求管理员显式选择/重新填写，不显示密码，不在读取、打开页面、撤销或校验失败时写回。如需超出该范围的迁移机制，先说明再做。
- LuCI 保留原生保存/应用/撤销和 T16.111 的保存前凭据可见性提示；不改系统 LuCI、ACL、防火墙，不扩大 RPC 权限。优先复用已有 LAN 网络查询；若需要新增权限或没有可靠来源，带证据停下询问。
- 仅改涉及该配置的 schema/解析、渲染、LAN 地址获取、显式代理表单、对应翻译/说明和测试。用离线网络状态夹具、真实 Xray 与虚构凭据证明：地址变化后重新应用，两协议实际绑定同一新地址但不同端口、正确认证通过/错误拒绝、冲突或无地址不发布错误配置、旧异凭据不静默丢失；双关与单开不回归。不得记录凭据值。复跑相关 LuCI、后端与 readiness 测试、clean review、diff --check。报告 reports/T16.112.md。仅本地提交，不合 main、不推送、不动设备、版本或 B29。
