# T16.126 · 放宽三个长值输入框

**目标**：真机验收反馈「稍微调整几个地方的输入框宽度，订阅地址，节点的 UUID 和公钥」。只调整三处，其余字段一律不动：
1. 订阅「地址」输入（`subscriptions-block.js` 的 `form.Value 'url'`，弹窗内）；
2. 节点编辑弹窗的 `uuid`（`view/aether-proxy/nodes.js:599`）；
3. 节点编辑弹窗的 `reality_pbk`（`view/aether-proxy/nodes.js:759`）。

**做法**：在 `common.js` 增加一个最小的可复用装饰器（例如 `ap.wide_input(option, em)`），只在 render 后设置输入框宽度，不改 LuCI 全局样式、不改保存/校验/清空/显隐逻辑（必须与 T16.122/123/125 的按钮共存：`×`、眼睛仍在框内，不重叠、不遮挡文字）。
目标宽度按真实内容定：1280px 弹窗内，36 字符 UUID、43 字符 REALITY 公钥、一条长订阅地址必须整条可见（`input.scrollWidth <= input.clientWidth`，且掩码态可见字符覆盖全长），360px 下不横向溢出、不出现页面级滚动。

**验收**：真实浏览器（Proton2025 与 Argon-plus，深浅两主题，1280/360）测量三个字段调整前后的 `clientWidth`、`scrollWidth`、值长度与截图；确认其它字段宽度不变；`bash tests/luci/run.sh` 全绿；`git diff --check` 干净。仅本地提交，不合 main、不推送、不装机、不发版。
