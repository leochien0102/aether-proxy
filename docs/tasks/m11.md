## T11.1 SOCKS5 出站（0.7.0 方向）

- **目标**：新增 `protocol=socks` 的手工节点，支持无认证和用户名/密码认证；不改变现有 vless/vmess/trojan/shadowsocks 行为。
- **分支**：`m11/t11.1-socks`；从 **`main`** 建 worktree，不要从 release/0.5.0 或旧分支建。
- **不在本卡**：SOCKS 分享链接/订阅 URI 导入（后续单独卡）；HTTP 出站；WireGuard/Hysteria；分流；不改更新通道。
- **必读**：[05](../05-config.md)「config node」协议/字段/校验规则、[06](../06-nodes-subscription.md)「出站映射」、[10](../10-cli-luci.md)「节点表/节点编辑框/协议列」、[12](../12-ucode.md) 全文；`lib/schema.uc`、`lib/config.uc`、`lib/render/outbound.uc`、`model/nodes.js`、`view/aether-proxy/nodes.js`、`tests/ci/xray.sh`。
- **允许改动**：
  - `docs/05-config.md` 的节点字段表与校验规则；
  - `aether-proxy/src/lib/schema.uc`、`lib/config.uc`、`lib/render/outbound.uc`；
  - `luci-app-aether-proxy/htdocs/luci-static/resources/aether-proxy/model/nodes.js`、`view/aether-proxy/nodes.js`、`po/zh_Hans/aether-proxy.po`；
  - 相关 `tests/unit`、`tests/luci`、`tests/ci` 与 golden fixtures。
  - **不改** `lib/uri.uc`、`lib/cmd/sub.uc`、后端更新/通道、其他页面；不新增配置字段。
- **实现要求**：
  1. 协议枚举加 `socks`；新增可选 `username` 字段；`password` 归入 socks，但仅 trojan/shadowsocks 必填。
  2. SOCKS5 认证必须“用户名和密码同时有或同时没有”；只填一个 → 节点配置无效，错误指向缺失字段。
  3. 出站渲染为 Xray `socks` 出站：`settings.servers[0] = { address, port }`，有认证时加 `users: [{ user, pass }]`；地址仍按现有 `node_ip` 规则替换。若 Xray 对 socks 不支持通用 `streamSettings`，按真实 `xray run -test` 结果省略，不要臆造字段。
  4. LuCI 协议列显示 `SOCKS`；添加/编辑节点时按协议显示 address/port/username/password；已有协议字段和旧值保留策略不变。
  5. 不把 SOCKS 密码写日志/事件；UCI 字段与现有 password 同级处理。
  6. 新增 golden：无认证 SOCKS5 和带认证 SOCKS5 各一条，真实 `aether-xray run -test` 通过；另测缺用户名/缺密码被拒。
- **先复现**：先加 schema/render/LuCI/测试断言，在旧实现上应失败（协议枚举、字段、出站、协议名）；再做实现。
- **测试**：`bash tests/host/bootstrap.sh`；`tests/run.uc`；`tests/cli/run.sh`；`tests/luci/run.sh`；`tests/ci/xray.sh`；`git diff --check`。报告写 `reports/T11.1.md`，含先复现、场景对照、Xray 版本与 golden 结果。
- **验收**：旧四种协议回归全过；手工 SOCKS5 无认证/有认证各能形成有效配置并通过 `run -test`；缺一项认证被拒；不新增 URI/订阅解析。不要 push、不改 release/tag。

**复核结论（2026-10-31，已合并 main）**：unit **1071/0**、CLI **215/0**、LuCI **982/0**；真实 Xray 26.3.27 与 26.10.21 各 **19/0**；SOCKS no-auth/auth 两条 golden 均为 `Configuration OK`；缺 username/password 均 CONFIG_INVALID 且事件不含密码。`tests/review.sh` **0 FAIL**（仅授权 docs WARN）。
