# T16.84 sys.run 超时辅助进程握手有界（M5 第二部分）

单一目标：定时器的 PID 发布失败或提前退出时，调用者不会无限等待或忙等；正常的快速命令也不必等到配置的超时。先追踪 sys.uc 中 runner、timer 和两次 sleep 的所有权。不要只给读 PID 的循环加超时却留下后台 sleep，或让 timer 在无人看管时继续发信号。

沿用 T16.83 私有目录与目标 umask，不改调用方、依赖或设备。保持 stdout/stderr、自然退出 124 与真实 timeout 的区别、TERM 后才 KILL、继承忽略 TERM 的情形、BusyBox 兼容与整数 sleep 约束。握手故障要有限时间收敛并如实报告，不伪装成功或命令超时；无忙轮询，不依据未经确认的 PID 杀进程。

验收：用隔离宿主夹具和同步点证明正常路径、首个 PID 未发布、grace 阶段未发布或 timer 提前退出。至少覆盖 runner 已完成与仍在途两种情况。外层硬超时仅保护测试，不能作为修复；返回后、夹具兜底清理前观测本次 runner/timer/sleep 无残留，旁边哨兵存活，私有目录被回收。给出修前红/修后绿和耗时，跑已有 sys.run/timeout、私有目录专项及干净检出的 review.sh main、git diff --check。仅改 sys.uc、针对性宿主测试与 reports/T16.84.md；本地提交后交回 SHA，不合 main、不推送、不发版、不动设备。
