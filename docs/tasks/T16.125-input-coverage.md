## 接入方式与边界

- 复用 `aether-proxy/common.js` 的 `input_action` / `field_actions`，抽出同一实现 `clear_input` 给手建输入使用。
- `text_actions(section, form)` 只由插件自己的 section 显式调用，只匹配 `form.Value` / `form.DynamicList` 的精确原型。不改 LuCI 原型、菜单、全局 CSS，不扫描 document，不向其他插件或任意新增 input 注入控件。
- 已显式接入的 UUID、REALITY、共享凭据保留原来的专用无障碍标签；选项与输入两级去重，兼容 GridSection clone/reset。
- 清空只写当前 input 草稿，派发原生 input/change 并调用原选项验证；不调用 write/remove/parse/save、UCI 或 RPC。原有字段的校验、默认值、配置、保存及取消路径不变。
- SDK 密码框用同一框内眼睛替换原外置按钮；默认遮蔽，重新渲染恢复遮蔽。节点 `password` 补上密码显示属性，不改存储值。
- 普通 DynamicList 保持 input 与 + 的直接相邻关系；+ 仍由 SDK 处理，清空按钮不是删除已添加项。候选 combobox 只包裹其创建输入的内部 cell，不改 SDK li 的 display/选择状态；清空创建草稿，不清候选、不选择条目、不关闭下拉。
- 配额保持原来 Enter/离开时校验、保存或恢复已提交值的路径；pointerdown 防止清空按钮抢焦点，Tab 到本栏按钮仍在编辑器内，真正离开编辑器才走原提交逻辑。无效空草稿离开时仍恢复原配额。
- 按钮不参与输入框的行高计算，共享 ResizeObserver 将按钮高度上限绑定到输入实际 border box，覆盖 24px 紧凑输入；眼睛/复制固定最右，清空独立左槽。三主题浏览器门禁已通过，像素/命中证据以执行者 OUTPUT_DIR 为准。

## 真实 SDK / 主题结论

- SDK DynamicList 的 + 通过 `previousElementSibling` 读取草稿输入，因此保留 input/+ 直接相邻。输入/框内操作使用明确的 grid 边界 `1/1/2/2`，+ 使用 `1/2/2/3`，避免绝对定位按钮的 auto 末端覆盖 +。门禁检查零交集、真实指针命中及非强制点击。
- 百分比 `max-height` 约束的是 grid 包含块，不等于输入高度；共享 ResizeObserver 将操作按钮高度限定为 `min(1.75rem, 输入 border-box 高度)`。24px 紧凑输入保持原高度，眼睛不漂移。
- `L.require()` 完成不代表异步 view 已挂载；harness 等待 `#view .cbi-map` 后才枚举字段，不接受空 DOM 作为通过。
- SDK `ui.showModal()` 添加 `body.modal-overlay-active`；`ui.hideModal()` 只移除此 class 并 blur overlay，不删除 dialog，也不等待/派发关闭过渡事件。
- Argon-plus 通过 overlay 的 `left:-10000px; right:10000px; opacity:0` 关闭，仍保留 `.modal { display:flex }`；active 时左右为 0、opacity 为 1，过渡 0.125s。Playwright hidden 不把透明或屏外视为 hidden，因此 Cancel 验收同时检查 SDK 状态、最终渲染/视口位置、无 overlay 命中遮挡，以及真实非强制背景点击和无配置写入，保留再次打开的原值与遮蔽检查。
- 已核对 Argon-plus header/footer 及其引用模块：`menu-argon-plus.js` 和 `argon-plus-settings.js` 不参与 modal 关闭；暗色样式按 header 的媒体条件加载真实 `dark.css`，不伪造过渡事件或注入隐藏修补 CSS。
- Bootstrap 使用 media 根目录的 `cascade.css` 及 `data-darkmode` 选择器；harness 同时支持根目录与 `css/` 下的静态路径，并记录实际加载资产的哈希。
