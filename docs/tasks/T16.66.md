# T16.66 · restart 意图文件的 umask 不外溢

目标：init 的 restart() 在启用态发布私有意图文件时使用 077，但不得改变随后 stop/start 或调用者的原始 umask。当前 aether-proxy/files/aether-proxy.init 的 umask 077 在当前 shell 执行，成功与失败路径都可能外溢。

范围：仅 aether-proxy/files/aether-proxy.init、tests/stubs/procd/ 下相关测试、reports/T16.66.md。优先复用现有 shell 作用域与夹具，不引入新服务或依赖。保留临时文件→rename 发布、先发布再 stop、失败清理和返回码、TERM 处理以及禁用态行为。不把调用方权限硬编码为 022。

验收：在临时目录、同一测试 shell 调用真实 restart 函数（stop/start 用现有 stub），至少用非默认原始 umask 验证 stop、start 及返回后调用方看到原值；私有意图文件在 stop 入口已经可见、内容正确、权限 0600。构造无破坏性的写入或 rename 失败，确认返回非零、未调用 stop/start、临时文件清理且原掩码不变。提供基线红、修后绿。跑 bash tests/stubs/procd/run.sh、review.sh <派卡基线> 和 git diff --check。仅本地提交，不推送不动设备。
