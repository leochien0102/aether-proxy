目标：缓存命中与实时转发均保留现有 best-effort IPv4 写集合语义，但 mutex/同步 Netlink 操作不在单线程 Tokio reactor 上运行。可写请求先尝试取得全进程有限写额度再投递，接纳的写入须等实际尝试结束才放行该应答（包括失败）；满额不排队、不投递、不逐包告警，按既有 best-effort 保留 DNS 应答。取消等待者不提前归还底层仍占用的额度。额度独立于成员查询；没有要写的集合/IP 时不要占额度。不得跨 await 持有缓存/判定锁，不把后台刷新变成写集合，不做跨请求永久去重：缓存命中仍须能补写重建过的集合。不新增配置或依赖、不改过滤/Netlink 超时和关停预算。

验收：current_thread runtime、回环请求、可控阻塞 writer，证明写入屏障未开时该应答没有提前放行，同时无需写的 DNS 请求已完成；覆盖实时与缓存命中，后者不再次访问上游却再次尝试写。验证满额、取消、失败、恢复、关停，不凭单纯 sleep 猜测；区分服务停止与不能强杀进行中的 syscall。复跑相关读写回归和全量 cargo test --locked --offline；在已有隔离 netns 环境跑真实 nft 写入验收（先确认隔离，不碰宿主集合），注明执行/跳过与权限，不能用模拟屏障冒充真内核。只改 DNS 写入接入、必要的专项和 reports/T16.103.md；git diff --check 69c63f5..HEAD。仅本地提交，不合 main、不推送、不发版、不动设备。
