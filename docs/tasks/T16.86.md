# T16.86 分享链接导入：拒绝节点字符串字段中的控制字符（M13 第二部分）

目标：在单条分享链接解析的公共边界，确保返回的节点字符串字段不含 ASCII C0（0x00–0x1f）或 DEL（0x7f）；拒绝而非删字符或截断后接受。检查原始字节、百分号解码、Base64/VMess JSON 转义等真实入口，特别验证 NUL 不会被底层解码静默截成另一合法值。只管导入数据；订阅条目分隔 LF/CRLF 和合法整包 Base64 换行仍按原协议。普通 UTF-8 标签、普通空格不变。

沿用现有非法单条的跳过/失败语义；订阅混合有效与无效项保留原契约，全无有效项不发布。手动导入坏链接不写 UCI。不回显链接/凭据，不新增配置、依赖或事件；不在本卡调整长度、下载量或 1024 上限。范围：uri.uc、仅必要的直接调用处、对应 unit/node/sub 测试、docs/06-nodes-subscription.md、reports/T16.86.md。

验收：给出至少一个基线错误接受或截断、修后拒绝的字节级对照；覆盖 %00、编码 CR/LF、DEL、VMess JSON 转义及合法中文/CRLF 多行；实际导入验证不写、相邻合法项不受污染、输出无测试凭据。跑 URI 专项、node/sub 套件及干净检出 review.sh main、git diff --check。只本地提交，交回 SHA 与报告；不合并、不推送、不发版、不动设备。
