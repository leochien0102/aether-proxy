# T16.110 LAN 客户端可主动使用带认证的显式代理

单一目标：复用 T16.107 的 SOCKS5/HTTP 认证与上游转发，以及 T16.108 的本代 Xray 就绪判定。两种协议默认均关闭、可独立开启；开启时只监听管理员配置的、实际属于本机 LAN 的具体 IPv4 和对应 TCP 端口。未选有效地址不得默认开放；不附带回环监听，不退到 wildcard。仅调整显式入站，不动内部回环监听。HTTP 支持 CONNECT 到 HTTPS 目标，不是 TLS 到代理本身。网络可达性由现有防火墙决定，不做可信接口/访客识别，不增删显式入口 nft 规则，不为本功能触发 fw4 reload，不改透明代理策略。

范围：必要的 UCI 配置与校验、现有 Xray 渲染及就绪判定、直接相关文档、回归测试和 reports/T16.110.md。此卡交付可由 UCI 配置的服务，不做 LuCI。尊重已有启动/重载失败与回滚语义，不重排防火墙生命周期。

验收：在隔离网络中，由独立 LAN 客户端主动配置代理；客户端不经透明拦截。双关无显式监听；分别验证 SOCKS5、HTTP 转发和 HTTP CONNECT，正确凭据经指定上游取得离线目标响应，错误凭据不能使用；双开后关闭其中一个不影响另一个。确认监听为指定 IP、端口且归本代 Xray；无效/非本机地址或端口占用不得误报成功或退到通配，失败重载后旧有效配置仍可用。复用已有夹具，不要求新建 OpenWrt 虚机；使用项目版本 Xray 26.11.9，区分真实请求与夹具证据，报告和日志不得含真实凭据。复跑受影响套件、干净检出 review 和 git diff --check。
