# T16.77 · 更新下载只允许 HTTP(S)（M9）

目标：设备更新器的公共 curl 调用（`aether-proxy/src/lib/update.uc`）对初始 URL 和每次重定向显式限制为 HTTP、HTTPS；URL 始终是最后一个位置参数，前置独立 `--`，无需 shell 拼接。保持现有 HTTP 镜像、HTTPS Release 跨主机重定向、原有代理优先/回退、最大跳数、时间/大小限制及签名/哈希验证。不扩到订阅下载、探针、发布工具或 M11 解压上限。

范围：该模块、针对性的 `tests/update/` 与 `reports/T16.77.md`。沿实际调用确认清单、签名和资产均经过公共策略，验证直连与代理 argv：`--proto =http,https`、`--proto-redir =http,https`（或等价严格白名单），`-o <path> -- <url>`。用本地 HTTP 正常跳转验证兼容性，不连外网，不读真实设备文件，不模拟攻击。不增加 CI job/依赖，不重写下载器。运行 `bash tests/update/run.sh`、`git diff --check`、`CI_TOOLS_DIR=/workspace/openwrt/ci-spike/tools bash tests/review.sh main`；主检出既有草稿不可清理。仅本地交 SHA 和证据，不推送不合 main 不动设备。
