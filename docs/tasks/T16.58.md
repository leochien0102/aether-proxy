# T16.58 · 异类控制请求不得相互吞掉（H3）

产品基线 `91ff1a18`，含 T16.56/57；独立于更新器 T16.55。本卡只修 daemon 已收到控制信号之后的待处理语义，不承诺内核逐个传递重复的标准 Unix 信号。

## 可观察契约
- 对当前阶段本来合法的 HUP（重读配置）、USR1（立即检测）、USR2（重启 Xray），一种请求待处理不能覆盖或丢弃另一种。同类尚未消费时可合并，不要求计数或 FIFO；动作串行，不允许重入。忙时保留请求，完成后消费，不依赖下一次外部唤醒，不忙等。
- TERM/INT 一旦被接受优先停机；丢弃未开始的非停止请求，遵守 T16.57 在途取消语义。保持原有启动等待、失败待恢复、failsafe 等阶段各自允许的操作，不把启动期间的普通信号误当 stop。不新增公共接口、事件或配置。

## 验收与边界
1. 独立追踪信号接收、等待、消费、完成回调；报告分清哪些请求被接收、哪些动作已完成。先在旧基线用真实 daemon、隔离 stub 和同步屏障复现异类请求至少一种漏执行（不把连续 kill 等同于已送达，不靠 sleep 或重试碰运气）。
2. 同一夹具新绿，用配置应用结果、Xray 启动次数、检测调用等可观察副作用证明异类请求均被消费且不重入；排除自动 tick/重启附带 tick 的假阳性。覆盖同类合并、忙时再来异类、TERM 插队；stop 后无新启动，正常单请求仍工作。启动阶段给出独立回归或既有可执行证据。所有等待有界，清理夹具进程。
3. 允许：`aether-proxy/src/lib/daemon.uc`，`tests/daemon/` 对应测试与套件接入，`reports/T16.58.md`。优先复用已有夹具；若另需路径先说明理由。不改更新器、锁、监控策略、版本、CI；不改设备、不推送、不合 main。
4. 跑新增测试、`bash tests/daemon/run.sh`、`bash tests/reload/run.sh`、`bash tests/xray-ready/run.sh`、`bash tests/host/ucode tests/run.uc`、`CI_TOOLS_DIR=/workspace/openwrt/ci-spike/tools bash tests/review.sh <派卡基线>`、`git diff --check`。报告给旧红新绿、对照、命令/退出码、未覆盖边界。
