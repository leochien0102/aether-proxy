### 契约（照此实现，不要自创）

1. `usage.json` 顶层新增：`"quota": { "bytes": <整数>|null, "set_at": <epoch 秒>|null }`。
   字段缺失或 `bytes:null` 均表示「未设置」；读取时缺失不算错误。
2. `stats history` 回复顶层新增 `"quota": { "bytes": <整数>|null, "set_at": <epoch 秒>|null }`，
   其余字段与语义不变（`ok`/`enabled`/`days`/`updated_at`）。
3. CLI（唯一实现处）：
   - `aether-proxy stats quota` → 显示当前额度；
   - `aether-proxy stats quota set <值>`，值接受整数字节或带单位：`<n>G`、`<n>GB`、`<n>T`、`<n>TB`
     （**十进制**：1 GB = 10^9，1 TB = 10^12；只接受整数，`1.5G` 视为 `USAGE`）；
     允许范围 1 GB – 100000 GB（含端点）；
   - `aether-proxy stats quota clear`；
   - 三者都支持 `--json`、`--sys-root`、`--run-dir`；成功 `{ "ok": true, "quota": {…} }` 退出 0；
     参数错误 `USAGE` 退出 2；写失败 `FS_FAILED` 退出 1（错误码按 `docs/10` 现有惯例）。
4. **本卡不做 rpcd**：`stats_quota`、ACL 与 `common.js` 的 `rpc.declare` 由 T16.3 与前端调用方一起加。
   原因：`tests/luci/static.test.js` 断言「ACL 方法 == 前端声明方法」，先加后端方法会让 16 套测试
   立刻失败，而加白名单只会留一个暂时没人调用的 rpcd 方法（2026-11-16 决定）。
5. 落盘互不覆盖（本卡关键点）：
   - monitor 的每日 flush 写 `usage.json` 前必须**重新读取文件**，只替换 `days` 与 `updated_at`，
     保留 `quota` 等其余字段；
   - quota 的写入读→改→写，保留 `days`；
   - 两条路径都用现有 `sys.write_atomic` 与 0600 权限。
6. 文件损坏/权限错误：按现有「空历史 + 一次 warn」处理，`quota` 读不到按「未设置」返回，不新增事件码。
