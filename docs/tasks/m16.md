### 契约（照此实现，不要自创）

1. `usage.json` 顶层新增：`"quota": { "bytes": <整数>|null, "set_at": <epoch 秒>|null }`。
   字段缺失或 `bytes:null` 均表示「未设置」；读取时缺失不算错误。
2. `stats history` 回复顶层新增 `"quota": { "bytes": <整数>|null, "set_at": <epoch 秒>|null }`，
   其余字段与语义不变（`ok`/`enabled`/`days`/`updated_at`）。
3. CLI（唯一实现处）：
   - `aether-proxy stats quota` → 显示当前额度；
   - `aether-proxy stats quota set <值>`，值接受整数字节或带单位：`<n>G`、`<n>GB`、`<n>T`、`<n>TB`
     （**十进制**：1 GB = 10^9，1 TB = 10^12；只接受整数，`1.5G` 视为 `USAGE`）；
     允许范围 1 GB – 100000 GB（含端点）；
   - `aether-proxy stats quota clear`；
   - 三者都支持 `--json`、`--sys-root`、`--run-dir`；成功 `{ "ok": true, "quota": {…} }` 退出 0；
     参数错误 `USAGE` 退出 2；写失败 `FS_FAILED` 退出 1（错误码按 `docs/10` 现有惯例）。
4. **本卡不做 rpcd**：`stats_quota`、ACL 与 `common.js` 的 `rpc.declare` 由 T16.3 与前端调用方一起加。
   原因：`tests/luci/static.test.js` 断言「ACL 方法 == 前端声明方法」，先加后端方法会让 16 套测试
   立刻失败，而加白名单只会留一个暂时没人调用的 rpcd 方法（2026-11-16 决定）。
5. 落盘互不覆盖（本卡关键点）：
   - monitor 的每日 flush 写 `usage.json` 前必须**重新读取文件**，只替换 `days` 与 `updated_at`，
     保留 `quota` 等其余字段；
   - quota 的写入读→改→写，保留 `days`；
   - 两条路径都用现有 `sys.write_atomic` 与 0600 权限。
6. 文件损坏/权限错误：按现有「空历史 + 一次 warn」处理，`quota` 读不到按「未设置」返回，不新增事件码。

- **单一目标**：让"非阻塞 `connect` + `socket.poll`"的就绪判定在超时（`revents == 0`）时返回"不可达"，
  而不是把仍在 SYN 重传中的连接当成成功。
- **分支**：`feat/t16.20-connect-ready`
- **必读**：本卡、`aether-proxy/src/lib/monitor.uc` 的 `node_reachable()`、

  `aether-proxy/src/lib/daemon.uc:181-189`（同一处错误写法）。

### 现象与证据（H28K 真机，2026-11-18）

把当前节点 IP 的 10443 用 nft 丢弃（`nft insert rule inet fw4 output ip daddr 20.243.152.198 tcp dport 10443 counter drop`，
必须 `insert` 到表头，`add` 会被 `output_wan` 的 accept 抢先），持续约 4 分钟：

- 设备上 xray 确实断了：`PROXY_UNHEALTHY` → `MODE_DEGRADED`、`DNS_TIER_CHANGED`，nft 计数 3992 包。
- 但 `state.json` 的 `failover_failures` 始终 `0`、`failover_latched` 为 `false`、`node_id` 未变、无 `NODE_FAILOVER`。
- 给 `observe()` 临时插桩后事件显示 `tcp_ok: true, subf: true, nodef: null, port: 10443, ip: 20.243.152.198`
  ——丢包期间 `node_reachable()` 返回 **true**（配置归一化已先排除：`snapshot.sub.failover == true`）。

设备上实测 ucode `socket.poll` 语义：

| 目标 | `poll()` 返回 | `getopt(SO_ERROR)` | 真实可达 |
|---|---|---|---|
| `223.5.5.5:53`（可连） | `[ [ "<socket 0x6>", 4, 1 ] ]` | 0 | 是 |
| `127.0.0.1:9`（拒绝） | `[ [ "<socket 0x6>", 28, 1 ] ]` | 111 | 否 |
| 静默丢包 | `[ [ "<socket 0x6>", 0, 1 ] ]` | 0（仍是 EINPROGRESS） | 否 |

`socket.poll()` 返回的永远是"被轮询 fd 的数组"（长度恒为 1），超时时 `revents` 为 0。
现有写法 `length(polled) > 0 && getopt(SO_ERROR) == 0` 因此把超时判成可达。

### 要求

1. `node_reachable()` 先看 `revents`：
   `let revents = polled?.[0]?.[1] ?? 0; connected = revents != 0 && sock.getopt(SOL_SOCKET, SO_ERROR) == 0;`
   `polled == null` 视为不可达；`connect()` 立即成功（返回 `true`）仍直接算可达。
2. 把这段判定收成一个可直接单测的小函数（放 `monitor.uc` 或 `net.uc` 均可，二选一并在报告里说明），
   不再用 `length()` 判断就绪。
3. 顺带把 `daemon.uc` 里 `length(polled)` 的同一写法按第 1 条统一；行为变化只应出现在"超时"这一种情形。

## T16.26 自动切换改用三态控件（替代原生 indeterminate）

状态：**已合并**（`215a06f`，2026-11-18）。

**审查结论（2026-11-18）**：luci **1160** 通过、`Unused msgids: 0`；`tests/run.uc` 1440 通过；`tests/review.sh main` 0 FAIL / 1 WARN（仅 docs/10）；`git diff --check` 干净；两主题截图三态可辨（空框／左半填充／实心白勾）。实现：`span.aether-tri[role=checkbox][aria-checked]` + `.aether-tri-mark`，`paint_failover()` 只改 class 与 `aria-checked`；键盘 `Space`/`Enter` 走 `box.click()`；`renderTextValue` 整格点击只在 `ev.target === cell` 时转发，避免和控件自身处理器重复触发；总开关关闭时用 `.cbi-value-field:has(> .aether-tri--inactive)` 给整格 `opacity:0.65`。来源：2026-11-18 真机界面复核——半选时浏览器原生的 `indeterminate`（灰底白横线）在主题下像「禁用」，设计负责人要求换成真正的三态控件。

### 问题

订阅行的「自动切换」用 `input[type=checkbox]` + `indeterminate` 表示「部分节点在名单」。原生半选样式是灰底横线，与禁用态同形，且 `view/nodes.js` 为了保住这个勾还专门写了 `appearance:auto !important` 覆盖主题。

### 要求

   - 结构：`span.aether-tri` 外层（`role="checkbox"`、`tabindex="0"`、`aria-checked` = `true` / `false` / `mixed`、`aria-label` 同现有 `FAILOVER_TITLE`），内含 `span.aether-tri-mark`。
   - 外观（约 `1em` 见方、`2px` 边框、圆角 `3px`，颜色取主题变量 `--primary-color-high` 一类，不要写死十六进制）：

   - 交互：鼠标点击、键盘 `Space`/`Enter` 都与现在一致（关或半选 → 补成全选；开 → 二次确认后全移除）；`focus-visible` 有可见轮廓；总开关关闭时整格 `opacity:0.65` 但可点。
   - `title` 文案不变（含「半选 · n/m」与 T16.25 的当前节点追加句）。
