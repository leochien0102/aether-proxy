## T12.1 B25 热力图设计与可行性（实验）

- **目标**：先定 B25 的数据模型、采样/持久化、API、UI 和回退边界；不写产品代码。
- **分支**：`experiment/b25-heatmap`；worktree `/workspace/openwrt/aether-proxy-wt/B25`。
- **必读**：`docs/backlog.md` B25、`docs/02-dataplane.md` 计数器、`docs/04-lifecycle.md` monitor/停止、`docs/05-config.md` `config stats`、`docs/10-cli-luci.md` 概览/统计、`docs/09-logging.md`。
- **允许改动**：只改 `docs/`（新增 `docs/b25-heatmap.md`）、`spikes/B25/`（可选原型）、`reports/T12.1.md`；不改产品代码、Makefile、版本、rpcd/UI。
- **设计必须回答**：
  1. 采样：monitor 每轮如何读 `proxy_tx/proxy_rx` 增量、清零、服务未运行/暂停；按本地日期聚合；observed/healthy 秒定义。
  2. 持久化：`usage.json` schema、0600、原子写、跨天/干净停止、可选 6h checkpoint、90 天裁剪、损坏文件/升级兼容、flash 写入预算。
  3. API：`stats history` 与 rpcd `stats_history` 的请求/响应、`enabled:false`、区间/上限、空数据、错误码；不进入 5 秒 `stats`。
  4. UI：7×13 CSS grid、颜色归一化、健康度表达、tooltip、无数据/未启用/历史不足、i18n、窄屏；默认关闭时完全不渲染。
  5. 开关：`heatmap_enabled` 默认 0、启用/关闭行为、重开继续、关闭保留文件；配置 apply/reload。
  6. 失败与隐私：不记录域名/节点/目的地；文件损坏、写失败、时钟跳变、跨天边界的降级。
  7. 测试计划：假时钟、清零、跨天、90 天、关闭无采样/无写、重开、损坏文件、API/UI 契约；H28K 验证步骤。
  8. flash 寿命估算与是否 checkpoint。
- **产出**：`docs/b25-heatmap.md` + 设计评审记录；实现卡拆分建议（后端聚合/API/UI 分开）。
- **验收**：设计覆盖上面 8 点，明确默认关闭和可整体撤销；不写产品代码、不 bump、不 push。

## T12.3 B25 采样与内存聚合（实验）

- **目标**：实现 monitor 内的代理计数器采样和按天内存聚合；不写 `usage.json`、不做 history API、不做 UI。
- **分支**：`experiment/b25-heatmap`；worktree `/workspace/openwrt/aether-proxy-wt/B25`。
- **允许改动**：新增 `aether-proxy/src/lib/usage.uc`（纯聚合）、`monitor.uc` 采样钩子、必要时把 `cmd/stats.uc` 的 nft 计数器读取抽成共享函数、`const.uc`、`tests/unit/`/`tests/monitor/`/`tests/fixtures`、报告。不改持久化/API/UI/配置默认（T12.2 已完成）。
- **要求**：
  1. `usage.uc` 纯函数/状态机：输入当前 tx/rx、`clock`、elapsed、服务状态、proxy_ok；输出/累计 `tx/rx/observed/healthy`；首次只建基线；计数器变小按清零；elapsed 上限；跨本地日期切日；时钟回退不写负数。
  2. monitor tick 仅在 `snapshot.stats.heatmap_enabled === true` 时采样；关闭时不得执行 nft 计数器查询。
  3. 当日数据只在内存；本卡**不写文件**；进程重启丢当天数据，属于预期。
  4. 不改变现有 `stats` 输出；不记录域名/节点/目的地。
- **测试**：假时钟/假 nft 输出；首次基线、增量、清零、跨天、时钟回退、elapsed 上限、关闭时无 nft 调用；monitor 集成仅验证采样入口；现有 stats/monitor 全回归。
- **验收**：开关关闭零采样；开启后内存数值正确；不落盘/不 API/不 UI；不 bump、不 push。
