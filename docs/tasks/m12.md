## T12.4 B25 usage.json 持久化（实验）

- **目标**：把 T12.3 的内存聚合按天写入 `/etc/aether-proxy/usage.json`；保留 90 天，处理损坏/写失败/干净停止；不做 API/UI。
- **分支**：`experiment/b25-heatmap`；worktree `/workspace/openwrt/aether-proxy-wt/B25`。

- **要求**：
  1. schema：`{schema:1, updated_at, days:{YYYY-MM-DD:{tx,rx,observed,healthy}}}`；当前日也写为一条，保持读写简单；`updated_at` 用墙钟秒。
  2. 路径 `/etc/aether-proxy/usage.json`；`0600`；`sys.write_atomic`；写后回读或至少校验写入成功；失败不阻塞 monitor，下次重试。

## T12.5 B25 stats history / rpcd API（实验）

- **目标**：在已落盘的 `usage.json` 上提供只读历史查询：CLI `stats history` 与 rpcd `stats_history`；不做 UI，不改采样/持久化。
- **分支**：`experiment/b25-heatmap`；worktree `/workspace/openwrt/aether-proxy-wt/B25`。
- **允许改动**：`aether-proxy/src/lib/cmd/stats.uc`、入口分派、`usage.uc`（只扩展 load 返回 updated_at 等只读字段）、rpcd 插件、ACL、docs/05/10、tests、报告。不改 monitor/daemon/UI/版本。
- **API**：
  - CLI：`aether-proxy stats history [--days N] [--json] [--sys-root DIR] [--run-dir DIR]`
  - rpcd：`stats_history`，参数 `{days?: number}`；ACL 归 read。
  - 成功：`{ok:true, enabled:true, days:[{date,tx,rx,observed,healthy}], updated_at}`；关闭：`enabled:false, days:[]`，不读文件；损坏文件：`enabled:true, days:[]`（或明确错误码，按 docs/08 统一）不能让 rpcd 崩。
  - `days` 1–90，默认 90；只返回最近 N 个有数据日期；不修改文件、不触发 monitor。
- **要求**：
  1. 复用 T12.4 `usage.load` 的条目校验；`updated_at` 由 load 返回，缺失文件为 null。
  2. 关闭开关时 CLI/rpcd 都不打开 usage 文件（读配置判断）。
  3. 现有 `stats` 无参数输出保持不变；`stats history` 不进入 5 秒轮询。
  4. ACL：`stats_history` 只读；错误不泄漏路径以外的隐私。
- **测试**：CLI `--days` 0/1/90/91、关闭/缺失/损坏、排序/裁剪；rpcd 参数/ACL/关闭；现有 stats/rpcd 全回归。
- **验收**：API 契约稳定、关闭零文件读、无 UI/采样改动；不 bump、不 push。

## T12.7 B25 热力图布局返工（实验）

- **目标**：连续日期网格改为 3 行 × 30 列，缩小格子并拉开与运行状态的间距；无卡片背景/标题/周表头，控制概览一屏高度。
- **分支**：`experiment/b25-heatmap`；worktree `/workspace/openwrt/aether-proxy-wt/B25`。
- **允许改动**：`model/overview.js`、`view/overview.js`、`po/zh_Hans/aether-proxy.po`、`tests/luci/`、`docs/10-cli-luci.md`、`docs/b25-heatmap.md` §7、报告。不改后端/API/数据/版本。
- **布局（最终口径）**：
  1. 位置仍在「启用」块与「运行状态」块之间；关闭时完全不渲染、零 API。
  2. 不要 `.cbi-section` 背景、不要「使用热力图」标题、不要周表头；直接渲染网格。
  3. 网格：**3 行 × 30 列 = 90 格**，连续日期 row-major；最近 90 个本地日期，
     今天恒在右下角（index 89）；无前导空格；未来/无数据为中性空白，不补 0。
  4. 宽度：热力图容器宽度约为**下方「运行状态」块内容宽度的 75%**（`width:75%`，
     居中；桌面最大不超过内容宽度的 75%）；30 列等宽铺满该宽度，格子为圆角正方形，
     约 25px；3 行总高约 80–100px，必须一屏可见。
  5. 与「运行状态」块之间必须留出明显间距（建议 `margin-bottom: 1.25em`）；空区域用
     `:empty { display:none }`，关闭时不产生空白间距。
  6. 颜色/健康度/tooltip 规则不变；tooltip 含日期；空格无 tooltip。
  7. 空历史也显示完整 90 格中性网格；失败保留最后网格+错误；窄屏可横向滚动，桌面不滚动。
- **测试**：3×30=90 格、无前导空格、今天 index 89 右下角、日期连续、无标题/表头/背景、格子尺寸/居中/75% 宽度/高度、与运行状态间距、`:empty` 隐藏、窄屏滚动、颜色/健康/tooltip 回归。
- **验收**：3 行 30 列、宽度约运行状态块 75%、与运行状态有间距、概览一屏；关闭零渲染/零 API；不 bump、不 push。
