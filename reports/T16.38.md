重新登录，等服务启动后检查：

```sh
raw=/var/run/aether-proxy/raw.log
grep -c 'I \[main.zig' "$raw"             # 粗查，含有意保留的例外；见下文
grep -c 'local listen addr' "$raw"        # ≥1
grep -c 'startup: .* suppressed' "$raw"   # ≥1
# 真正应为 0 的是非例外 main.zig 明细：
grep -vE 'local listen addr|failed|\[(Warning|Error)\]' "$raw" | grep -c 'I \[main\.zig:'
```

任务卡的原样 `grep -c 'I \[main.zig'` 会把监听地址也算进去。宿主机启动缓存的 chinadns-ng 2025.08.09 二进制（仅回环）后，将真实输出经假 `logread` 喂给收集器：落盘为 `I [main.zig:164 main] local listen addr: 127.0.0.1#54583` 和 `6 info lines suppressed`。因此该版本应以排除保留例外后的计数为 0，不能以原样计数为 0。汇总要等下一条可写记录或 `logread` EOF，不会因静默超时提前写入。
