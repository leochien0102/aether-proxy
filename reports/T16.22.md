# T16.22 — 自动切换名单界面

工作树 `/workspace/openwrt/aether-proxy-wt/T16.22`，分支 `feat/t16.22-failover-list-ui`，基线 `8972706`。

## 实现

- `subscriptions-block.js` 持有两个表和订阅编辑框共享的名单草稿（按节点 ID 记录加入/移除）。`model/subscriptions.js` 处理 UCI 单值/列表形态与选中数量。仅页脚保存将草稿合并写入 `main.failover_nodes`；清空名单用 `unset`。页脚重置丢弃草稿。普通勾选不写 UCI、不发 RPC，订阅模态框保存其它字段时也不提交名单。
- `view/aether-proxy/nodes.js` 在节点表挂载两态列、依次保存两个共用 UCI 缓存的 Map，并在导入重读 UCI 后重绘。名单草稿按 ID 合并到最新 UCI，保留后端新增 ID，不重复写导入默认值。
- 通用设置的总开关默认、位置与风控提示保持原样。关闭只影响是否生效，不清名单；淡显是样式，不是 `disabled`。参与判定仍由后端负责：总开关开、节点存在且未停用、ID 在名单中。没有节点编辑框三选一，也没有新增配置字段。
- 64 项上限按后端约束处理：超限的批量选择不部分写入，并提示；页脚保存时也检查与最新后端名单合并后是否超限。

## DOM 片段

下例为 LuCI DOM 关键属性摘录，与 `tests/luci/progressive-lists.test.js` 断言的结构对应；不是设备截图。示例中总开关关、订阅 10 个节点选中 8 个：

```html
<td class="td cbi-value-field" data-name="_failover" data-title="自动切换" style="cursor:pointer">
  <button type="button" class="btn cbi-button cbi-button-neutral"
          aria-pressed="mixed" style="width:100%;opacity:0.65">
    <span>半选 · 8/10</span><small style="display:block">总开关未开启，当前不生效</small>
  </button>
</td>
```

单元格留白点击转发给内部按钮；按钮本身支持键盘激活。节点列使用相同结构，`aria-pressed` 只有 `true` 或 `false`。订阅表该列紧跟「获取方式」。

## 三态与点击矩阵

| 订阅节点在名单中的数量 | 列显示 | `aria-pressed` | 编辑框初始值 |
|---:|---|---|---|
| 0（包括空订阅） | 关 | `false` | 关 |
| 例如 8/10 | 半选 · 8/10 | `mixed` | 关 |
| 全部且至少一项 | 开 | `true` | 开 |

| 操作 | 名单草稿变化 | 确认与重绘 |
|---|---|---|
| 订阅列：关 / 半选 → 点击 | 加入该订阅全部现有节点 ID | 不确认；立即重画订阅和对应节点。空订阅无变化 |
| 订阅列：开 → 点击 | 确认后移除该订阅全部节点 ID | 提示移除数量；取消不变 |
| 节点列：关 / 开 → 点击 | 加入 / 移除该节点 ID | 不确认；立即重画节点与所属订阅 |
| 订阅编辑框：改开关后保存 | 按开关批量加入 / 移除 | 成功保存模态框后重画；取消或保存失败不改。半选时不操作则保留；要清空半选可先开再关 |
| 总开关：关 ↔ 开 | 不改变名单 | 原位更新淡显和提示；关闭时仍可操作 |
| 页脚保存 / 重置 | 保存合并到最新 UCI；重置丢弃草稿 | 不因名单点击刷新整页；生效走正常「保存并应用」 |
