# T11.10 CI 发布门禁与 smoke 依赖

## 改动

- `build.yml`：push/PR paths 加 `aether-xray/**`、`chinadns-ng/**`；`PACKAGES` 加 `aether-xray chinadns-ng`；矩阵扩展为 x86_64/armsr-armv8 × 24.10.8/25.12.5，并按 `package_arch` 校验/上传 artifact；smoke 下载对应架构 artifact。
- `release-assets.yml`：新增 `Wait for successful build`，按 `github.sha` 查询 `build.yml` 的 push/workflow_dispatch run，必须 success 才继续；failure/cancelled/timed_out/skipped/neutral/action_required、无 run、API 失败、SHA 不符都阻断，不能创建/上传 Release。权限增加 `actions: read`，总超时 195 分钟。
- `tests/ci/smoke.sh`、`tests/ci/smoke-host.py`：安装/卸载 5 个包（aether-xray、chinadns-ng、aether-proxy、LuCI、i18n），并覆盖两个二进制缺失。
- 新增 `tests/release/test_build_workflow.py`：build paths/PACKAGES/artifact/矩阵静态断言，以及 artifact 检查的可执行负例。
- `test_release_assets.py`：fake `gh api` 提供 build run 序列，覆盖 pending→success、各类失败/无 run/API 失败/SHA 不符、忽略 PR run、取最新 run；失败时确认没有 release/upload/curl。

## 先复现

旧 release workflow 没有 build gate；新增测试在旧基线上 `Wait for successful build` 不存在，测试按预期失败。旧 build PACKAGES/artifact 不含 aether-xray/chinadns，新断言和 smoke 负例失败。

## 验证

- `python3 tests/release/test_release_assets.py`：**19/19 OK**。
- `python3 tests/release/test_build_workflow.py`：**3/3 OK**。
- 两个 workflow YAML 解析通过；所有 run 块 `bash -n` 通过（由测试覆盖）。
- `bash -n tests/ci/smoke.sh` 通过；`git diff --check` 通过。
- 未实际跑 GitHub Actions（需要 push）；未 bump 版本、未创建 tag/Release。

## 边界

0.6.3 的 build 失败现场是 packages 成功、smoke 因缺少 `aether-xray`/`chinadns-ng` 依赖全失败；本卡修复的是该 CI 配置和发布门禁，不改产品代码。
