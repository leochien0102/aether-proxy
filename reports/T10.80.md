# T10.80 概览延迟文字分级

## 范围

- 分支：`m10/latency-label`，基于 `6f0dbb9`。
- 仅修改概览 model、中文 po 和概览测试；view 继续直接渲染 `probe_text`，颜色继续读取 `probe_level`，无需修改。
- 按用户后续要求，中文单位保留 `ms`，不改为“毫秒”。
- 未修改共享阈值、节点页、后端、版本、release 或 tag；未 push、不发版。

## 实现

- 概览自动和手动成功结果共用文字映射，调用 T10.79 的 `latency.level()`，没有另写阈值：
  - `ok` → 正常；`warn` → 偏高；`error` → 过高；缺失/无效等级 → 未知。
- 自动示例：`正常，123 ms`、`偏高，500 ms`、`过高，2000 ms`。
- 手动示例：`偏高，208 ms（GitHub，手动）`；缺少 latency 为 `未知，? ms（GitHub，手动）`。
- 保留自动失败、手动超时、检测失败及 HTTP 失败文案。
- po 新增分级及格式条目，复用已有 `Unknown`，删除两个无引用的 `Healthy` 条目。

## 先复现、后实现

1. 先新增 T10.80 测试，覆盖自动/手动 100、200、201、800、801、2000，缺失及无效 latency，DOM 颜色和失败文案。
2. 修改实现前执行：
   ```sh
   node --test --test-name-pattern='T10.80' tests/luci/overview.test.js
   ```
   结果：13 项，1 通过、12 失败。旧实现成功结果一律显示“正常”，失败文案保持现状。此轮测试最初使用任务卡的“毫秒”；用户随后要求保留 `ms`，最终测试和翻译均已相应调整。
3. 实现共享等级到文字的映射，并更新旧测试中的成功文字预期。
