## 实现

- `luci-app-aether-proxy/htdocs/luci-static/resources/aether-proxy/model/logs.js`
  - 原始日志先将 RPC 行映射到新数组，再 reverse/join，最新记录显示在最上方。
  - 不原地反转 RPC 数组，不按时间重新排序，不拆分单条记录内部文本；后端和 CLI 仍保持原有顺序。
  - 保留空日志、失败提示、debug 提示及纯文本输出行为。
- `luci-app-aether-proxy/htdocs/luci-static/resources/view/aether-proxy/logs.js`
  - “事件 / 原始日志”按钮放入独立 flex 行，使用 gap、flex-wrap 和上下 margin。
  - “来源 / 行数”放入 flex 筛选行，每个 label 包含自己的文本和 select；组内、组间均有 gap，整行及组内允许换行，组最大宽度 100%。
  - 两个 select 均为 `width:auto; max-width:100%`，避免主题的满宽 select 挤压相邻控件。
  - 切换按钮行、原始日志筛选行、操作行共享同一个 rowStyle：居中对齐、`gap:0.5em`、`flex-wrap:wrap`、`margin:0.5em 0 1em`。
  - 操作行仍在内容下方右对齐，后续清空按钮可以加入同一行，沿用间距/换行规范。
  - 不引入 CSS 框架，不修改事件面板自身的布局。
