# T16.36 子进程日志限流：启动突发、立即摘要与自检

- 基线 `8faee81`；分支 `feat/t16.36-log-limits`。
- 真机背景沿用任务卡：x86 的 chinadns-ng 启动日志触发限流，H28K 的 aether-dns 启动输出较少；原先摘要到会话结束才可见。本卡未连接或重启那两台设备，未声称验收了设备上的 `raw.log`。

## 实现

- 每个 awk 会话从 `BEGIN` 起前 5 秒仅豁免 20 行/秒，保留滚动 60 秒 120 行与 10 秒去重。回拨清空配额和去重窗口，同时平移会话起点，不重新开启豁免。
- 连续丢弃的首条立即 `fflush()`，带去色、去时间戳的 `first:`（前 160 字符，BusyBox 按字节截取）。同一连续段若再丢，恢复放行或 EOF 时才补一条整段总计（包含第一条）。摘要不计入任何配额。
- DNS 初启、reload 正向/回滚以及 monitor 交给监督器的 tier 重启按已知引擎 basename 命名。`daemon.children.dns` 不变；陈旧子进程清理兼容旧的 `chinadns-ng` PID/FIFO，并认新 `aether-dns` 名称。
- `.logstats` 是会话快照：开始、首次放行、限流摘要与 EOF 刷新。`accepted`/`dropped` 为会话累计；去重不计入两者。会话未限流时首末时间为 `null`，否则为 epoch 秒。文件写失败不会杀掉 awk/FIFO；摘要仍使用原来的 stdout。CLI 不改日志文件，缺目录或无快照返回空表/空数组。
- 未改配额数值、`rawlog.sh`、轮转、LuCI、rpcd、ACL、版本或 Makefile。

## 主机真实复现（BusyBox 1.37.0 awk，未伪造时钟）

运行 `LOG_STATS_AWK='busybox awk' python3 tests/cli/log-stats.py`，使用实际过滤器、保持 stdin 打开的管道和临时 run-dir。输入为带 ANSI 与时间戳的 chinadns-ng 格式样例，不是设备抓取：

1. 2026-11-19 `09:01:32 UTC`（epoch `1795078892`）同一秒送入 30 条互异的启动日志，30 条全部按序放行，且无额外摘要。
2. `09:01:37 UTC`（epoch `1795078897`）同一秒送入 21 条互异的会话日志，前 20 条放行。第 21 条触发下方摘要，读取时仍是 `09:01:37` 且 stdin 没有关闭，没有发送下一行。`first:` 不含 ANSI 和子进程时间戳，长度断言为 160。

```text
aether-proxy: chinadns-ng output rate limited, dropped 1 lines between 09:01:37 and 09:01:37, first: W [Upstream.zig:825 TCP.on_error] xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

同一活跃会话中实际执行 `aether-proxy log stats --run-dir <临时目录>`（通过 host ucode 运行仓库 CLI 入口）：

```text
NAME	ACCEPTED	DROPPED	FIRST_DROP	LAST_DROP	SECOND_LIMIT	MINUTE_LIMIT
chinadns-ng	50	1	1795078897	1795078897	20	120
```

`--json` 的单文件结果为 `ok:true`、`stats` 只有上述 1 条；多文件场景额外放入 `xray` 测试快照后返回两条；目录不存在或为空均返回 `{"ok":true,"stats":[]}`。关闭 stdin 后没有重复打印单条丢弃摘要。另有固定时钟用例验证启动期第 121 条仍触发分钟上限、第 6 秒恢复秒级上限、时钟回拨、连续限流在恢复/EOF 汇总与去重顺序。

## 场景对照

| 场景 | 用例与证据 |
|---|---|
| 前 5 秒豁免、第 6 秒恢复 | `tests/daemon/logfilter.py`：`25 lines in each of startup seconds 1 and 5 all pass`，`sixth second applies the 20-line limit and summarizes on recovery`；误限流或晚恢复均会破坏逐行比较。 |
| 分钟上限不豁免、去重不变 | `tests/daemon/logfilter.py`：`the rolling minute limit still applies during startup`（首秒第 121 条丢弃）；`merged lines leave all 120 rolling minute slots available`（重复行不占配额）。 |
| 回拨、立即摘要与合并 | `tests/daemon/logfilter.py`：`rollback clears the quota but does not renew startup grace`、`EOF flushes the full drop streak`；`tests/cli/log-stats.py` 在 EOF/下一行之前逐字比较摘要、检查当秒和 `first:`。 |
| stats 计数随接受/丢弃更新 | `tests/cli/log-stats.py` 依次读取 `0/0`、`1/0`、`50/1` 活跃快照；`tests/daemon/supervise-log.py`：`crash: stats path with shell metacharacters holds latest session counts`（EOF 后 `120/380`）。 |
| CLI 无文件、单文件、多文件 | `tests/cli/log-stats.py`（`T16.36 log stats CLI scenarios passed`）：缺目录/空目录返回空表和空数组，真实单快照与两条快照的 JSON 字段、顺序均比较，并排除坏 JSON 与目录。 |
| DNS 监督名与回归 | `tests/daemon/engine-selection.py`：初启及 S8/S9 reload 的 `PID file uses the selected supervision name`、`DNS FIFO uses the selected supervision name`，同时核对实际子进程 PID/argv；其余回归见上表。 |
