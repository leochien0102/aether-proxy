# T10.79 — 概览与节点页共享延迟分级颜色

## 范围与实现

- 工作目录：`/workspace/openwrt/aether-proxy-wt/T10.79`；分支：`m10/latency-levels`。
- 开始时 HEAD 为 `2f1aa63`（扩展节点页范围的任务说明提交，父提交为 `b4e02b2`）；按扩展后的 T10.79 实现，未重置分支。
- 新增 `luci-app-aether-proxy/htdocs/luci-static/resources/aether-proxy/model/latency.js`，只在 `level(ms)` 中定义阈值：有限非负数字 `<=200` 为 `ok`、`>200 && <=800` 为 `warn`、`>800` 为 `error`；缺失、null、非数字、负数、NaN、Infinity 为 `neutral`。数字字符串不隐式转换。
- `model/overview.js` 的自动结果与 `manual_probe()` 均调用共享函数，手动结果携带 `probe_level`，显示时不再自行推断等级；检测失败始终为 `error`。
- `model/nodes.js` 用同一个内部 `probe_fields()` 解析文字和等级，供 `probe_column()`、新增 `probe_level()` 及 `build()` 使用。成功结果按 `median_ms` 分级；pending / 未检测 / 读取中为 `neutral`，读取失败及检测失败为 `error`。本地 pending 保留优先级，不被旧结果染色。
- `view/aether-proxy/nodes.js` 在初次渲染和结果刷新时设置颜色；转为 neutral 时清除旧颜色。沿用现有 success / warning / error 主题变量与回退值。
- 概览视图原有 `colorStyle(vm.probe_level)` 已满足要求，无需改视图。所有展示文字保持不变；未添加可选 title / legend，因此未改翻译。
- `tests/luci/loader.js` 补充真实共享 latency 模块的加载支持，与其已有共享模块加载适配方式一致，使所有既有模型测试使用实际阈值而非测试替身。
