# T16.46 运行中开启热力图时补种

`create_daemon()` 不再预读 `usage.json`。每个进程在首个启用热力图的采样点尝试补种一次；缺文件或无今日条目就从零继续，读取或解析失败时额外记一次 `FS_FAILED`（`op=read`）。关闭时不读盘且不消耗首次补种机会。重新加载 snapshot 不重置就绪状态；首次可读的 nft 计数仅用于建立基线。`flush_usage()`、`usage.collect()` 和 `stats history` 的覆盖语义均未改变。

## 运行中开启前 / 后实测

2026-11-21，在基线 `f58d4b80`（只加测试夹具）及修复版本 `782a5641` 上运行相同 monitor 场景：预置本地今日 2 GB（`tx=200000000`、`rx=1800000000`，`observed=1800`、`healthy=1500`），关闭热力图创建 daemon 并运行一轮，再替换 snapshot 开启。首个启用 tick 后再次替换已启用的 snapshot，第二个 tick 的 nft 计数只增加 `2500/4000` 字节。各阶段的 `stats history --json --days 1` 用真实 CLI 在独立 sysroot 中读取当轮 state 快照与初始磁盘文件，配置开关与该阶段一致。下面省略时间戳和无关字段。

### `state.json`

| 阶段 | 基线：`usage_today` | 修复后：`usage_today` |
| --- | --- | --- |
| 开启前 | 字段不存在 | 字段不存在 |
| 首个启用 tick | `{"date":"2026-11-21","tx":0,"rx":0,"observed":0,"healthy":0}` | `{"date":"2026-11-21","tx":200000000,"rx":1800000000,"observed":1800,"healthy":1500}` |
| 第二个启用 tick | `{"date":"2026-11-21","tx":2500,"rx":4000,"observed":0,"healthy":0}` | `{"date":"2026-11-21","tx":200002500,"rx":1800004000,"observed":1800,"healthy":1500}` |

### `stats history --json --days 1`

| 阶段 | 基线 | 修复后 |
| --- | --- | --- |
| 开启前 | `{"enabled":false,"days":[]}` | `{"enabled":false,"days":[]}` |
| 首个启用 tick | `{"enabled":true,"days":[{"date":"2026-11-21","tx":0,"rx":0,"observed":0,"healthy":0}]}` | `{"enabled":true,"days":[{"date":"2026-11-21","tx":200000000,"rx":1800000000,"observed":1800,"healthy":1500}]}` |
| 第二个启用 tick | `{"enabled":true,"days":[{"date":"2026-11-21","tx":2500,"rx":4000,"observed":0,"healthy":0}]}` | `{"enabled":true,"days":[{"date":"2026-11-21","tx":200002500,"rx":1800004000,"observed":1800,"healthy":1500}]}` |

### `usage.json`

开启前及两个同日启用 tick 后，基线和修复版均未改写磁盘文件：

```json
{"schema":1,"days":{"2026-11-21":{"tx":200000000,"rx":1800000000,"observed":1800,"healthy":1500}}}
```

合成跨天并调用 `flush_usage()` 后，基线把 2 GB 覆盖成了零头：

```json
{"schema":1,"days":{"2026-11-21":{"tx":2500,"rx":4000,"observed":0,"healthy":0},"2026-11-22":{"tx":0,"rx":0,"observed":0,"healthy":0}}}
```

修复版写回既有累计加新增流量：

```json
{"schema":1,"days":{"2026-11-21":{"tx":200002500,"rx":1800004000,"observed":1800,"healthy":1500},"2026-11-22":{"tx":0,"rx":0,"observed":0,"healthy":0}}}
```
