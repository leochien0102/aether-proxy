## 偏差与待定
- `docs/09-logging.md` 规定了 `CHILD_STARTED` 和 `CHILD_CRASHED`，但当前 `aether-proxy/src/lib/log.uc` 的事件注册表没有这两个代码；调用 `log.event()` 会直接以 unknown event code 终止。按任务卡允许改动范围，未修改 `log.uc`，代码在对应位置保留 `TODO(design)`，并通过接口的 `on_event` 发出 `started` / `crashed` / `restarting` / `exited`。请设计负责人决定是否将两事件码加入注册表后启用结构化日志。
- `kill_stale()` 按设计给定的 PID 文件及命令行子串校验进程；TERM 后等待一秒，仍匹配则 KILL，避免误杀复用该 PID 的无关进程。
