## 上游核对、偏差与待定

1. **PSK 字段拼写修正**：任务示例 `presharedKey` 与真实上游不一致；两个目标版本 `infra/conf/wireguard.go` 均声明 `json:"preSharedKey"`。实现使用 **preSharedKey**，否则 Xray 静默忽略 PSK，run -test 仍会通过。不同时输出无效别名。此偏差已在实现前告知，并写入获授权修改的 docs/05。
2. **local_address 的版本差异**：26.3.27 使用 `10.7.0.2/24` 时真实 -test 失败，摘要 `interface address subnet should be /32 for IPv4 and /128 for IPv6`；26.10.21 同样配置通过。按任务范围继续允许 IPv4/CIDR 并原样渲染，不按版本猜能力、不静默改成 /32。golden 使用 `10.7.0.2/32` 与裸 IPv4，页面和文档注明最低版限制；其他前缀最终以实际二进制预检为准。
3. **streamSettings 实测**：在相同 /32 配置上，添加 `{network: 'raw'}`、以及 ws+tls，两个版本 -test 均通过，没有观察到“通用 streamSettings 一律非法”的约束。没有据此臆造 WireGuard 传输字段；本卡仅映射 WireGuard 自身设置，省略通用 streamSettings/Mux，旧值保留，不宣称 WireGuard 支持 ws/tls 包装。golden 对省略后的最终配置也均通过。
4. 不扩展 URI/订阅。只将新字段加入既有“分享链接填表前清理字段”清单，防止手工填过 WireGuard 后从其他 URI 填表残留密钥；没有新增 scheme 或解析路径。
5. 没有新增代码 TODO(design)。既有其他卡的 TODO 未改。尚未进行真实 Peer 的握手/端到端流量或真机 LuCI 浏览器验收；本卡验收的是配置生成与真实 run -test，不把预检通过等同于隧道可用。
