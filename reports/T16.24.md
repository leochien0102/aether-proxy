# T16.24 全站块一致性巡检

工作树 `aether-proxy-wt/T16.24`，分支 `feat/t16.24-block-sweep`，基线 `065fdfa`。改动仅含 LuCI、翻译、文档、测试和证据；未改后端、接口、事件、版本、Makefile 或 T16.19。

## 实现与规则对照

| 页面 | 块内结构 |
|---|---|
| 概览 | 运行状态工具、告警和动态状态同块；轮询不重挂启用开关与刷新选择器。流量/连接汇总同块，组件错误及重试留在组件表块。 |
| 访问控制 | 未列出设备策略及说明同块；设备表的添加按钮在表上方，空表占位仍由 LuCI 在表内渲染。表单原有重置和编辑逻辑不动。「默认模式」是只读摘要，不是编辑控件；修改入口保留在规则与 DNS 页。 |
| 规则与 DNS | 模式、DNS 表单、四个名单标签和规则数据分别成块。直连 DNS 检测、名单保存及规则数据更新在各自块的工具行；加载及错误不离开自己的块。 |
| 高级 | 原 LuCI 标签、选项和依赖留在一个块，原页级说明移至块头。此页没有块级工具行。 |
| 更新 | 更新策略、包清单和运行组件各自成块；清单块包含检查时间、进行中与结果、错误和包表。 |
| 日志 | 共享工具行仍是左侧「事件／原始日志」、右侧「清空／截断」。共享错误和两个面板也在同一块，切换标签不卸载共享行。 |

- 页级 `h2` 在块外。六页的 `ap.section` 块按可选 `h3` → 可选短说明 → 可选 `.aether-section-actions` → 主体排列；右侧操作反馈与按钮同行。高级、日志及更新清单的块由页标题承担命名，不重复渲染 `h3`；「运行中的组件」保留独立块标题。表格内行操作、原始日志筛选、错误旁的恢复按钮是对应主体的上下文控件。
- 访问控制的策略用法、DNS 检测的路径说明，以及手动安装与 Xray 迁移的长解释沿用原文放入 `title`。按钮名、运行状态、错误、必要校验及确认文案仍可见。PO 未引用条目为 0。
- 节点和订阅都采用**容器内横向滚动的真表格**：保留表头和列对齐，方便跨行对比，避免把状态与单行操作拆散。仅调整节点表包装与 CSS；两表的列定义、交互、订阅地址遮蔽均未改。Bootstrap、Argon 均验证 360 px 下两容器确实可滚动、行/表头仍按 `table-row`/`table-cell` 排版。
