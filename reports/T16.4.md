## 验收
### 标签页与保存
表单声明/DOM 顺序：intercept → log → boot → components → experimental。experimental 顶部由 LuCI `s.tab(name, title, description)` 渲染一行说明，之后只有「使用热力图」Flag。boot 页不再含此选项。

假 UCI 保存前：升级配置没有 stats 节。未经修改的表单显示关闭，parse 的写调用为 `[]`，不补默认配置。勾选保存的调用按顺序精确为：
```js
['add', 'aetherproxy', 'stats', 'stats']
['set', 'aetherproxy', 'stats', 'heatmap_enabled', '1']
```
保存后等价配置：
```uci
config stats 'stats'
    option heatmap_enabled '1'
```
取消后唯一写调用：
```js
['set', 'aetherproxy', 'stats', 'heatmap_enabled', '0']
```
保存后等价配置：
```uci
config stats 'stats'
    option heatmap_enabled '0'
```
有节时启用仅 set；旧配置已开启而未改动时无写调用，不迁移旧值。不创建 experimental 节。

### 关闭路径复核（不新增实现）
- 读 `aether-proxy/src/lib/monitor.uc`：`sample_usage()` 与 `flush_usage()` 均在 heatmap_enabled 非 true 时立即返回；不查询计数器、不读写历史。
- 现有 `tests/monitor/driver.uc` 断言：`heatmap-off: a closed switch never queries the nft counters`、`heatmap-off: nothing is aggregated`、`heatmap-persist-off: a closed switch never creates or writes usage.json`、`heatmap-persist-off: a closed switch never loads the history`。
- 读概览 view/model：沿用原开关判断，关闭不构建热力图、不读 history。T16.3 现有 `tests/luci/heatmap.test.js` 测试 `T16.3 view: disabled has original traffic structure, no heatmap and no history RPC` 验证原表格/连接结构及零 RPC；`T16.3 view: switch changes and backend disabled hide heatmap without replacing live values` 验证切换后的回退。
- 结论：关闭时概览页与正式版一致，且不采样、不写历史；本卡未改后端或概览页实现。
