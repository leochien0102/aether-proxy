## 反向验证与恢复

1. 将关联过滤 `if (rr.owner != name)` 改为永不跳过：`Q6 associated cname` 精确失败（错误取到最先的无关 A）。
2. TC 后重设完整 3000ms deadline：`Q5 UDP TCP share original deadline` 精确失败（本应 300ms 内失败的请求成功）。
3. 参数校验/网络前先用成功 LKG：`Q8 DNS precedes warm LKG` 精确失败（没有 DNS 请求、来源错误）。
4. 取消分支从立即 return 改为 continue：`Q9 real SIGTERM cancel-udp no retry write fallback` 精确失败（继续轮次并最终落到 LKG/事件路径）。

四项均要求 subprocess 退出 1 **且命中上述精确 AssertionError**，不能用语法错误、任意非零或超时冒充。
每次在 finally 恢复原文件字节，随后再次完整运行新入口和现有回归，全部通过。

## 偏差与待定

- 无设计行为偏差，无 `TODO(design)`。
- 新模块没有从探针复制解码器或第三方代码；使用既有 ucode/socket/uloop/fs 能力。核对固定 ucode 的 `lib/socket.c`：低层实例方法 `uc_socket_inst_connect()` 经 `uv_to_sockaddr()` 解析 literal 地址，不经过高层 `uc_socket_connect()` 的 getaddrinfo 路径。
- 本卡新增文档是任务卡明确允许的 `docs/03-dns.md` 接口契约，非扩改设计/编排。
- 生产函数均短于 100 行；受控 authority 的报文构造分派和 suite 场景调度较长，为保持每种 adversarial wire layout 和断言可直接对照，未拆成隐藏报文差异的通用解码器。
- TCP prefix 是 16 位，因此自然上限 65535；完成一个 frame 后不等待 EOF（DNS TCP 可以保持连接），拒绝已排队的多余数据；后续未到达的独立 TCP 数据不属于本次已收完整 frame。
- 不保证私有 child 归属、端口 ACL、TLS 证书校验、启动顺序或 readiness；没有创建 bootstrap child、改初始 tier/fail_open/已应用状态，也不宣称修复真机窗口。S15.3 的 aether-dns TLS 不支持及回退引擎 PKI 未验证边界保留。
