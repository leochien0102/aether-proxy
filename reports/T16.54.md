# T16.54 · APK 已安装 DNS 提供者识别

## 范围与结论

- 工作树：`/workspace/openwrt/aether-proxy-wt/T16.54`；分支：`fix/t16.54-apk-provides`。
- 起点：`2fe07260`；产品基线：`270b7ae5`。起点相对产品基线只有既有任务卡 `docs/tasks/T16.54.md`，本任务没有修改该卡。
- 根因：`installed_metadata()` 的 APK 分支仅执行 `apk list -I NAME`，只能解析版本，始终返回空 Provides。合法已安装提供者因此进入不必要的引擎迁移。
- 修复：只在 DNS 前置检查使用一次 `apk query --from installed --format json --fields name,version,provides NAME`，同时取得安装版本及声明。普通版本查询仍为一次 `list -I`，没有无条件附加查询。
- 没有改 UI、发布线、包版本或白名单外源码；没有推送、合 main、派发 CI、发版或操作设备。所有 APK 安装均在临时隔离 root，不安装到宿主根。

## 先读调用链，再确定边界

`update.uc` 的查询链已完整检查：

| 调用层 | 使用处 | 本次处理 |
| --- | --- | --- |
| `installed_metadata()` | `installed_version()` 包装层 | 默认不查询 Provides |
| `installed_version()` | 更新发现 `build_updates`、包安装前版本、安装后验证、伴随包更新、分组更新、桥接规划、链式推进及重新进入更新链 | 原 APK `list -I`；不加第二次查询 |
| `installed_metadata(..., true)` | `prerequisite_prepare()` 中 `aether-dns` / `chinadns-ng` 两个调用 | 各一次 installed-only JSON 查询 |
| `prerequisite_satisfied()` | 前置条件纯判断 | 安装版本证据、精确 `dns-engine` 声明、运行引擎下限分别检查 |

三种事实不混用：

1. JSON 记录必须是目标包名、有非空版本的已安装记录；空数组表示未安装，仓库候选不参与。
2. Provides 可缺省（已装但未声明），`dns-engine=1.0.0` 归一为能力名 `dns-engine`；包名或运行文件存在均不替代声明。
3. 原运行版本比较/引擎识别不变；声明能力不豁免运行版本下限。

非零查询返回 `ok:false` 并保留退出码及 stderr。损坏 JSON、错误形状/包名/版本/Provides 类型同样不能满足。没有已知满足的提供者时，APK 查询失败以 `CMD_FAILED` 阻止迁移；已装但未声明或运行版本过旧仍可走原自动迁移，只有缺少精确恢复路径等原保护条件才要求人工处理。一个已知合法提供者足以满足包能力条件，不要求另一个不存在/未知的提供者也满足。

opkg 的命令、解析、失败处理不变。纯判断增加 `version != null` 防止无安装版本的能力记录被当作已安装；正常 opkg installed 元数据不受影响。精确恢复版本（含 revision）、先下载验证恢复资产、安装后验证、失败回滚及运行版本下限均未放宽。

```text

```

来源：
- `https://raw.githubusercontent.com/openwrt/openwrt/openwrt-25.12/package/system/apk/Makefile`

主机构建步骤（产物只在 `/tmp/t1654-evidence/`，未安装到宿主）：

```sh
mkdir -p /tmp/t1654-evidence
cd /tmp/t1654-evidence
curl -fLs https://sources.openwrt.org/apk-3.0.5.tar.zst -o apk.tar.zst

  -Ddocs=disabled -Dhelp=enabled -Dlua_version=5.1 -Dlua=disabled \

  -Dcrypto_backend=openssl

# apk-tools 3.0.5, compiled for x86_64.
```

这是对应源码版本的真实 apk-tools，不声称是从设备提取或在设备执行的交叉编译二进制；没有做设备实证。离线测试包由该工具 `mkpkg` 创建，是真实 APK 文件，不是生产 release 包或手写数据库。
