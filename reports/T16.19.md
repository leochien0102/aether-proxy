## 验收

### 两态 DOM

LuCI 网格 DOM 测试替身，省略样式与监听器。URL 为合成夹具；显示态中 `&amp;` / `&lt;` 等是 HTML 序列化转义，页面仍按原始字符显示。

默认（或再次点击、重绘后）：

```html
<td><a role="button" tabindex="0" title="点击显示完整地址">https://host/…</a></td>
```

显示（同一个控件，无 `href`）：

```html
<td><a role="button" tabindex="0" title="点击隐藏完整地址">https://user:password@host/sub?token=fake&amp;x=&lt;b&gt;literal&lt;/b&gt;</a></td>
```

```html

    title="频繁切换出口 IP 可能导致部分网站/应用触发风控，建议只在必要时开启。"

</div>
```
