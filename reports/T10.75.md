## 场景对照

| 场景 | 结果/依据 |
| --- | --- |
| labels 顺序 n_z、n_a、n_b，当前 n_a | 下拉保持 n_z、n_a、n_b，仅 n_a 带当前后缀 |
| labels 非空且无当前节点 | 空值「未选择」在最前，后续维持声明顺序 |
| 无节点 | 仍返回空选项，不凭空添加占位 |
| 有效运行节点/配置回退节点 | 各状态保持声明顺序与唯一当前后缀，切换保护不变 |
| 当前节点行 | Probe、内置手柄、Edit；无 Delete |
| 其他节点行 | Probe、内置手柄、Edit、Delete；保留原始按钮对象、样式及不折行布局 |
| 桌面拖动/触摸排序 | 使用 SDK form.js 内置 dragstart/drop 与 touchmove/touchend；handleDrop/handleTouchEnd 调用 map.data.move 暂存段顺序 |
| 保存并应用 | 沿用 form.Map / LuCI 标准 Save & Apply 流程提交 UCI 段顺序，不新增即时写文件逻辑 |
| 订阅更新 | 后端未改；检查 sub.uc 的 make_plan/apply_changes：仅新节点创建段，已有节点修改选项而不重建/重排，因此新增追加、保留节点维持已有相对顺序；既有订阅测试全过 |
