### 2. JS 只加上下文，po 只加上下文与删除指定条目

使用以下命令同时验证两个逐字节约束。po 归一化保留原文件尾部换行；去重的是移除上下文后完全相同的条目块，因此也会检查菜单重复条目的原文与译文均未改变。

```bash
python3 - <<'PY'
import difflib
import re
import subprocess
from pathlib import Path

files = subprocess.check_output(['git', 'ls-files', 'luci-app-aether-proxy/htdocs'], text=True).splitlines()
js_files = [name for name in files if name.endswith('.js')]
for name in js_files:
    original = subprocess.check_output(['git', 'show', 'main:' + name])
    normalized = Path(name).read_bytes().replace(b", 'aether-proxy')", b')')
    assert normalized == original, name
print(f'PASS JS byte comparison: {len(js_files)} files identical to main after removing contexts')

name = 'luci-app-aether-proxy/po/zh_Hans/aether-proxy.po'
original = subprocess.check_output(['git', 'show', 'main:' + name], text=True)
without_context = re.sub(r'^msgctxt "aether-proxy"\n', '', Path(name).read_text(), flags=re.M)
normalized = '\n\n'.join(dict.fromkeys(without_context.split('\n\n')))
removed = 'msgid "This page has not been implemented yet."\nmsgstr "此页面尚未实现"\n\n'
assert removed in original
assert normalized == original.replace(removed, '')
print('PASS PO byte comparison: only the obsolete placeholder was removed; all translations unchanged')
print(''.join(difflib.unified_diff(original.splitlines(True), normalized.splitlines(True),
                                  fromfile='main PO', tofile='normalized task PO')), end='')
PY
```

实际输出：

```diff

+++ normalized task PO

-msgstr "此页面尚未实现"
-
```
