### 根因与现有扩展点边界

以下 `SDK` 指 `/workspace/openwrt/openwrt-actions/build/rockchip/build_dir/target-aarch64_generic_musl/root-rockchip`；安装树 JS 已压缩，行号可能一行包含多个方法。

1. `luci-app-aether-proxy/htdocs/luci-static/resources/aether-proxy/common.js:22–36` 只替换当前文档的 `ui.changes.displayChanges`。新文档不执行 common，就没有包装。
2. `SDK/usr/share/ucode/luci/template/view.ut:1–12` 按当前 view 加载依赖；包菜单与 Makefile 没有所有系统页面的摘要过滤注册点。`SDK/www/luci-static/resources/view/system/reboot.js:1` 只依赖 view/rpc/ui/uci，不依赖本包。
3. `SDK/www/luci-static/resources/ui.js:341–350` 从 `uci.changes()` 取原始记录并直接格式化值，不读取表单 password 元数据。表单密码遮蔽与摘要展示是两条不同链路。
4. 存在 `SDK/www/luci-static/resources/luci.js:182–191` 的 preload 消费路径，但其列表来自 `Session.getLocalData('preload')`；同文件 `:132–139` 使用按 session ID 键控的 **window.sessionStorage**。把 common 加入列表可以覆盖已注册标签页中的后续加载，**不能保证同一认证会话的其他已打开标签页、独立 sessionStorage、存储失效或未注册文档**。这会让窄化的“同标签页”回归通过，却不能保证凭据不会在会话其他页面显示；本轮未采用这个不完整绕过。
