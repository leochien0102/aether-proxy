# T16.80 · 正式 aether-dns ELF 的 strip 状态与打包收益核验（M19）

## 范围与基线

- 工作树：`/workspace/openwrt/aether-proxy-wt/T16.80`
- 分支：`audit/t16.80-dns-strip`
- 基线：`fbfef3b0`
- 核验目标：仅以 `aether-dns/Makefile` 当前钉定版本（`1.0.2-1`）的两份正式发布 ELF（`x86_64`、`aarch64_generic`）为输入，核实“上游已经 strip，打包无需重复处理（`RSTRIP:=:`）”是否成立，并分别量化**裸 ELF 差值**与**压缩包差值**。
- 边界遵守：仅变更 `reports/T16.80.md`；不改产品代码、Makefile、上游仓库或基线资产；所有 `strip` 与重打包均在 `/tmp` 临时副本上执行；不合 `main`、不推送、不触发 CI、不发版、不动设备。

## 核心结论

1. **原假设不成立（两份正式 ELF 均未 strip）**：
   - `aether-dns/Makefile:36-37`（`# Upstream ships it stripped and statically linked. RSTRIP:=:`）与上游 `aether-dns` 仓 `openwrt/Makefile:19-20`（`# The input binary is already stripped by the producer. RSTRIP:=:`）的注释均与实际发行字节不符。
   - 两份正式 ELF（SHA-256 与 `aether-dns/Makefile` 逐字一致）均处于 **`not stripped`** 状态，完整保留了 `.symtab` 与 `.strtab`（`x86_64` 含 `5,362` 条符号、`541,415 B`；`aarch64_generic` 含 `12,876` 条符号、`727,803 B`）以及 `.comment`（`61 B`）。
   - 同时确认：**两份二进制均无 `.debug_*` DWARF 调试段**，且为静态链接 musl ELF，**无 `DYNAMIC` 段与 `.dynsym`/`.dynstr` 动态符号表**；保留的 `.eh_frame`/`.eh_frame_hdr`/`.gcc_except_table` 属于运行时 `ALLOC` 展开表，不在常规 strip 范围内。
2. **生产端根因核实**：
   - 核对上游 `aether-dns` 仓 `v1.0.2`（`0c013b1`）与当前 `HEAD`：`Cargo.toml` 无 `[profile.release]` 配置（Cargo 默认 `release` profile 为 `debug = false`、`strip = "none"`，故无 `.debug_*` 但保留 `.symtab`/`.strtab`），仓内无 `.cargo/config.toml`；`.github/workflows/release.yml` 仅以 `RUSTFLAGS="-C target-feature=+crt-static -C relocation-model=static"` 执行 `cargo build --release --locked --target "$TARGET"` 后直接拷贝产物，未执行 `strip` 或 `-C strip=...`。
3. **收益量化（裸 ELF 与压缩包收益差异显著）**：
   - 裸 ELF 缩减（`llvm-strip --strip-all`）：`x86_64` 减 **`541,696 B`（`-529.00 KiB`，`-25.22%`）**，`aarch64_generic` 减 **`728,080 B`（`-711.02 KiB`，`-31.97%`）**。
   - 压缩包实际收益（符号表与字符串表高度可压缩，**不可将裸字节缩减等同于打包或固件节省**）：
     - **等条件重打包 `.ipk`（`fakeroot` + OpenWrt `scripts/ipkg-build`，`gzip -n`）**：`x86_64` 净省 **`112,846 B`（`-110.20 KiB`，`-13.55%`）**，`aarch64_generic` 净省 **`136,557 B`（`-133.36 KiB`，`-16.25%`）**。
     - **等条件强压缩对照（仅作高压缩包/固件量级参考）**：`zstd -19` 分别省 **`80,638 B`（`-78.75 KiB`，`-11.57%`）** / **`99,873 B`（`-97.53 KiB`，`-14.29%`）**；`xz -9` 分别省 **`75,808 B`（`-74.03 KiB`，`-11.77%`）** / **`90,468 B`（`-88.35 KiB`，`-14.90%`）**。
4. **后续处理建议层级**：
   - 压缩包实测有约 **110–133 KiB（13.55%–16.25%，`.ipk`）** 的稳定净收益，值得后续处理；**建议在上游 `aether-dns` 生产端处理，而非在下游 `aether-proxy` 打包层取消 `RSTRIP:=:`**：
     - 在 `aether-dns` 的 `Cargo.toml` 中为 `[profile.release]` 增加 `strip = "symbols"`（或在 `release.yml` 显式 strip 并加入 `file`/`readelf` 校验门禁），使上游 Release 裸二进制、上游 `.ipk`/`.apk` 与下游 feed 包统一受益，同时让两份 Makefile 注释重新与事实一致；
     - 避免在下游 OpenWrt SDK 阶段对预编译静态 Rust ELF 二次跑各版本 `strip`/`sstrip`，减少不同工具链对段表/哈希的额外变动；
     - 待上游发新版本后，本仓 `aether-dns/Makefile` 仅常规升级 `PKG_VERSION` 与 `PKG_HASH` 即可，保持 `RSTRIP:=:` 不变。

### 1. 工具版本、打包环境与口径说明

- **打包性质**：**等条件重打包（非 CI/SDK 实包）**。
  - `.ipk`：直接调用本地 OpenWrt 树中的真实脚本 `/workspace/openwrt/openwrt-actions/build/rockchip/scripts/ipkg-build`（内部执行 `tar --format=gnu --numeric-owner --sort=name --mtime="$TIMESTAMP" | gzip -n -` 生成 `data.tar.gz`、`control.tar.gz`，再与 `debian-binary` 同参数打包压缩为 `.ipk`），复用本地 `build_dir/target-aarch64_generic_musl/aether-dns-1.0.2/ipkg-aarch64_generic/aether-dns/CONTROL/{control,postinst,prerm}` 元数据（按架构替换 `Architecture:` 字段，并将 `Installed-Size:` 归零交由 `ipkg-build` 回填）。

## 核验缺口与边界声明

以下项在本机离线/单卡范围内无法直接实测，按任务卡要求如实列明，**未用宿主构建替代**：

1. **OpenWrt 25.12 `.apk`（APKv3）实包**：本机无 `apk`（`apk mkpkg`）工具且不触发 CI/SDK，未直接生成 `.apk` 实包；其压缩收益可参考同条件 `gzip`/`zstd` 差值范围（约 `81–137 KiB`），具体精确字节需在 OpenWrt 25.12 SDK 中实打验证。
2. **整机固件 SquashFS 差值**：未构建 OpenWrt 固件镜像；SquashFS 实际节省受块大小与跨文件字典压缩影响，不能将裸 ELF 减少量（`529 KiB` / `711 KiB`）等同于固件 Flash 节省量，仅以 `zstd -19` / `xz -9` 差值（约 `74–98 KiB`）作量级参考。
3. **`aarch64_generic` 剥离后未做运行时执行验证**：宿主为 `x86_64` 且未执行 `qemu-aarch64` 仿真，因此 `aarch64_generic` 无剥离后的运行时执行证据；静态层面仅通过上节 `readelf -lW` 全部 `LOAD` 程序头字段及逐字节比对确认程序头字段未变、且除 `LOAD[0]` 首部 64 字节 ELF 头内的节表元字段（`e_shoff`/`e_shnum`/`e_shstrndx`）外所有 `LOAD` 载荷字节未变。
4. **本地 OpenWrt 既有 `.ipk` 实包文件缺失**：`/workspace/openwrt/openwrt-actions/build/rockchip/staging_dir/packages/rockchip/aether-dns_1.0.2-1_aarch64_generic.ipk` 指向的 `bin/packages/...` 目标文件已清理，故 `.ipk` 对照采用同一 OpenWrt 树中的 `scripts/ipkg-build` 与 `CONTROL` 元数据在 `fakeroot` + `umask 0022` 下做等条件重打包（原件 `data.tar.gz` 字节数 `841,907 B` 与既有 `CONTROL/control` 记录的 `Installed-Size` 逐字节一致）。

## 可复跑命令

以下命令为生成本报告全部实测数字（含 `llvm-strip`、GNU `strip`、`ipkg-build`、`zstd -19`、`xz -9`、`LOAD` 程序头及段字节比对、原件/剥离后大小与差值、ELF 与 IPK SHA-256）的完整脚本。若离线复跑且已有本地 `x86_64` 二进制，可通过 `X86_SRC=/path/to/aether-dns-1.0.2-r1-x86_64` 传入；否则自动只读下载：

```bash
set -euo pipefail
umask 0022
export LC_ALL=C TZ=UTC PKG_SOURCE_DATE_EPOCH=1794642208

WORK=$(mktemp -d /tmp/t16.80-repro.XXXXXX)
trap 'rm -rf "$WORK"' EXIT

# 1) 获取并按 aether-dns/Makefile 校验两份正式发布 ELF
X86_ORIG="${X86_SRC:-$WORK/aether-dns-1.0.2-r1-x86_64}"
if [ ! -f "$X86_ORIG" ]; then
  curl -fsSL -o "$X86_ORIG" \
    https://github.com/leochien0102/aether-dns/releases/download/v1.0.2/aether-dns-1.0.2-r1-x86_64
fi
ARM_ORIG="${ARM_SRC:-/workspace/openwrt/openwrt-actions/shared/dl/aether-dns-1.0.2-r1-aarch64_generic}"
if [ ! -f "$ARM_ORIG" ]; then
  ARM_ORIG="$WORK/aether-dns-1.0.2-r1-aarch64_generic"
  curl -fsSL -o "$ARM_ORIG" \
    https://github.com/leochien0102/aether-dns/releases/download/v1.0.2/aether-dns-1.0.2-r1-aarch64_generic
fi

IPKG_BUILD=/workspace/openwrt/openwrt-actions/build/rockchip/scripts/ipkg-build
CTRL_SRC=/workspace/openwrt/openwrt-actions/build/rockchip/build_dir/target-aarch64_generic_musl/aether-dns-1.0.2/ipkg-aarch64_generic/aether-dns/CONTROL
ARM_GNU_STRIP=/workspace/openwrt/openwrt-actions/build/rockchip/staging_dir/toolchain-aarch64_generic_gcc-13.3.0_musl/bin/aarch64-openwrt-linux-musl-strip

echo "=== Packaging environment ==="
echo "host_uid=$(id -u) host_gid=$(id -g) fakeroot_uid=$(fakeroot id -u) fakeroot_gid=$(fakeroot id -g) umask=$(umask) PKG_SOURCE_DATE_EPOCH=$PKG_SOURCE_DATE_EPOCH"
echo "fakeroot=$(fakeroot --version)"

echo "=== 1) SHA-256 verification against aether-dns/Makefile ==="
sha256sum -c - <<EOF
d7ad176292664bb5f4d070d3d3ed98b483c2403fc6ef87efa1ff1e0483a499eb  $X86_ORIG
9c21f7d9d35a2b9784719bebb17f88dce3fcba0b446acb06bb38cbec4c95e223  $ARM_ORIG
EOF

echo "=== 2) ELF header, dynamic, section & symbol inspection ==="
file "$X86_ORIG" "$ARM_ORIG"
for f in "$X86_ORIG" "$ARM_ORIG"; do
  echo "--- $f ---"
  readelf -h "$f" | grep -E 'Class:|Type:|Machine:'
  readelf -d "$f" || true
  readelf -SW "$f" | grep -E 'Name|symtab|strtab|dynsym|dynstr|debug|comment|eh_frame|gcc_except_table|shstrtab'
  readelf -sW "$f" | grep '^Symbol table' || true
done

echo "=== 3) Producer build parameters (upstream aether-dns v1.0.2) ==="
git -C /workspace/openwrt/aether-dns show v1.0.2:Cargo.toml
git -C /workspace/openwrt/aether-dns show v1.0.2:.github/workflows/release.yml | sed -n '45,75p'
git -C /workspace/openwrt/aether-dns show v1.0.2:openwrt/Makefile

echo "=== 4) Strip on temp copies, LOAD verification & equivalent-condition packaging ==="
for spec in "x86_64:$X86_ORIG:strip" "aarch64_generic:$ARM_ORIG:$ARM_GNU_STRIP"; do
  IFS=':' read -r arch orig gnu_strip <<< "$spec"
  echo ""
  echo "### ARCH: $arch ###"

  cp "$orig" "$WORK/$arch.orig"
  cp "$orig" "$WORK/$arch.llvm_stripped"
  cp "$orig" "$WORK/$arch.gnu_stripped"
  chmod 0755 "$WORK/$arch.orig" "$WORK/$arch.llvm_stripped" "$WORK/$arch.gnu_stripped"

  llvm-strip --strip-all "$WORK/$arch.llvm_stripped"
  "$gnu_strip" --strip-all "$WORK/$arch.gnu_stripped"

  echo "--- Program Headers (LOAD) & segment byte comparison ---"
  python3 - "$WORK/$arch.orig" "$WORK/$arch.llvm_stripped" "$WORK/$arch.gnu_stripped" <<'PY'
import subprocess, sys

def parse_loads(path):
    out = subprocess.check_output(["readelf", "-lW", path], text=True)
    rows = []
    with open(path, "rb") as f:
        for line in out.splitlines():
            parts = line.split()
            if parts and parts[0] == "LOAD":
                typ, off, vaddr, paddr, filesz, memsz = parts[:6]
                align = parts[-1]
                flg = " ".join(parts[6:-1])
                o, sz = int(off, 16), int(filesz, 16)
                f.seek(o)
                rows.append(((typ, off, vaddr, paddr, filesz, memsz, flg, align), f.read(sz)))
    return rows

orig = parse_loads(sys.argv[1])
for name, p in [("llvm_stripped", sys.argv[2]), ("gnu_stripped", sys.argv[3])]:
    cur = parse_loads(p)
    ph_equal = [r[0] for r in cur] == [r[0] for r in orig]
    print(f"  {name}: LOAD_count={len(cur)} phdr_fields_identical={ph_equal}")
    for i, ((oh, ob), (_, cb)) in enumerate(zip(orig, cur)):
        if ob == cb:
            print(f"    LOAD[{i}] (Off={oh[1]} FileSiz={oh[4]} Flg={oh[6]}): bytes_identical=True")
        else:
            diffs = [idx for idx, (a, b) in enumerate(zip(ob, cb)) if a != b]
            print(f"    LOAD[{i}] (Off={oh[1]} FileSiz={oh[4]} Flg={oh[6]}): bytes_identical=False diff_count={len(diffs)} diff_offsets={[hex(x) for x in diffs]}")
PY

  if [ "$arch" = "x86_64" ]; then
    echo "--- x86_64 runtime check (-V) ---"
    for v in orig llvm_stripped gnu_stripped; do
      echo "  $v: $("$WORK/$arch.$v" -V)"
    done
  fi

  for v in orig llvm_stripped gnu_stripped; do
    pdir="$WORK/pkg_${arch}_${v}"
    odir="$WORK/out_${arch}_${v}"
    mkdir -p "$pdir/usr/bin" "$pdir/CONTROL" "$odir" "$odir/inspect"
    cp "$WORK/$arch.$v" "$pdir/usr/bin/aether-dns"
    chmod 0755 "$pdir" "$pdir/usr" "$pdir/usr/bin" "$pdir/usr/bin/aether-dns"
    cp "$CTRL_SRC/postinst" "$CTRL_SRC/prerm" "$pdir/CONTROL/"
    chmod 0755 "$pdir/CONTROL/postinst" "$pdir/CONTROL/prerm"
    sed "s/^Architecture: .*/Architecture: $arch/; s/^Installed-Size: .*/Installed-Size: 0/" \
      "$CTRL_SRC/control" > "$pdir/CONTROL/control"
    chmod 0644 "$pdir/CONTROL/control"

    fakeroot "$IPKG_BUILD" "$pdir" "$odir" >/dev/null
    ipk="$odir/aether-dns_1.0.2-1_${arch}.ipk"
    tar -xzf "$ipk" -C "$odir/inspect"

    tar -C "$pdir" --exclude=CONTROL --format=gnu --numeric-owner --owner=0 --group=0 --sort=name \
      --mtime="@$PKG_SOURCE_DATE_EPOCH" -cpf - ./usr | zstd -q -19 -c > "$odir/data.tar.zst"
    tar -C "$pdir" --exclude=CONTROL --format=gnu --numeric-owner --owner=0 --group=0 --sort=name \
      --mtime="@$PKG_SOURCE_DATE_EPOCH" -cpf - ./usr | xz -9 -c > "$odir/data.tar.xz"

    printf '%s %s %s %s %s %s %s %s\n' \
      "$v" \
      "$(stat -c '%s' "$WORK/$arch.$v")" \
      "$(sha256sum "$WORK/$arch.$v" | awk '{print $1}')" \
      "$(stat -c '%s' "$ipk")" \
      "$(sha256sum "$ipk" | awk '{print $1}')" \
      "$(stat -c '%s' "$odir/inspect/data.tar.gz")" \
      "$(stat -c '%s' "$odir/data.tar.zst")" \
      "$(stat -c '%s' "$odir/data.tar.xz")" >> "$WORK/$arch.metrics"
  done

  echo "--- Metrics & Deltas ---"
  python3 - "$WORK/$arch.metrics" <<'PY'
import sys
rows, order = {}, []
with open(sys.argv[1]) as f:
    for line in f:
        v, raw, esha, ipk, isha, dtg, zst, xz = line.split()
        rows[v] = dict(raw=int(raw), esha=esha, ipk=int(ipk), isha=isha, dtg=int(dtg), zst=int(zst), xz=int(xz))
        order.append(v)

base = rows["orig"]
for v in order:
    r = rows[v]
    print(f"  [{v}] elf_sha256={r['esha']} ipk_sha256={r['isha']}")
    for k, label in [("raw", "raw_elf"), ("ipk", "ipk"), ("dtg", "data.tar.gz"), ("zst", "data.tar.zst(-19)"), ("xz", "data.tar.xz(-9)")]:
        if v == "orig":
            print(f"    {label:18s}: {r[k]:9d} B (baseline)")
        else:
            d = r[k] - base[k]
            print(f"    {label:18s}: {r[k]:9d} B | delta={d:+9d} B ({d/1024:+7.2f} KiB, {d/base[k]*100:+6.2f}%)")
PY
done
```
