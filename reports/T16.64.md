## 共享解析器调用方与影响范围对照

改动前先核对了 `aether-proxy/src/lib/uri.uc` 内共享函数及其外部调用方：

- 外部模块调用方：
  - `aether-proxy/src/lib/node.uc`：`parse_node()` 与 `import_node()` 均调用 `uri.parse_line()`；
  - `aether-proxy/src/lib/sub.uc`：订阅更新流程调用 `uri.parse_body()`（逐行调用 `parse_line()`）。
- 内部共享函数对照：

| 共享函数 | 调用方 | 修前行为 | 修后行为 | 范围影响说明 |
| --- | --- | --- | --- | --- |
| `transport(value)` | `copy_common()`（VLESS/Trojan） | 仅接受 `'tcp'` → `'raw'`；`'raw'` 返回 `null`（`unsupported_transport`） | `'raw'` 与 `'tcp'` 均归一化为 `'raw'` | 同一节点 `type=raw` 与 `type=tcp` 解析结果逐字段一致；未知传输（如 `kcp`、`quic`、`RAW`）仍返回 `unsupported_transport` |
| `transport(value)` | `parse_vmess()`（VMess） | `data.net == 'raw'` 返回 `null`（`unsupported_transport`） | `data.net == 'raw'` 与 `'tcp'` 同样归一化为 `'raw'` | 共享函数带来 VMess `net: "raw"` 的一致归一化，已补充单测锁定；未改动 VMess gRPC 映射 |
| `parse_authority(authority)` | `parse_standard()`（VLESS/Trojan） | 直接按 `host:port` 校验，不剥离尾斜杠；`host:443/` 报 `malformed` | 仅剥离末尾单个空路径 `/`（`replace(authority, /\/$/, '')`），随后沿用原有 IPv6/host/端口严格校验 | 接受 `host:port/`，但仍严格拒绝非空路径（`/extra`、`/extra/`）、双斜杠（`//`）及非法/缺失端口（`:0/`、`:65536/`、`:abc/`、`:/`、无端口） |
| `parse_authority(authority)` | `parse_ss()`（Shadowsocks） | 调用前自行执行 `replace(authority, /\/$/, '')` | 移除调用方重复剥离，统一复用 `parse_authority()` 的单次剥离 | 行为完全保持不变，且不会对 `//` 二次剥离（单测已覆盖 `ss://...@ss.example:8388//#bad` 仍报 `malformed`） |
| `parse_authority(authority)` | `parse_new_protocol()`（socks/socks5/http/wireguard/hysteria2/hy2） | 调用前自行执行 `replace(..., /\/$/, '')` | 移除调用方重复剥离，统一复用 `parse_authority()` 的单次剥离 | 行为完全保持不变，且不会对 `//` 二次剥离（单测已覆盖 `hy2://auth@h.example:443//...` 仍报 `malformed`） |

## 改动说明

1. **`aether-proxy/src/lib/uri.uc`**：
   - `parse_authority()`：在入口处仅剥离最多一个尾部空路径 `/`（`authority = replace(authority, /\/$/, '')`），不放宽 IPv6、空主机名、非纯数字端口或 `1..65535` 范围校验；同步移除 `parse_ss()` 与 `parse_new_protocol()` 中重复的 `/\/$/` 剥离，避免双斜杠被连续剥离。
   - `transport()`：增加 `case 'raw':` 落入 `case 'tcp': return 'raw';`，复用现有 `'raw'` 归一化结果，保留未知传输拒绝逻辑。
   - `parse_standard()` 仍通过 `parse_fragment()` → `split_once(..., '?')` → `parse_query()` 解析查询参数和片段标签，因此 query 中 URL 编码的路径值（如 `path=%2Fws%2Fv1`、`spx=%2Fedge%2Fpath`）与 fragment 标签（如中文/空格编码）原样保留。
2. **`tests/unit/uri.uc`**：
   - 新增 32 条脱敏回归用例：
     - VLESS 4 组等价写法（`type=tcp`/`type=raw` × 有无单个尾斜杠 `/`），含 `spx=%2Fedge%2Fpath` 与中文/空格 fragment，逐字段对比预期对象；另覆盖 `type=ws` 下 `path=%2Fws%2Fv1` 与尾斜杠并存；
     - Trojan 4 组等价写法（`type=tcp`/`type=raw` × 有无单个尾斜杠 `/`），含 `alpn=h2,http%2F1.1` 与中文/空格 fragment；另覆盖无 query 的裸尾斜杠加 fragment；
     - 共享函数影响对照：VMess `net=raw` 归一化为 `transport=raw`；`ss://` 与 `hy2://` 双斜杠仍报 `malformed`；
     - 负向边界：未知传输（`quic`、`kcp`、大写 `RAW`）、非空路径（`/extra`、`/extra/`）、双斜杠（`//`）、非法/缺失端口（`:0/`、`:65536/`、`:abc/`、`:/`、无端口）。
3. **`tests/node/parse.py`**：
   - 现有语料循环已自动对 `tests/unit/uri.uc` 全部新增 `line` 用例执行实际 `aether-proxy node parse` 与 `aether-proxy node import`；
   - 新增 T16.64 实入口等价性与去重断言：通过 `aether-proxy node import` 分别导入 VLESS 和 Trojan 的 4 组等价链接，断言落盘 UCI 选项逐字段完全一致，并验证导入 `type=tcp` 后再导入 `type=raw` + 尾斜杠 `/` 时命中强键去重（`duplicate: true`，返回同一节点 ID）。
