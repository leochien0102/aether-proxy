把 T11.14/T11.15 的 compatibility 能力接进真实发布链路：RC 可携带受审的
`bridges/compatibility.json`，channel promote 下载并逐字节校验历史 bridge 资产，
publisher 收到同一份文件与字节后签名发布。返工按复核意见完成：统一 canonical
version 规则（真实命名 fixture 证明不误杀）、删除不可晋升的 ipk-only 草稿、

## 返工内容（对照复核意见）

1. **统一版本规范**：canonical version = 包文件名里的版本串（= 包管理器报告的
   已安装版本），manifest、兼容步骤、设备比较全部用它，不从 Makefile 重新拼装。
   真实渲染有两种（以实际 SDK 产物为准，h28k-test/pkg061-063，0.6.3 已成功经
   build.py 发布证明同包 ipk/apk 同版本串）：标准包 `-<release>`
   （aether-proxy `0.6.3-1`、aether-xray `26.10.31-1`、chinadns-ng `2025.08.09-1`）、
   luci.mk 包 `-r<release>`（luci-app-aether-proxy `0.6.3-r1`）、i18n 带动态版本
   无 release。RC 与 promote 共用 `tools/channel/build.py::canonical_version()`：
   按 Makefile 接受两种渲染、原样返回文件名版本；promote 从 RC commit 原样取
   build.py，两边规则必然一致。原 `PKG_VERSION-rPKG_RELEASE` 假设已删除。
2. **删除 compatibility 草稿**：`bridges/compatibility.json` 不再入库（首轮的
   ipk-only 草稿已删）。首个真实链在全部步骤 ipk+apk 字节可核对后由维护者提交，
   此前 RC/promote 走无链路径。测试链全部是合成 fixture（注释与报告均注明），
   不伪装成已发布链。
3. **版本/目标校验**：文档化对应关系（docs/08「包版本写法」）：兼容终点步 ==
   manifest aether-proxy current version == RC 构建包版本 == 设备已安装串；
   target tag（`v<version>-r<release>`）是 tag 规范，经 rc-manifest `target_tag`
   单独绑定；release 后缀精确匹配（设备端 `exact-release-alias` 冻结 `0.6.3-1`
   不是 `0.6.3-r1` 的别名）。promote 新增终点步 fail-fast（先于任何 bridge 下载）。
4. **测试**：默认 fixture 改为真实命名；新增两种渲染、混合格式、Makefile 不符、
   终点步不符等用例；无链普通 RC/promote/publish 回归全部原样保留。

## 偏差与待定

- `tools/channel/build.py` 本次有改动（新增 `canonical_version`）：首轮报告把它列为
  超范围，返工意见「RC 和 promote 必须使用同一个 canonical version 解析规则」使
  共享函数成为唯一可行实现（promote 只 fetch 这一个发布工具）。build.py 不是产品
  代码（`aether-proxy/`、`luci-app-aether-proxy/` 未动，版本未动）。
- apk 文件名版本没有本地实物可核对（工作区无任何 .apk）。间接证据：0.6.3 已成功
  经 `build.py collect_packages` 发布，该函数要求同包跨格式版本唯一 → 真实 apk
  文件名版本与 ipk 一致。canonical 规则对两种渲染都接受，因此即使 SDK 行为变化
  也不会误杀；混合渲染则会被既有「一包一版本」规则拒绝。
- RC 步骤新增对 checkout 内 `tools/channel/build.py` 的依赖（import）。测试的 fake
  checkout 相应补了 tools 软链；真实 checkout 天然具备。
- 首个真实 bridge 链的维护者清单（写入 docs/08）：全步骤 ipk+apk 字节可核对
  sha256/size 后提交 `bridges/compatibility.json`，min_from 用前驱的实际安装串，
  终点步等于发布版本串。
