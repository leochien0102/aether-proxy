### 宿主 ucode `fs.stat()` 实际字段

使用仓库宿主 ucode 对真实文件执行：

```bash
bash tests/host/ucode -e "import * as fs from 'fs'; printf('%.J\n', fs.stat('aether-proxy/src/lib/reload.uc'));"
```

返回结果（节选字段名与真实输出）：

```json
{
	"dev": { "major": 8, "minor": 48 },
	"perm": { "setuid": false, "setgid": false, "sticky": false, "user_read": true, "user_write": true, "user_exec": false, "group_read": true, "group_write": false, "group_exec": false, "other_read": true, "other_write": false, "other_exec": false },
	"inode": 35151335,
	"mode": 420,
	"nlink": 1,
	"uid": 1000,
	"gid": 1000,
	"size": 31457,
	"blksize": 4096,
	"blocks": 64,
	"atime": 1795421147,
	"mtime": 1795421093,
	"ctime": 1795421093,
	"type": "file"
}
```

结论：宿主 ucode `fs.stat()` 的 inode 字段名为 `inode`，不存在 `ino`。旧代码 `sprintf('%.J', [ st.size, st.mtime, st.ino ])` 使第三分量恒为 `null`，因此在原路径以等大小、等 `mtime` 文件原子 `rename` 替换时签名不变，reload 漏掉 `-V` 版本探测与 `chinadns-ng` 重启。
