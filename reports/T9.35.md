## 原有断言变更（逐条）

只更改与本条配置启用门槛有关的八条 notices 预期，其余断言不变：

| 原断言名 | 原预期 → 新预期 | 原因 |
|---|---|---|
| `ssr-plus nil plus boot` | `notice(boot=True)` → `[]` | 主服务器 `nil` 表示配置停用，仅自启不提示。 |
| `ssr-plus missing package still boot enabled` | `notice('ssr-plus', boot=True)` → `[]`，名称改为 `ssr-plus missing package plus boot` | 配置包缺失视为未启用，不能只靠自启提示。 |
| `passwall missing package still boot enabled` | `notice('passwall', boot=True)` → `[]`，名称改为 `passwall missing package plus boot` | 同上，仅自启不构成冲突。 |
| `passwall2 missing package still boot enabled` | `notice('passwall2', boot=True)` → `[]`，名称改为 `passwall2 missing package plus boot` | 同上。 |
| `homeproxy missing package still boot enabled` | `notice('homeproxy', boot=True)` → `[]`，名称改为 `homeproxy missing package plus boot` | 同上。 |
| `openclash missing package still boot enabled` | `notice('openclash', boot=True)` → `[]`，名称改为 `openclash missing package plus boot` | 同上。 |
| `nikki missing package still boot enabled` | `notice('nikki', boot=True)` → `[]`，名称改为 `nikki missing package plus boot` | 同上。 |
| `unreadable foreign package is not configured` | `notice(boot=True)` → `[]` | 不可读包视为未启用，boot 仅作参考。 |

每条仍严格比较完整 notices 数组，未改为子集、未跳过检查。新增十二例为六插件的启用且自启开、停用且自启开两类。
