### 悬停、点击/点按、聚焦证据

- 悬停：图标 title 精确等于既有 msgid 的中文「只影响 TCP；UDP 始终按原策略代理。」；测试同时断言气泡文本等于 title。悬停交给浏览器原生 title，而非仅 CSS hover。
- 点击：调用实际图标 click 回调，断言气泡 hidden 从 true → false → true，aria-expanded 同步 false → true → false；preventDefault 阻止 label 默认激活下拉。
- 键盘：调用实际 focus 回调，断言气泡可见；blur 隐藏；Enter/空格可切换且阻止默认行为。tabindex=0、role=button 与中文 aria-label 均有断言。
- 触摸：模拟 pointerdown → focus → click，首个点按保持可见，第二个 pointerdown → click 隐藏。pointerdown 记住聚焦之前的开闭状态，避免“focus 打开后 click 立即关闭”。不依赖 title 或 hover 才能读提示；离开焦点隐藏。未操作手机或真实触屏设备，证据边界是实际事件处理函数与可观测 DOM 状态测试。
