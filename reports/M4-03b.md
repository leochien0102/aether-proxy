### T13 三次变异

命令：`python3 tests/update/mutate-prerequisite.py`。

1. `return run_ok && pkg_ok;` → `return run_ok;`。T3 错误跳过依赖，完整安装序列不符。
2. `if (prior == null || prior.version != installed.version)` → `if (prior == null)`。T7 错误自动替换日期版，不再零安装拒绝。
3. `install_target` 中暂用 `{ ok:true }` 代替 prepare，并将真实 prepare 移到 `install()` 回调执行之后。T10 完整调用/事件序列变成 backend 在前，断言失败。

实际输出：

```text
PASS  M4-03b T13 pkg_ok: exit 1; FAIL  M4-03b T3 prerequisite transaction
PASS  M4-03b T13 pkg_ok: original bytes restored
PASS  M4-03b T13 exact_recovery: exit 1; FAIL  M4-03b T7 prerequisite transaction
PASS  M4-03b T13 exact_recovery: original bytes restored
PASS  M4-03b T13 engine_order: exit 1; FAIL  M4-03b T10 prerequisite transaction
PASS  M4-03b T13 engine_order: original bytes restored
```

恢复方式：每轮保存原文件 bytes，测试后 write_bytes(original) 并校验相等；外层 finally 再恢复，断言或测试异常也不保留变异。恢复后正常更新套件再次 944 passed / 0 failed。
