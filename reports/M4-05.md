### 降级参数证据

SDK 版本依据：`spikes/S5/README.md:111` 记录 25.12.5 SDK 使用 apk-tools 3.0.5。
本次只读上游固定 tag 源码（未复制第三方代码），核对：

- https://github.com/alpinelinux/apk-tools/blob/v3.0.5/src/app_add.c ：`ADD_OPTIONS` 无 `--allow-downgrade`；`add_main()` 读本地文件后调用 `apk_dep_from_pkg()`，然后加入 world 并求解提交。
- https://github.com/alpinelinux/apk-tools/blob/v3.0.5/src/package.c ：`apk_dep_from_pkg()` 将该包 hash 固定为 `APK_DEPMASK_CHECKSUM` 依赖，不是选择仓库最新版。因此本地指定旧资产可替换日期版，无需额外降级开关。
- https://github.com/alpinelinux/apk-tools/blob/v3.0.5/src/apk.c ：全局选项也无 `--allow-downgrade`；`--force-old-apk` 不是包版本降级开关。
- opkg 的日期版 → 1.0.0 是降级，复用现有 `install_package(..., previous=true)` 的 `--force-downgrade`；不修改产品行为。
