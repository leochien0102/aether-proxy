## 根因梳理与最小修复

### 1. 所有统计发布入口梳理

`aether-proxy/files/aether-proxy-logfilter.awk` 中所有 `write_stats()` 入口：

| 入口 | 旧版 (`afeaf3d0`) | 新版（T16.60） | 说明 |
| --- | --- | --- | --- |
| `BEGIN` | 无条件写 `(0, 0)` | 保留 | 会话初始快照 |
| 放行分支 | `total_accepted == 1 \|\| now - last_stats_write >= 5 \|\| total_accepted - last_stats_accepted >= 50` | 保留 | 原有放行进度不变 |
| 丢弃首条 (`++dropped == 1`) | `summary()` → `write_stats()` | 保留 | 即时输出限流摘要并立即发布可读统计 |
| 连续丢弃 (`++dropped > 1`) | **每行无条件调用 `write_stats()`** | `else if (now - last_stats_write >= 5) write_stats()` | 同秒洪峰不再逐条 fork `/bin/sh`；持续丢弃满 5 秒且有新输入时刷新，无后台定时器 |
| 丢弃段结束 (`finish_drops()`) | `dropped > 1` 时 `summary()` → `write_stats()` | 保留 | 恢复放行或 EOF 时输出整段汇总并发布统计 |
| 去重汇总 (`repeat_summary()`) | `if (emitted) write_stats()` | `if (emitted && stats_dirty) write_stats()` | 摘要照旧输出，仅当统计计数有变化时写盘 |
| `END` | 无条件 `write_stats()` | `if (stats_dirty) write_stats()` | 若 `finish_drops()`/`repeat_summary()` 尚未写出最新计数则补写，保证 EOF 精确且无冗余重写 |

### 2. 原子发布与失败保护（`stats_writer`）

- 仍先由 `/bin/sh` 消费 `IFS= read -r line`，避免 `awk` 侧管道写触发 `SIGPIPE` 中断子进程日志 FIFO。
- 保留不安全目标类型拒绝：`[ ! -L "$1" ] || exit 1`、`[ ! -e "$1" ] || [ -f "$1" ] || exit 1`（拒绝符号链接、悬空符号链接、目录、FIFO 等非常规目标）。
- 路径目录用 POSIX 参数展开 `case "$1" in */*) dir=${1%/*}; [ -n "$dir" ] || dir=/ ;; *) dir=. ;; esac` 与前导 `-` 防护提取，全流程双引号保护元字符。
- 在同目录以 `umask 077` + `mktemp "$dir/.logstats.XXXXXX"` 建立独占 `0600` 临时文件（后缀不为 `.logstats`，不会被 `aether-proxy log stats` 扫描），完整写入 JSON 后用 `mv -f -- "$tmp" "$1"` 原子替换目标文件。
- 写临时文件或 `mv` 失败时立即执行 `rm -f -- "$tmp"` 清理自身临时文件并返回非 0；`awk` 见 `close(stats_writer) != 0` 后置 `stats = ""` 停写本会话统计，不破坏已有可读快照，不影响 FIFO 消费、后续日志放行与 EOF 收尾。
- 不含 `2>/dev/null` 或 `|| true`，不增加常驻进程、新依赖或 flash 写入。

## 实时进度、原子替换与失败路径证据

均在 `tests/daemon/logfilter.py`（宿主 `awk` 与 `busybox awk` 双解释器）和 `tests/cli/log-stats.py`（双解释器）中实跑验证通过：

1. **首次丢弃与持续丢弃进度（EOF 前可见）**：
   - 耗尽 120 条滚动分钟额度后，在 `t=105` 送入首丢 `105 first-drop`，EOF 前即时输出首丢摘要且 `.logstats` 立即更新为 `(120, 1, 105, 105)`。
   - 随后在 `t=105..109`（距上次写入 `< 5` 秒）连续送入 50 条不同丢弃消息，并在 `t=110`（满 5 秒）送入 `110 five-sec-drop`：`.logstats` 更新为 `(120, 52, 105, 110)` 且期间 `IN_MOVED_TO` 增量精确为 `1`（证明 50 条子 5 秒丢弃全部被消费且新增写入为 `0`）。
   - 静默期间无后台定时器、无新增写入；尾部再送 10 条丢弃后 EOF，精确写出 `(120, 62, 105, 111)`，且 `IN_MOVED_TO` 增量精确为 `1`。
2. **可重复原子发布验证（不靠高频轮询猜概率）**：
   - 在触发首丢更新前先持有旧 `.logstats` 的已打开文件描述符 `old_fp` 并记录 `old_ino`。
   - 触发更新并观测到 `new_ino != old_ino` 后，读取 `old_fp` 仍得到完整合法的旧 JSON `(101, 0, null, null)`；重新打开路径读取得到完整合法的新 JSON `(120, 1, 105, 105)`；权限恒为 `0600`，目录无 `.logstats.*` 残留。
3. **发布失败路径与负向用例**：
   - **中途 `mv` 失败**：通过 `PATH` 包装 `mv` 在第 3 次发布（首丢时刻）返回退出码 `1`。验证：① 已有可读快照 `(1, 0)` 保持完整未被破坏；② `rm -f -- "$tmp"` 清掉了刚创建的临时文件（目录零残留）；③ `mv` 调用总数停在 `3`（`stats = ""` 停写本会话）；④ 日志转发、丢弃摘要、恢复放行与 EOF 收尾全部正常，退出码 `0`。
   - **符号链接目标**：目标为指向 `target.txt` 的 symlink 时拒绝写入，`target.txt` 原文 `KEEP\n` 未变，无临时文件，日志照常转发。
   - **目录目标**：目标为已存在目录时拒绝写入，目录保持为空，日志照常转发。
   - **元字符路径**：含空格、单引号与 `$(touch SENTINEL)` 的路径保持字面值、无命令注入、原子发布 `0600` 快照。

## 未覆盖边界

- **极短 TOCTOU 窗口**：`stats_writer` 在 `mktemp` 前检查目标非 symlink / 非目录；POSIX `mv -f` 无法原子化校验“检查后到 `mv` 前被同权限进程替换为目录”的极端竞争，但运行目录 `/var/run/aether-proxy` 仅由 root 独占，属可接受边界。
- **文件系统级 `ENOSPC` / `fsync` 断电测试**：`.logstats` 位于 tmpfs（`/var/run/aether-proxy`），不落 flash，不做 `fsync`；失败路径以 `mv` 返回非 0 覆盖了「临时文件已写入但发布失败」的清理与降级逻辑，未在真机或独立限额 tmpfs 挂载上模拟 `ENOSPC`。
- **真机 / procd 实测**：本次全部验证在宿主机（GNU Awk 5.3.2 与 BusyBox v1.37.0 `busybox awk`）及打包 `smoke-host.py` 下完成，未操作设备。
