## 改动

- 分支：`m8/version-suffix`；worktree：`/workspace/openwrt/aether-proxy-wt/T8.21`。
- `aether-proxy/src/lib/update.uc`：`version_parts()` 的末尾 release 匹配从 `-rN` 扩展为 `-r?N`，并解释固件、SDK 两种后缀的兼容原因。上游数字分段、缺省 release 0、`version_newer()` 及调用方均不改。

- `reports/T8.21.md`：记录场景映射、旧实现失败证据和全部验收输出。

### 根因与测试方式

原正则只认 `-rN`，`26.9.30-5` 因而没有提取 release，按 0 参与比较，误把同上游的 `26.9.30-r1` 当作更新。修复只让正则中的 `r` 可选，仍要求末尾为完整的十进制 release 后缀。

测试复用仓库的 opkg 替身、本地 HTTP 服务和 usign 密钥生成流程。每组清单只保留被测包、改通道版本、重新签名，保留已存在且架构/包格式适用的资产元数据。检查阶段不安装或下载包，因此无须为每个比较版本另造资产文件。每组使用全新运行目录，避免既有 `updates.json` 的事件去重掩盖误报；正向更新用例要求恰好一条事件，反向和相等用例要求零条。

本卡只改两处已有模块，沿用模块职责注释和缩进。新增测试逐条断言、表驱动循环少于百行；新增行按 tab 为 4 列检查均不超过 120 列。无顺手行为修改。
