# T12.7 B25 热力图布局返工：3×30 连续日期网格

## 结论

按最后一条指令（最终布局，以此为准）完成 T12.7 返工：热力图不再是卡片——**去掉
`.cbi-section` 背景、「使用热力图」标题和星期表头**，网格直接渲染在容器里；网格改为
**3 行 × 30 列 = 90 格**的连续日期网格，row-major——最近 90 个本地日期（含今天），
**无前导空格**，今天恒在 index 89（第 2 行第 29 列，右下角），与星期几无关。宽度按
指定 CSS 实现：容器 `.ap-heat-wrap { width: 75%; max-width: 75%; margin-inline: auto;
margin-bottom: 1.25em }` 居中并与「运行状态」卡保持 1.25em 间距，关闭时空区域由
`.ap-heat-wrap:empty { display: none }` 完全移出布局；网格 `repeat(30, minmax(0, 1fr))`
等宽铺满（`gap: 3px`、`width: 100%`），每格 `aspect-ratio: 1` 的圆角正方形（桌面约
25px 一格），3 行总高约 80–100px。颜色 5 档/健康度边框角标/tooltip 四行文本/空历史
渲染完整 90 格中性网格/失败保留最后网格+一句错误/空格无 tooltip 的规则全部不变；
外层 `overflow-x: auto` 在极窄屏幕兜底横向滚动。同步更新 `docs/10-cli-luci.md` 与
`docs/b25-heatmap.md` §7。不改后端/API/usage/采样/版本；未 push。

## 实现

- `model/overview.js`（纯函数改动）：
  - `heatmap_view(reply, today)` 返回 `{ state:'ok', cells }` 扁平 90 格（row-major）：
    `cells[i]` 是 `anchor − 89 + i` 天，`anchor = 今天`（today 不可解析时回退最新有效
    条目，再退到固定锚点），无前导空格，`cells[89]` 恒为今天。常量收敛为
    `HEATMAP_DAYS = 90`（3×30 由 CSS 的 30 列表达，模型只管 90 天窗口）；
    `HEATMAP_COLUMNS` 随 13 列方案一起删除。
  - 无数据的天仍落 `null`（空白、无 tooltip、不补零）；未来日期与坏条目在窗口铺设前
    丢弃；窗口外旧条目丢弃；颜色归一化只取窗口内有数据的天（`Math.max(0, …)` 防空
    数组），5 档 `log1p(tx+rx)`、健康档 ok/warn/bad/none、tooltip 四行文本不变。
  - 文件头注释同步为「连续 3 行 × 30 列网格」口径。
- `view/overview.js`：
  - `HEATMAP_CSS` 按指令逐条落名：`.ap-heat-wrap { width: 75%; max-width: 75%;

    none }`、`.ap-heat-scroll { overflow-x: auto }`、`.ap-heat-grid { display: grid;
    grid-template-columns: repeat(30, minmax(0, 1fr)); gap: 3px; width: 100% }`、

    度/角标样式不变。样式仍内联在视图 `<style>` 里随脚本版本走（T10.12 同因）。
  - `heatmapGrid(cells)`、`updateHeatmap()` 的结构不变（无 `cbi-section`、无标题，
    失败保留最后网格 + 一行警告色错误，关闭清空）；只是数据从 91 格换成 90 格。
- `docs/10-cli-luci.md`「B25：概览页使用热力图」小节：网格（3×30、无前导空格、

## 决定与理由

- **无前导空格、窗口就是 90 天**：3×30=90 恰好等于窗口长度，row-major 下
  `cells[89]` 自然落在第 2 行第 29 列（右下角），不再需要任何占位格；上一版的
  「1 前导空格 + 90 天 = 91 = 13×7」随布局一起失效，模型循环回到朴素的
  「`anchor − 89 … anchor`」。
- **30 列交给 CSS、模型只出 90 格**：`repeat(30, minmax(0, 1fr))` 等宽铺满后格宽
  完全由容器决定（75% 内容宽），行高由 `aspect-ratio: 1` 派生——模型不需要知道
  列数，布局调整不动数据结构。
- **`:empty { display: none }` 而不是条件挂载**：区域 div 始终在 `content` 里占位
  （测试断言它在 notices 与「运行状态」之间的位置），关闭时清空子节点后由 `:empty`
  把它连同 `margin-bottom` 一起移出布局——关闭时视觉上零残留，刷新逻辑也不用
  特判挂载/卸载。
- **格子约 25px、3 行约 80–100px 是派生值**：`width: 75%` × 桌面内容列（约
  1000–1200px）≈ 750–900px，减去 29×3px 间距后除以 30 → 每格约 22–27px，
  `aspect-ratio: 1` 下 3 行 + 2 间距 ≈ 72–87px，落在指令给的约数区间；尺寸不写死，
  随主题内容宽度自适应。
- **`overflow-x: auto` 保留为兜底**：`minmax(0, 1fr)` 使网格永不溢出容器，正常情况
  无滚动；极窄屏幕上格子压缩过小时外层仍可滚动，满足「窄屏滚动」验收项。
