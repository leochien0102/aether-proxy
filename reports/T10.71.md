## 偏差与待定

1. `docs/` 变更仅限本卡明确允许的两份文档，履行交接材料「文档/i18n」要求。通用 review 的 docs WARN 属预期；不修改其它设计、任务卡。
2. `tests/luci/progressive-lists.test.js` 不匹配卡片的 nodes*.js glob，但它集中承载节点页真实 GridSection/旧切换锁和通知用例；删除入口必然需要同步这些期望。只清理本卡对应旧入口、初屏 status、提示和删除保护，不修改订阅功能行为。其余原卡 expected/golden 未改。
3. `TODO(design)`：旧节点或旧模式未设置（返回 null）时，选择 API 无法表达“恢复未设置”。保守进入 rollback-failed 并保留横幅，不用默认值冒充 previous、不做部分恢复。
4. `TODO(design)`：live hash 失败发生在读取配置之前，无法知道本次目标。记录 target:null，不把旧运行节点冒充目标；配置规范化失败同样没有可用 snapshot，页面保守超时而不是猜测回滚。
5. `TODO(design)`：浏览器/路由器时钟偏移没有规定校正协议，保持严格的开始时间下界；不满足则超时，不放宽到可能接受旧成功结果。`at` 使用含小数 Unix 秒以避免整秒碰撞，并排除本页原有记录。
6. `last_reload` 写入遇 I/O/状态读取错误时明确记 FS_FAILED，不覆盖无法读取的状态，也不伪造 completion；页面按期限处理。错误对象编码为诊断字符串后以文本节点显示。
7. 保留现有停止优先屏障；未改锁。页面关掉/断网、UCI 回读后到写 RPC 之间再发生跨页改动的绝对保证仍不在本卡，未扩展后端 API。
8. 没有改启用/启动/重启的遮罩、订阅回滚或当前节点编辑失败处理。原启动 watcher/反馈测试全部保留通过。
