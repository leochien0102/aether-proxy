# T16.40 完成报告

基线 `76aba10`；分支 `feat/t16.40-rawlog-dup`。

## 改动

- 仅在 collector 的写盘 awk 中处理相邻重复：比较完整的归一化记录，只更新最后一条已写入的普通记录。实时写入不等待下一行；被抑制的明细、collector 生成的摘要都不会打断相邻比较。
- EOF 与普通记录触发轮转前先写待处理的 `suppressed` 摘要，再写 `folded` 摘要。能容纳时将摘要留在旧段末尾，触发轮转的普通记录写入新段；若段内剩余空间本身容不下摘要，仍以 1 MiB / 2000 行硬上限为准，按相同顺序写入下一段，不截断摘要。
- `tests/daemon/raw-log.py` 的字节轮转夹具原本送入三条相同的 600 KB 记录，恰好被新规则折叠，无法触发两次轮转。经确认只将三条记录改为等长的 `x`、`y`、`z` 填充，保留原有阈值和全部断言。
- `tests/daemon/run.sh` 纳入新用例和启动噪音回归；检测到 BusyBox 时覆盖两种 awk。显式设置 `RAW_LOG_BUSYBOX=1` 时，缺少 BusyBox 会导致测试失败。未改 logd、子进程过滤器、监管、收集器握手、版本号或 Makefile。

## 两种 awk 的实际输入 / 输出

以下摘自 `RAW_LOG_BUSYBOX=1 bash tests/daemon/run.sh` 中 `raw-log-dup.py` 的实跑结果，省略了测试明确核对过的公共 syslog 前缀和轮转预填行。`S` = `aether-proxy: chinadns-ng startup: 1 info lines suppressed`；`F(n)` = `aether-proxy: raw log: n duplicate line(s) folded`。`L` = `I [main.zig:90 on_start] local listen addr: 127.0.0.1#5353`；`N` = `I [main.zig:91 on_start] startup detail`；`B×160` 为一行 160 个 `B`。

| 场景 | 实际输入（两种 awk 相同） | 宿主 GNU awk 5.3.2 实际落盘 | BusyBox awk 1.37.0 实际落盘 |
|---|---|---|---|
| 相邻重复及不相邻的 A | `A, A, B, B, B, A` | `raw.log: A, B, A, F(3)` | `raw.log: A, B, A, F(3)` |
| 不同 ANSI / 自带时间戳 | `\x1b[31m2026-11-19 12:00:01 A\x1b[0m`、`A`、`\x1b[32m2026-11-19 12:00:02 A\x1b[0m` | `raw.log: A, F(2)` | `raw.log: A, F(2)` |
| 启动豁免、噪音和 EOF 摘要顺序 | `L, N, L, L, N` | `raw.log: L, S, S, F(2)` | `raw.log: L, S, S, F(2)` |
| 行数轮转与前后独立计数（预填 1998 行） | `A, A, B, B, B` | `raw.log.1` 尾：`A, F(1)`；`raw.log: B, F(2)` | `raw.log.1` 尾：`A, F(1)`；`raw.log: B, F(2)` |
| 字节轮转（预填到距 1 MiB 还有 200 字节） | `A, A, N, B×160` | `raw.log.1` 尾：`A, S, F(1)`；`raw.log: B×160` | `raw.log.1` 尾：`A, S, F(1)`；`raw.log: B×160` |

宿主和 BusyBox 的初版 5 个用例在 `76aba10` 写盘实现上均失败；修复并加强轮转后计数断言后，两边均 `Ran 5 tests` / `OK`。实时 burst 两边均读到 40/40 条有序的非重复记录及两个 1 秒 tick，会话尚未 EOF；启动噪音测试（含 `dnl_init tag:` 例外和 EOF 摘要顺序）`Ran 2 tests` / `OK`。
