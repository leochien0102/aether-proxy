# T16.48 — 同版本复用已发布字节的离线回归

1.2.2-r1 曾因 `Gate bytes conflict with published package` 直发失败。新用例直接调用 `reconcile()`，以临时清单和注入的 `fetch` 模拟 `channel-stable`，验证同版本包实际交付的是已发布字节，而不是本次门禁重建的字节。未修改生产代码或原有 9 条用例的断言。

## 新增用例

`tests/ci/test_release_paths.py` 中的 `ReconcilePublishedBytes`：

| 用例 | 验证 |
| --- | --- |
| `test_unchanged_version_reuses_published_bytes` | 暂存文件由 B2 变为 B1，`source` 为 `published`，`sha256` 对应 B1。 |
| `test_different_version_keeps_built_bytes` | 保留构建字节和 inode，`source` 为 `built`，不获取发布资产。 |
| `test_missing_package_keeps_built_bytes` | 清单缺包时不抛错，保留构建字节和 inode，`source` 为 `built`，不获取发布资产。 |
| `test_three_noarch_packages_use_all_assets` | 三个 noarch 包的 entry 都是 `aarch64_generic`，各自清单的 `assets` 只有 `all`；验证实际替换字节、`source` 和哈希。 |
| `test_sha256_mismatch_exits_without_rewriting` | 哈希不匹配时 `SystemExit`，暂存文件内容和 inode 不变。 |
| `test_size_mismatch_exits_without_rewriting` | 哈希正确而大小不匹配时 `SystemExit`，暂存文件内容和 inode 不变。 |
| `test_missing_packages_object_exits_without_rewriting` | 缺少 `packages` 时 `SystemExit`，暂存文件内容和 inode 不变，不获取发布资产。 |

## 反向验证

用 `compile` / `exec` 在内存中逐一运行 `stage.py` 的临时错误变体，仅在测试模块中替换导入的 `reconcile`。磁盘上的生产代码未改动。

- 替换后错标 `source='built'`：`test_unchanged_version_reuses_published_bytes` 报 `AssertionError: 'built' != 'published'`。
- 跳过落盘但保留发布元数据更新：同一用例报 `AssertionError: b'gate build bytes (B2)' != b'published bytes (B1)'`。
- noarch 改为按 entry 的 `arch` 查找：`test_three_noarch_packages_use_all_assets` 的三个子用例都因 `KeyError: 'aarch64_generic'` 被包装为 `SystemExit` 而失败。
