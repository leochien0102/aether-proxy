### 实际快照与 history 对比

`tests/monitor/driver.uc` 读取 monitor 实际写出的 `state.json` 后打印（隔离 sys-root）：

```json
    "tx": 2500,
    "rx": 2000,
    "observed": 1,
    "healthy": 0,
    "at": 1794883641
  }

```

`tests/stats/test.py` 的 CLI 实际输出（同一份 usage 文件；加入快照前后）：

```json
{"ok":true,"enabled":true,"days":[{"date":"2026-11-16","tx":1,"rx":2,"observed":3,"healthy":2},{"date":"2026-11-17","tx":1,"rx":2,"observed":3,"healthy":2}],"updated_at":17,"quota":{"bytes":100000000000,"set_at":17}}
```

```json
{"ok":true,"enabled":true,"days":[{"date":"2026-11-16","tx":1,"rx":2,"observed":3,"healthy":2},{"date":"2026-11-17","tx":123,"rx":456,"observed":60.5,"healthy":55}],"updated_at":17,"quota":{"bytes":100000000000,"set_at":17}}
```

```json
{"state":"running","usage_today":{"date":"2026-11-17","tx":123,"rx":456,"observed":60.5,"healthy":55,"at":1794883600}}
```

忽略路径证据（真实 CLI 的 PASS 行）：


前三者分别用 now-601、昨天、关闭 UCI 开关；前两者返回合并前的完整结果，关闭返回精确的 `enabled:false` 对象。最后一条用 FIFO 占据 usage/state 路径，若关闭后仍打开任一文件，测试会超时失败。

## 偏差与待定

- 基线 `overview.js` 实际注释为 “No TTL: every enabled refresh sees quota changes from other sessions”，并没有卡中所述 600 秒 TTL。因此本卡从无缓存改为 60 秒缓存，最终行为按契约；其他会话的额度修改最多随下一次 history 刷新可见。本页额度保存仍立即本地重着色，未改交互。
- “at 距今 ≤600 秒”按绝对时间距离实现（max-min），并用固定时钟测试正负方向的 600/601 端点。日期仍必须严格等于本地今天；超过窗口的未来时间同样忽略。
- state 读写本已透明保留未知字段，不必重写；畸形字段由新的纯读取助手当作无实时数据，不使整份运行态报错。
- docs 中旧文案有 `--run-dir` 仅接受不用、当天等落盘等历史描述；以本卡和新设计 §2.1 为准。遵循执行约定，本卡不修改 docs。
- 未修改其他卡的期望文件、共享测试基础设施、usage.uc、rpcd/ACL/common.js、颜色/布局/额度交互、advanced、版本或 Makefile。
