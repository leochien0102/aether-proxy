## 偏差与待定

- 没有产品设计偏差，没有新增 `TODO(design)`。
- 「没有写入」按没有列表写入、没有有效 UCI 配置变化验证。SDK 的 `Flag.parse()` 即使值未改也会调用 set；对已有同值调用 set 是 UCI no-op。测试不错误要求整个页面永远不调用 Flag 的 setter，同时确认直连开关仍为 0，未做任务范围外的 Flag 保存行为修改。
- SDK 的 add-box 校验与保存前检查是本次复现的依据；按卡要求，替身另对每个已存项做预检。SDK 的列表项是 hidden input，替身的逐项预检比 SDK 的添加框行为更严格，不声称完整重实现 DOM、Dropdown 交互或 datatype 引擎。
- 静态闸门复用现有 `schema-defaults.test.js` 的声明记录器，执行实际选项的 validator 而不是匹配源码字符串；既有「所有表单页」覆盖断言仍保留，新增页面会要求更新清单。
- 不改 URL/DNS 模型：它们仍可严格检查已存项及与 CLI 对照，只有真正的 DynamicList 单项入口放过空添加框。
