### postinst 全文

```sh
#!/bin/sh
[ -n "$${IPKG_INSTROOT}" ] && exit 0
if [ -x /etc/init.d/rpcd ]; then
	/etc/init.d/rpcd reload || echo "luci-app-aether-proxy: rpcd reload failed (rc=$$?)" >&2
fi
exit 0
```

### postrm 全文

```sh
#!/bin/sh
[ -n "$${IPKG_INSTROOT}" ] && exit 0
if [ -x /etc/init.d/rpcd ]; then
	/etc/init.d/rpcd reload || echo "luci-app-aether-proxy: rpcd reload failed (rc=$$?)" >&2
fi
exit 0
```

Makefile 中 `$$` 在包构建时变成 `$`。`IPKG_INSTROOT` 非空时立即退出 0，不检测或调用宿主机 rpcd。
真机上 rpcd 不存在或不可执行则静默跳过；存在时调用 reload，失败打印带退出码的一行 stderr，最后仍退出 0。
不使用 restart/kill、不修改 `/etc/config/rpcd`，不改版本号或任何产品代码/ACL。
