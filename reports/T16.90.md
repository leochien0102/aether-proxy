3. `.github/workflows/release-component.yml`：将 workflow 顶层 `permissions` 从 `contents: write` 收紧为 `contents: read`；`build`（`uses: ./.github/workflows/build.yml`）继承 `contents: read`，仅负责创建并上传 GitHub Release 的 `release` job 保留显式 job 级 `permissions: { contents: write }`。

逐项核对三份工作流中的全部外部 Action 与命令，**除 `contents: read`（以及 `release` job 必需的 `contents: write`）外，无需任何其他 `GITHUB_TOKEN` 权限**：

| 工作流 / Job | 调用点 | 鉴权机制与所需 `GITHUB_TOKEN` 权限 |
| --- | --- | --- |
| `build.yml` / `detect` | `actions/checkout` + 本地 `git` + `$GITHUB_OUTPUT` | 仅拉取本仓代码，需要 `contents: read`。 |
| `build.yml` / `packages` | `actions/checkout`、`openwrt/gh-action-sdk`、`actions/upload-artifact` | `checkout` 需 `contents: read`；`upload-artifact@v4` 使用 runner 运行时 `ACTIONS_RUNTIME_TOKEN`，无需 `actions:` scope；`gh-action-sdk` 拉取公开 OpenWrt SDK 镜像，无 GitHub API 写调用。 |
| `build.yml` / `smoke` | `actions/checkout`、`actions/download-artifact`（同 run，未传 `run-id`/`github-token`）、`docker/setup-qemu-action`、`docker run` | `checkout` 需 `contents: read`；同 run `download-artifact@v4` 使用 `ACTIONS_RUNTIME_TOKEN`，**不需要** `actions: read`（不同于 `release-assets.yml` 跨 run 下载需传 `run-id` + `github-token`）。 |
