### 其他验收项

- 规则/DNS 页、模型、翻译和测试均在本卡允许范围内；新函数按职责拆分，使用 tab 缩进，模块注释注明依据。可信 DNS 的单一选项共同拥有两行，避免独立选项并行覆盖同一个 UCI list；单独覆盖 `isValid` / `getValidationError`，防止 LuCI Combobox 强制 optional 导致第一行空值漏检。
- 国内 DNS 的既有列表原样传给 DynamicList，渲染和 status 回复不会写 UCI；TCP 前缀只在用户保存可信 DNS 时按设计归一化。
- LuCI 的 `form.Value` 只渲染字符串 description，因此国内说明及异步状态容器在该选项的 renderWidget 中使用标准 `cbi-value-description` 渲染，运行态文字位于说明之后。
- 三组预设集中在模型的 `{ value, name }` 表中。国内/直连保留 LuCI DynamicList 的自由输入；可信地址使用 LuCI Combobox，协议使用 Select，窄屏可换行，协议 select 设置 `width:auto`。
- 当前检出后端尚不支持 `wan` / `status.wan_dns`，按任务卡允许的前置关系使用 status 替身测试本卡新能力；可信 TCP/UDP 的新测试同时与真实后端 CLI 对照。未扩展 CLI/rpcd 来抢做 T9.23。
- 未进行真机页面、固件 CI、主题和窄屏的视觉验收：本卡明确由设计负责人在两张后端卡合并后查看真机效果，本环境未连接测试路由器。相关 DOM 结构、标签、布局属性和数据读写在宿主机测试中覆盖。
