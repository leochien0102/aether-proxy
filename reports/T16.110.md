## 隔离网络真实验收

`tests/explicit-proxy/lan.py` 复用原有 production daemon/reload fixture 和流量/进程 helper，`network.py` 创建可销毁的 server/client 网络命名空间和 veth：

```text
独立 LAN client 192.0.2.2/24 ── veth ── server br-lan 192.0.2.1/24
                                              ├─ production daemon → Xray
                                              ├─ authenticated Xray upstream (loopback)
                                              └─ offline HTTP / TLS targets (loopback)
```

没有客户端默认路由；客户端直连目标 loopback 失败，未装透明拦截规则。所有主动网络修改只发生在新命名空间，未操作宿主路由、防火墙或设备；无公网请求、无新 OpenWrt 虚机。主 Xray 使用完整生产渲染，不删除透明/DNS 入站。测试上游才使用独立测试配置。

命令（仓库根目录）：

```sh
sudo -n env XRAY_BIN=/workspace/openwrt/ci-spike/tools/xray-26.11.9/xray \
  python3 -B tests/explicit-proxy/lan.py
```

真实引擎：**Xray 26.11.9 / 676eaf6 / go1.27.3 linux/amd64**。

验收结果：

1. 双关启动无显式监听；逐次重载 SOCKS → 双开 → HTTP → 双开 → SOCKS → 双关，另开启 HTTP 做失败回滚。独立客户端使用正确账号完成 SOCKS5 到 HTTP/TLS、HTTP forward、HTTP CONNECT 到 TLS 的真实响应；每次只关闭一个协议，另一协议继续可用。
2. 无认证、错误用户名、错误密码均失败，目标 TCP 接受计数零增加；关闭的入口请求失败。每次校验 daemon 直属的真实本代 Xray PID 和其 FD 拥有的 TCP listener，只出现指定 LAN IPv4/端口，不附带回环或 wildcard。
3. 依次提交空地址、非法字符串、`0.0.0.0`、`127.0.0.1`、`::1`、非本机 LAN 同网段地址 `192.0.2.99`、实际属于本机但不在 LAN 接口的 `198.51.100.1`：reload 均失败，旧 artifacts/hash/running 状态保留；独立客户端的旧 HTTP forward 与 CONNECT/TLS 仍通过。
4. 其他进程占用新增 SOCKS 端口后，真实引擎运行时 bind 失败；reload 报失败并恢复旧配置。占用者 socket inode 保留，新代/回滚 Xray 不误占其监听，旧 HTTP forward 与 CONNECT/TLS 仍真实可用。
5. 停掉上游后，认证请求失败且目标零新增接受，确认无 direct 回退。显式配置变更前后非显式入站、出站和路由 projection 不变。
6. 读取 rooted 命令夹具，显式变更前后 nft artifacts 字节与 nft load/delete、fw4 命令记录不变。**这是命令/渲染夹具证据，不冒称真实 OpenWrt 防火墙验收。**

观察边界：沿用 T16.108 的隔离模块复制，在读取私有 current artifacts 后仅将 Xray `wait()` 观察上下文切至原生 `/proc` / socket_diag；requirements、所有权判定、成功条件和超时均未替换。DNS、nft、路由、dnsmasq 仍为私有夹具；仅只读地址查询委托给隔离服务器命名空间的真实 `ip`。

## 执行边界与风险

- 没有合 main、push、发版、改版本、操作设备或 B29。
- 没有实际设备/OpenWrt/fw4 防火墙流量验收；网络可达性仍由既有防火墙决定，管理员须限制允许访问显式端口的网络。
- SOCKS 用户密码与 HTTP Basic 本身不加密；HTTP CONNECT 加密的是客户端到目标的 TLS，不是客户端到代理的认证链路。只应在受控 LAN 使用。
- 测试凭据随机生成，仅存在于临时私有配置与 stdin；不输出原始配置/含密引擎输出，运行日志、事件和状态检查无随机凭据，退出清理进程与临时目录。
