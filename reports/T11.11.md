5. 向用户说明超出任务卡原文件范围的必要性，用户明确选择「允许最小补齐」。只给 `lib/node.uc` 和 `lib/sub.uc` 的白名单末尾补齐 username、WireGuard 和 Hysteria 字段，不调整旧字段顺序、不改 schema/render/UI。

## 实现与场景

| 场景 | 结果 |
|---|---|
| SOCKS / SOCKS5 / HTTP 无 userinfo | 无 username/password，raw + none |
| URL 编码 user:pass、Base64(user:pass)、URL 编码的 Base64 padding | 解码成功；用户名大小写、密码冒号保留 |
| user/pass 缺一项、错误 Base64、错误转义 | missing_field 或 malformed；CLI 错误 detail 仅含 skip 枚举 |
| hysteria2 / hy2 | auth → hysteria_auth，固定 hysteria + TLS，支持 SNI 和名称 |
| insecure / allowInsecure | 任一为 1/true 则 NODE_INSECURE_IGNORED；即使另一参数为 0 也告警，不导入跳过校验字段 |
| WireGuard v2rayN | URL 解码私钥、公钥、地址列表、PSK、keepalive；地址按逗号切分；显式 0 保留 |
| WireGuard 缺密钥/地址、非规范 Base64 密钥 | missing_field / invalid_value；不输出密钥 |
| WireGuard 地址/keepalive 非法 | 沿用现有校验映射，malformed |
| IPv6 字面量 / 非法端口 | ipv6_address / malformed |
| 未知 query（含 obfs / reserved） | 忽略，不导入为节点字段 |
| 明文 / Base64 混合订阅 | 有效节点继续导入，错误逐原因统计 |
| 真实 CLI 导入 | 7 条新协议节点持久化为 source=manual，WireGuard list / keepalive=0 完整保留 |
| 真实订阅更新 | 7 条新协议节点原子落地，错误计数、状态和 insecure 告警正确；相同内容再次更新 added=0、updated=0 |
| 凭据保护 | 检查 CLI import 输出、错误 detail、stderr、订阅输出、events.jsonl 和调用日志，不含认证或密钥 |

`node parse` 的成功输出按原 API 返回节点配置（含供编辑/导入使用的认证字段）；这不属于日志/事件/错误诊断。`node import` 的成功输出不返回认证值。
