## DNS 引擎与跨仓契约

|编号|复核结论|建议与验收|
|---|---|---|
|C1|无界任务及每次上游交换分配 65535 字节成立。报告的 QPS、四路、FD、内存是特定并发路径估算，不是实机阈值。默认集成还要区别环回监听与直接对外监听。|**派生任务前**限额，而不是先 spawn 再等 semaphore；分别约束 TCP 连接、在途请求和上游尝试。取消/超时归还额度；用受控正常负载量任务、FD 和 RSS。不要用 4096 一刀切破坏合法 DNS TCP 大帧。|
|H11|单线程 Tokio 上同步 Netlink send/recv；部分缓存命中也需重写集合。|专用有界工作队列，读判定也移出 reactor；定义队列满、内核超时和写入失败时的行为。不要以永久去重破坏 nft 集合重建后补写；需要先写集合再放行应答的路径应保留顺序。|
|H12/H14|响应未核对完整 Question、ID 递增；名单及缓存键大小写敏感。连接式 UDP 会限定对端，不能据此声称已经污染。|随机上游 ID，校验 QR、ID、Question 数及 QNAME/QTYPE/QCLASS；路由与缓存键 ASCII 归一化，返回本次客户端 ID 与问题大小写。用固定报文单测，不做攻击复现。|
|H13|组内首个通过基本校验的应答胜出，快错误会遮住慢的有效结果。|错误答复保留作兜底，等待有效 NOERROR/NXDOMAIN 或期限；测全错、先错后成功及既有国内/可信组策略。|
|H15|跨仓契约不一致：proxy 接受 TLS 上游，引擎启动校验拒绝。|按**实际选中的引擎**前置能力检查，停旧进程前解释不支持的上游；不全局禁用，不把实现完整 DoT 当成本次必要条件。|
|M16|未经客户端 UDP 上限处理即发送。删 OPT 本身并不是设置 TC 的充分条件。|统一实时/缓存 UDP 出口，按无 EDNS 默认 512 或协商上限生成有效截断响应；必要时 TC=1，并验证 TCP 可取完整应答。|
|M17/M18|TTL=0 可进入 stale；时间加法在极值下有溢出风险，stale 时间取决于配置。IPv4 区间尾值回绕成立，具体内核整批 EINVAL 尚未实测。|零 TTL 不缓存，限制配置并安全计算期限；对最大地址明确定义可表示性，不让特殊地址拖垮合法批次，隔离 netns 验实际写入。|
|M19|两侧有跳过 RSTRIP 的设置，缺显式 strip 策略；节省 1–2 MiB 无对照证据。|检查正式 ELF 符号/调试段，比较两架构裸 ELF 和压缩包，再决定在哪一处 strip，避免重复处理。|

## Low 项整理

- 冷却/退避用单调时间，对外事件仍用墙钟；临时文件用同目录独占唯一名、有限重试；把 restart intent 的 umask 限于子 shell。reload 热换二进制补启动时相同的最低版本检查，结合 M6 验证。
- rawlog prober 的“长期僵尸”缺证据，BusyBox ash 可在等待时回收子进程；不能单凭没有立即 wait 定案。rpcd 的 probe_url 上限是外层期限遗漏，CLI 有独立校验；service 的 quiet 则不应盲加，现有失败日志是有意行为。opkg 组件展示解析只计 installed 状态。
- DNS verdict 缓存无 TTL，满时是任意淘汰，不是正式的随机策略；TCP 单请求、无 HUP 是能力边界（proxy 当前通过重启 DNS 应用设置），先确定产品承诺。Netlink 缓冲可在有界 worker 内复用。
- 纠正安装指南和两包说明：真正的依赖是 `aether-xray` 和虚拟 `dns-engine`，不是必须指定 `aether-dns` 实现。按 schema 同步 DNS 默认值；组件发布清单应与唯一发布源一致。规则文件实有 15 行，核实有效记录数并重生成来源表；T16.40 已随 r6 发布。空目录不受 Git 跟踪，不作为产品缺陷。

## 派卡和发布顺序建议

1. **先保护用户数据**：H8 与 M3 两张独立卡，分别证明“备份中确有账本”和“并发更新不丢字段”。H8 可独立交付，不等锁重构。
2. **解除发版/升级阻塞**：C2 与 H10 分卡，复用现有 CI；H5 单卡验证真实 APK 元数据和精确恢复策略。H6 作为兼容路径回归，不恢复已经停用的 RC/bridge 发布流程。
3. **运行态一致性**：H1/M1/M2 先明确锁的所有者与生命周期；H4 独立做事务。H3/M7、H2、M5、H7 各按失败边界验收，不在一张卡内重写整个 daemon。M8 的文本渲染修复可独立提前。
4. **DNS 单独发布线**：先 C1、H12/H14，再 H11、H13、M16；H15 在 proxy 一侧单独阻止不可用配置。Rust 单测之外保留一次真正运行的隔离 Netlink 验收。不要把两仓修复硬塞进同一版。
5. **测试与文档**：旧测试逐条映射为仍有效、已替代、历史废弃；先迁移缺失的负例，再删除废弃项。用已有工作流接入，不新增一套平行构建。其余 M/Low 按表分批，不以审计严重度直接决定版本号。
