### V8 三次反向变异

命令：`python3 tests/update/mutate-events.py`。每次只暂改生产文件，运行指定测试，`finally` 恢复原始内容，并在结束核对字节一致。

```text
PASS V8 after-install: exit 1; FAIL  M4-04 V3-hash event contract
PASS V8 old-finish: exit 1; M4-04 V6: exact Chinese and English start/finish templates and unknown fallback
PASS V8 proxy-only: exit 1; FAIL  M4-04 V1 event contract
PASS V8: all production files restored byte-for-byte
```

1. **开始事件后移**：交换普通路径 `UPDATE_STARTED` 与 `let installed = install_package(...)`，执行 `bash tests/update/run.sh`。红灯包括 `FAIL  M4-04 V3-download event contract`、`FAIL  M4-04 V3-hash event contract`，原因：`AssertionError: V3 UPDATE_STARTED must immediately precede install_package`；V1/V2 动态边界也红。
2. **完成文案恢复旧串**：模板改回实际旧 msgid `Installed {package} version {version}`，执行 `node --test tests/luci/logs-update-events.test.js`。V6 红，`pass 1, fail 1`；实际 `Installed aether-proxy version 1.0.0-r1` 不等于预期 `已完成更新：aether-proxy 1.0.0-r1`，V7 仍绿。
3. **仅 proxy 发开始事件**：普通/companion 发射加 `name == C.PROG` 条件，删除 dns 开始事件，执行 `bash tests/update/run.sh`。`FAIL  M4-04 V1 event contract`：实际 companions 仅有 TEST_INSTALL/UPDATE_INSTALLED，缺少两条 UPDATE_STARTED；V2/V5 也红。

变异后的正常实现又通过更新与 LuCI 全量、V6/V7 与 i18n，两份生产文件均已恢复，无残留变异。
